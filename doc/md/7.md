```markdown
# Simple JSF (Jakarta Faces) Project — Step‑by‑Step Commands

This Markdown file contains every command needed to create a minimal JSF application and deploy it to WildFly.

## Prerequisites

- **Java 17** or **Java 21** (LTS)
- **Maven 3.8+**
- **WildFly** (or another Jakarta EE 10 compatible server) running on `localhost:9990`

## 1. Generate the Maven Web Project

Run the following command in a terminal. Replace the `groupId` and `artifactId` if you wish.

```bash
mvn archetype:generate \
  -DarchetypeGroupId=org.apache.maven.archetypes \
  -DarchetypeArtifactId=maven-archetype-webapp \
  -DarchetypeVersion=1.4 \
  -DgroupId=com.example.jsf \
  -DartifactId=hello-jsf \
  -Dversion=1.0-SNAPSHOT \
  -DinteractiveMode=false
```

Now enter the project directory:

```bash
cd hello-jsf
```

## 2. Update `pom.xml`

Replace the generated `pom.xml` with the following content.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
                             http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example.jsf</groupId>
    <artifactId>hello-jsf</artifactId>
    <version>1.0-SNAPSHOT</version>
    <packaging>war</packaging>

    <properties>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <maven.compiler.source>17</maven.compiler.source>
        <maven.compiler.target>17</maven.compiler.target>
    </properties>

    <dependencies>
        <!-- Jakarta Faces API (provided by the application server) -->
        <dependency>
            <groupId>jakarta.faces</groupId>
            <artifactId>jakarta.faces-api</artifactId>
            <version>4.0.0</version>
            <scope>provided</scope>
        </dependency>

        <!-- CDI API (provided by the application server) -->
        <dependency>
            <groupId>jakarta.enterprise</groupId>
            <artifactId>jakarta.enterprise.cdi-api</artifactId>
            <version>4.0.0</version>
            <scope>provided</scope>
        </dependency>
    </dependencies>

    <build>
        <finalName>hello-jsf</finalName>
        <plugins>
            <!-- WildFly Maven Plugin for one‑command deployment -->
            <plugin>
                <groupId>org.wildfly.plugins</groupId>
                <artifactId>wildfly-maven-plugin</artifactId>
                <version>5.0.0.Final</version>
            </plugin>
        </plugins>
    </build>
</project>
```

## 3. Create the CDI Backing Bean

Create the directory for Java sources:

```bash
mkdir -p src/main/java/com/example/jsf/web
```

Now create the file `src/main/java/com/example/jsf/web/HelloBean.java` with this content:

```java
package com.example.jsf.web;

import jakarta.enterprise.context.RequestScoped;
import jakarta.inject.Named;
import java.io.Serializable;

@Named("helloBean")
@RequestScoped
public class HelloBean implements Serializable {

    private static final long serialVersionUID = 1L;

    private String name;
    private String message = "Welcome to Jakarta Faces!";

    public void submit() {
        if (name != null && !name.trim().isEmpty()) {
            message = "Hello, " + name.trim() + "! Glad to meet you.";
        } else {
            message = "Hello, mysterious stranger!";
        }
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getMessage() { return message; }
    public void setMessage(String message) { this.message = message; }
}
```

## 4. Create the Facelets View

Create the file `src/main/webapp/hello.xhtml`:

```xhtml
<!DOCTYPE html>
<html xmlns="http://www.w3.org/1999/xhtml"
      xmlns:h="jakarta.faces.html"
      xmlns:f="jakarta.faces.core">
<h:head>
    <title>Hello JSF</title>
</h:head>
<h:body>
    <h:form>
        <h:outputText value="#{helloBean.message}" />
        <br/><br/>

        <h:outputLabel for="nameInput" value="Your name: " />
        <h:inputText id="nameInput" value="#{helloBean.name}" />
        <br/><br/>

        <h:commandButton value="Say Hello" action="#{helloBean.submit}" />
    </h:form>
</h:body>
</html>
```

## 5. Configure the `FacesServlet` in `web.xml`

Replace the content of `src/main/webapp/WEB-INF/web.xml` with the following. This registers the Jakarta Faces controller and maps `*.xhtml` requests to it.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="https://jakarta.ee/xml/ns/jakartaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="https://jakarta.ee/xml/ns/jakartaee
                             https://jakarta.ee/xml/ns/jakartaee/web-app_6_1.xsd"
         version="6.1">

    <servlet>
        <servlet-name>FacesServlet</servlet-name>
        <servlet-class>jakarta.faces.webapp.FacesServlet</servlet-class>
        <load-on-startup>1</load-on-startup>
    </servlet>

    <servlet-mapping>
        <servlet-name>FacesServlet</servlet-name>
        <url-pattern>*.xhtml</url-pattern>
    </servlet-mapping>
</web-app>
```

## 6. Build the Application

From the project root (`hello-jsf`), run:

```bash
mvn clean package
```

This creates the deployable WAR file at:

```text
target/hello-jsf.war
```

## 7. Deploy to WildFly

Make sure WildFly is running. Then, from the project root, deploy with the WildFly Maven plugin:

```bash
mvn wildfly:deploy
```

The application will be deployed to the running WildFly instance.

Alternatively, you can combine build and deploy in one step:

```bash
mvn clean package wildfly:deploy
```

## 8. Access the Application

Open your browser and navigate to:

```text
http://localhost:8080/hello-jsf/hello.xhtml
```

You should see the greeting message, an input field, and a “Say Hello” button.

## 9. Undeploy (Optional)

To remove the application from the server, run:

```bash
mvn wildfly:undeploy
```
