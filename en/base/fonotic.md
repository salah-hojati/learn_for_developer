هیچ مشکلی نیست. آن علامت‌ها **IPA** یا «الفبای آوایی بین‌المللی» هستند. لازم نیست الان همه را حفظ کنی. من از این به بعد کنار هر کلمه، هم IPA می‌گذارم و هم **تلفظ ساده با حروف انگلیسی و فارسی** می‌نویسم تا کم‌کم یاد بگیری.

مثلاً:

**receipt**  
IPA: `/rɪˈsiːt/`  
تلفظ ساده: **ri-SEET**  
تقریب فارسی: **ری‌سیت** با کشش روی «سیت»  
معنی: رسید  
نکته: حرف **p** نوشته می‌شود ولی خوانده نمی‌شود.

حالا `/rɪˈsiːt/` را باز می‌کنم:

- `/r/` = صدای «ر»
- `/ɪ/` = صدای کوتاه بین «اِ» و «ای»، مثل کلمه **sit**
- `/ˈ/` = علامت تکیه. یعنی هجای بعدش را قوی‌تر بگو.
- `/s/` = صدای «س»
- `/iː/` = صدای «ای» کشیده، مثل **see**
- `/t/` = صدای «ت»

پس می‌شود: **ri-SEET**  
دو هجا دارد: `ri` + `SEET`  
تکیه روی `SEET` است.

چند نماد مهم که کم‌کم باید یاد بگیری:

| نماد | تقریب | مثال |
|---|---|---|
| /iː/ | ای کشیده | see |
| /ɪ/ | ای کوتاه/کسره | sit |
| /e/ | اِ | bed |
| /æ/ | بین اَ و اِ | cat |
| /ʌ/ | آ کوتاه | cup |
| /ə/ | صدای بی‌حال «اِ» | about |
| /ɜː/ | اِ/ار کشیده | bird |
| /ɑː/ | آ کشیده | car |
| /ɔː/ | اُ کشیده | door |
| /ʊ/ | او کوتاه | book |
| /uː/ | او کشیده | food |

علامت `/ˈ/` هم خیلی مهم است:  
قبل از هجایی می‌آید که باید **قوی‌تر و بلندتر** گفته شود.

مثلاً:
- `appointment` = **uh-POYNT-muhnt** = تکیه روی POYNT
- `prescription` = **pri-SKRIP-shuhn** = تکیه روی SKRIP
- `queue` = **kyoo** = کیو
- `sink` = **singk** = سینگک

از این به بعد لازم نیست IPA را تنها بخوانی. من همیشه کنارش تلفظ ساده می‌نویسم. اگر خواستی، کم‌کم یک دوره کوچک IPA هم با هم کار می‌کنیم.

برای شروع، این ۵ کلمه را ببین. فقط بنویس:

1. معنی فارسی‌شان چیست؟
2. با هرکدام یک جمله ساده انگلیسی بساز.

- receipt = **ri-SEET**
- queue = **kyoo**
- appointment = **uh-POYNT-muhnt**
- prescription = **pri-SKRIP-shuhn**
- sink = **singk**
