# جلسه ۴: جلوه‌ها و انیمیشن‌ها (Effects & Animations)

## 🎯 اهداف این جلسه
- نمایش و مخفی‌سازی با `hide()`، `show()`، `toggle()`
- محو شدن با `fadeIn()`، `fadeOut()`، `fadeToggle()`، `fadeTo()`
- لغزش با `slideDown()`، `slideUp()`، `slideToggle()`
- انیمیشن سفارشی با `animate()`
- مدیریت صف انیمیشن با `stop()` و `delay()`
- توابع callback در انیمیشن‌ها

---

## ۱. چرا انیمیشن؟
با انیمیشن می‌توانی تجربه کاربری بهتری بسازی: منوهای بازشو، پیام‌های ظاهر شونده، اسلایدر و… . jQuery این کار را با چند خط کد ممکن می‌کند.

---

## ۲. نمایش و مخفی‌سازی

```javascript
$("#box").hide();       // مخفی کن
$("#box").show();       // نمایش بده
$("#box").toggle();     // جابه‌جا کن (اگر پیدا بود مخفی، اگر مخفی بود نمایش)
```

### با سرعت و callback
```javascript
$("#box").hide(500);                     // ۵۰۰ میلی‌ثانیه
$("#box").show("slow");                  // slow = ۶۰۰ms، fast = ۲۰۰ms
$("#box").toggle(400, function() {
  console.log("انیمیشن تمام شد");
});
```

**مثال کامل:**
```html
<button id="toggleBtn">نمایش/مخفی</button>
<div id="box" style="width:150px;height:100px;background:tomato;">جعبه</div>

<script>
$(function() {
  $("#toggleBtn").on("click", function() {
    $("#box").toggle("slow");
  });
});
</script>
```

---

## ۳. محو شدن (Fading)

```javascript
$("#box").fadeIn(600);      // از شفاف به کامل
$("#box").fadeOut(600);     // از کامل به شفاف
$("#box").fadeToggle(600);  // جابه‌جا
$("#box").fadeTo(600, 0.4); // به شفافیت مشخص (0 تا 1)
```

**تفاوت `hide/show` با `fade`:**  
`hide/show` هم ارتفاع و عرض را تغییر می‌دهد (عنصر جمع می‌شود)، اما `fade` فقط شفافیت را تغییر می‌دهد و **جای عنصر حفظ می‌شود**.

---

## ۴. لغزش (Sliding)

```javascript
$("#panel").slideDown(500);   // باز شدن از بالا به پایین
$("#panel").slideUp(500);     // بسته شدن
$("#panel").slideToggle(500); // جابه‌جا
```

**مثال کاربردی: آکاردئون ساده**
```html
<button class="acc">بخش ۱</button>
<div class="content">محتوای بخش ۱</div>
<button class="acc">بخش ۲</button>
<div class="content">محتوای بخش ۲</div>

<script>
$(function() {
  $(".acc").on("click", function() {
    $(this).next(".content").slideToggle(300);
  });
});
</script>
```

---

## ۵. انیمیشن سفارشی با `animate()`

متد `animate()` به تو اجازه می‌دهد هر ویژگی CSS عددی را انیمیت کنی:

```javascript
$("#box").animate({
  width: "300px",
  height: "200px",
  opacity: 0.5
}, 800);
```

### پارامترهای animate
```javascript
$(selector).animate(properties, duration, easing, callback);
```
- `properties` → ویژگی‌های CSS (با مقادیر عددی)
- `duration` → مدت (میلی‌ثانیه یا "slow"/"fast")
- `easing` → نوع حرکت: `"swing"` (پیش‌فرض) یا `"linear"`
- `callback` → تابعی که پس از پایان اجرا می‌شود

### مقادیر نسبی
```javascript
$("#box").animate({ left: "+=100px" }, 500);   // ۱۰۰px به چپ فعلی اضافه کن
$("#box").animate({ left: "-=50px" }, 500);    // ۵۰px کم کن
```

**مثال: حرکت جعبه با کلیک**
```html
<button id="move">حرکت</button>
<div id="box" style="width:80px;height:80px;background:steelblue;position:relative;"></div>

<script>
$(function() {
  $("#move").on("click", function() {
    $("#box").animate({ left: "+=120px" }, 400);
  });
});
</script>
```

### زنجیره‌سازی انیمیشن (Queue)
انیمیشن‌ها به صورت صف اجرا می‌شوند:
```javascript
$("#box")
  .animate({ left: "200px" }, 500)
  .animate({ top: "150px" }, 500)
  .animate({ opacity: 0.3 }, 500);
```

---

## ۶. کنترل صف انیمیشن

### `stop()` — توقف انیمیشن جاری
```javascript
$("#box").stop();          // انیمیشن جاری متوقف می‌شود
$("#box").stop(true);      // صف را پاک کن
$("#box").stop(true, true); // صف را پاک کن و به حالت نهایی برو
```
💡 در دکمه‌های toggle، قبل از شروع انیمیشن جدید `stop()` بزن تا انیمیشن‌ها روی هم انبار نشوند:
```javascript
$("#toggleBtn").on("click", function() {
  $("#box").stop().slideToggle(400);
});
```

### `delay()` — تأخیر
```javascript
$("#box").slideUp(300).delay(800).slideDown(300);
```

---

## ۷. Callback و Promise در انیمیشن

### Callback سنتی
```javascript
$("#box").fadeOut(600, function() {
  $(this).text("مخفی شدم!").fadeIn(600);
});
```

### روش مدرن با `promise()`
```javascript
$("#box").fadeOut(600).promise().done(function() {
  console.log("انیمیشن تمام شد");
});
```

---

## ۸. نکته‌های کلیدی
- انیمیشن‌ها به صورت **صف** اجرا می‌شوند.
- قبل از toggleهای سریع، از `stop()` استفاده کن.
- `animate()` فقط ویژگی‌های **عددی** را پشتیبانی می‌کند (مثل `width`, `opacity`, `left`)؛ رنگ‌ها را نمی‌تواند انیمیت کند مگر با پلاگین.
- برای انیمیشن‌های پیچیده، CSS Transitions/Animations گاهی بهتر و سریع‌تر از jQuery هستند.

## ✍️ تمرین این جلسه
1. یک دکمه بساز که با کلیک، یک جعبه را با `fadeToggle` نمایش/مخفی کند.
2. دو دکمه بساز: «باز کردن» و «بستن» که پنلی را با `slideDown` و `slideUp` کنترل کنند.
3. جعبه‌ای بساز که با کلیک، به اندازه ۱۰۰px به راست و بالا حرکت کند (با `animate`).
4. یک انیمیشن زنجیره‌ای بساز: جعبه اول کوچک شود، بعد شفاف شود، بعد مخفی شود.

## 📝 تکلیف
یک **منوی کشویی (Dropdown)** بساز:
- یک دکمه «منو»
- یک لیست زیر آن
- با کلیک روی دکمه، لیست با `slideToggle` باز/بسته شود
- از `stop()` استفاده کن تا کلیک‌های سریع باعث باگ نشوند
