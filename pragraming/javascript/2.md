## 1. Arrays

An ordered list of values.

```js
const fruits = ["apple", "banana", "cherry"];

fruits[0];          // "apple"  (zero-indexed)
fruits.length;      // 3
fruits.push("date");  // add to end → ["apple","banana","cherry","date"]
fruits.pop();       // remove from end → "date"
fruits.unshift("kiwi"); // add to start
fruits.shift();     // remove from start
fruits.includes("banana"); // true
fruits.indexOf("cherry");  // 2
```

**Slicing vs splicing** (common confusion):

```js
const nums = [1, 2, 3, 4, 5];
nums.slice(1, 3);   // [2, 3]   — returns copy, original unchanged
nums.splice(1, 2);  // [2, 3]   — MUTATES original → [1, 4, 5]
```

### The array methods you'll use daily

```js
const nums = [1, 2, 3, 4, 5];

nums.map(n => n * 2);          // [2, 4, 6, 8, 10]  — transform each
nums.filter(n => n % 2 === 0); // [2, 4]            — keep matching
nums.reduce((sum, n) => sum + n, 0); // 15          — collapse to one value
nums.find(n => n > 3);         // 4                 — first match
nums.some(n => n > 4);         // true              — any match?
nums.every(n => n > 0);        // true              — all match?
nums.sort((a, b) => b - a);    // [5,4,3,2,1]       — sort (note the comparator!)
```

**This trio — `map`, `filter`, `reduce` — is the heart of modern JS.** Master them.

## 2. Objects

A collection of key–value pairs. The other fundamental data structure.

```js
const user = {
  name: "Sam",
  age: 25,
  greet() { return `Hi, I'm ${this.name}`; }
};

user.name;       // "Sam"  (dot notation)
user["age"];     // 25     (bracket notation — use when key is dynamic)
user.greet();    // "Hi, I'm Sam"

user.email = "sam@x.com";  // add property
delete user.age;            // remove property
```

**Destructuring** — extract values cleanly:

```js
const { name, age } = user;          // name = "Sam", age = 25
const { name: userName } = user;     // rename → userName = "Sam"
```

**Spread** — copy/merge:

```js
const updated = { ...user, age: 26 };  // new object, age overridden
const copy = { ...user };              // shallow copy
const combined = [...arr1, ...arr2];   // array merge
```

**Iterating objects:**

```js
Object.keys(user);   // ["name", "age", ...]
Object.values(user); // ["Sam", 25, ...]
Object.entries(user); // [["name","Sam"], ["age",25], ...]

for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
```

## 3. Scope

Where a variable is *visible*.

```js
let global = "I'm everywhere";

function outer() {
  let outerVar = "visible inside outer";

  function inner() {
    let innerVar = "only here";
    console.log(global);    // ✅
    console.log(outerVar);  // ✅
  }

  // console.log(innerVar); // ❌ error — not in scope
}
```

**Two rules to remember:**

1. **`let`/`const` are block-scoped** — they live inside the nearest `{ }`.
2. **`var` is function-scoped and hoisted** — another reason to avoid it.

```js
{
  let blockVar = "inside";
}
// console.log(blockVar); // ❌ ReferenceError
```

## 4. Closures ⭐ (the big one)

**A closure is a function that remembers the variables from where it was created — even after that outer function has returned.**

```js
function makeCounter() {
  let count = 0;            // "private" variable

  return function () {      // inner function closes over `count`
    count++;
    return count;
  };
}

const counter = makeCounter();
counter(); // 1
counter(); // 2
counter(); // 3
```

`makeCounter()` has finished running — yet `count` still exists, because the returned function **closed over** it.

**Why it matters:** closures power private state, callbacks, event handlers, partial application, and modules.

```js
// Practical example: a "multiplier factory"
const multiplyBy = n => x => x * n;

const double = multiplyBy(2);
const triple = multiplyBy(3);

double(5); // 10
triple(5); // 15
```

## 5. Higher-Order Functions

A function that **takes a function as an argument** or **returns a function**. You've already used them — `map`, `filter`, `reduce` all take callbacks.

```js
function repeat(n, action) {
  for (let i = 0; i < n; i++) action(i);
}

repeat(3, i => console.log(`Step ${i}`));
// Step 0
// Step 1
// Step 2
```

**Callback:** a function passed to another function to be called later.

```js
setTimeout(() => console.log("2 seconds later"), 2000);
```

## 6. ES6+ Syntax Cheat Sheet

```js
// Template literals
const msg = `Hello ${name}, you are ${age}`;

// Arrow functions — concise, and inherit `this`
const square = x => x * x;
const obj = () => ({ a: 1 }); // wrap object return in ()

// Default params
function greet(name = "friend") { /* ... */ }

// Rest params — collect remaining args into an array
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3); // 6

// Spread — expand an array into arguments
Math.max(...[1, 5, 3]); // 5

// Optional chaining — safe access, no crashes
const city = user?.address?.city; // undefined instead of error

// Nullish coalescing — default only if null/undefined
const port = config.port ?? 3000;

// Short-circuit default (older style)
const label = value || "default"; // falsy triggers default (careful with 0, "")
```

## 7. The DOM & Events

The DOM is the browser's object model of the HTML page. JavaScript manipulates the page through it.

```html
<button id="btn">Click me</button>
<ul id="list"></ul>
```

```js
// Select
const btn = document.getElementById("btn");
const list = document.querySelector("#list");        // first match
const all = document.querySelectorAll(".item");      // all matches

// Change
btn.textContent = "Clicked!";
btn.style.color = "white";
btn.classList.add("active");

// Create & insert
const li = document.createElement("li");
li.textContent = "New item";
list.appendChild(li);

// Events
btn.addEventListener("click", (event) => {
  console.log("Button clicked!", event.target);
});

// Input events
const input = document.querySelector("input");
input.addEventListener("input", e => {
  console.log("Typing:", e.target.value);
});
```

**Tiny working example** — a to-do app core:

```js
const input = document.querySelector("#newTodo");
const list  = document.querySelector("#list");

input.addEventListener("keydown", e => {
  if (e.key === "Enter" && input.value.trim()) {
    const li = document.createElement("li");
    li.textContent = input.value;
    list.appendChild(li);
    input.value = "";
  }
});
```
