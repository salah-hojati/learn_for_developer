## نقشه راه ۵ جلسه‌ای

1. **جلسه ۱:** پایه‌ها — عنوان، پاراگراف، تأکید، لیست، لینک، نقل‌قول
2. **جلسه ۲:** ساختار سند — سرفصل‌بندی، جدول، خط جداکننده، تصویر، فهرست مطالب
3. **جلسه ۳:** کد و بلوک‌های کد، چک‌لیست، پانویس، لینک داخلی
4. **جلسه ۴:** اسناد حرفه‌ای — Front Matter، مسیر فایل‌ها، Badge، تنظیمات RTL
5. **جلسه ۵:** پروژه عملی + بهترین شیوه‌ها و اشتباهات رایج

# جلسه ۱: شروع سریع Markdown

Markdown یک زبان نشانه‌گذاری ساده است که با آن می‌توانی متن را ساختاردهی کنی. فایل‌های Markdown معمولاً پسوند `.md` دارند، مثل:

```text
docs/guide.md
README.md
```

## ۱. عنوان‌ها

با `#` عنوان می‌سازی. تعداد `#` سطح عنوان را مشخص می‌کند:

```markdown
# عنوان اصلی
## عنوان دوم
### عنوان سوم
#### عنوان چهارم
```

معمولاً در هر سند فقط **یک** عنوان سطح ۱ (`#`) استفاده می‌کنیم.

## ۲. پاراگراف

برای ساختن پاراگراف جدید، بین دو پاراگراف **یک خط خالی** بگذار:

```markdown
این پاراگراف اول است.

این پاراگراف دوم است.
```

## ۳. تأکید روی متن

```markdown
**متن پررنگ**
*متن کج*
~~متن خط‌خورده~~
```

خروجی: **متن پررنگ**، *متن کج*، ~~متن خط‌خورده~~

## ۴. لیست‌ها

لیست نشانه‌دار:

```markdown
- آیتم اول
- آیتم دوم
  - زیرآیتم
```

لیست شماره‌دار:

```markdown
1. مرحله اول
2. مرحله دوم
3. مرحله سوم
```

## ۵. لینک

```markdown
[متن لینک](https://example.com)
```

مثال:

```markdown
[مستندات Markdown در GitHub](https://docs.github.com/en/get-started/writing-on-github)
```

## ۶. نقل‌قول

```markdown
> این یک نقل‌قول است.
> می‌تواند چند خط باشد.
```

## ۷. خط جداکننده

```markdown
---
```

## ۸. کد درون‌خطی

اگر می‌خواهی یک عبارت کوتاه را به شکل کد نشان دهی:

```markdown
دستور `npm install` را اجرا کن.
```

خروجی: دستور `npm install` را اجرا کن.

## تمرین جلسه ۱

یک فایل به نام `about-me.md` بساز و این موارد را در آن بنویس:

1. یک عنوان اصلی
2. دو پاراگراف درباره خودت
3. یک لیست از مهارت‌هایت
4. یک لیست شماره‌دار از اهدافت
5. یک لینک به یک سایت مورد علاقه‌ات
6. یک نقل‌قول
7. یک خط جداکننده

---

**نکته مهم برای اسناد فارسی:** Markdown خودش زبان راست‌به‌چپ را نمی‌شناسد. در VS Code می‌توانی از افزونه‌هایی مثل **Markdown Preview Enhanced** یا تنظیم RTL ویرایشگر استفاده کنی. در GitHub و Obsidian هم بسته به تنظیمات، پیش‌نمایش فارسی قابل تنظیم است.

اگر آماده‌ای، بگو **«جلسه ۲»** تا برویم سراغ جدول، تصویر، فهرست مطالب و ساختاردهی حرفه‌ای اسناد.
