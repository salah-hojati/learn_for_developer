## تعریف ساده رندر

**رندر (Render)** = تبدیل داده/داده‌ی خام به **خروجی قابل نمایش** (HTML، DOM، پیکسل روی صفحه و…).

نکته‌ی کلیدی: رندر یک **مفهوم** است، نه یک مکان. هر جایی که «داده → نمایش» اتفاق بیفتد، همان‌جا رندر انجام شده است. پس هم سمت سرور رندر داریم، هم سمت مرورگر.

---

## ۱) رندر سمت سرور (SSR — Server-Side Rendering)

سرور داده را می‌گیرد و **HTML آماده** می‌سازد، بعد به مرورگر می‌فرستد.

```
داده (DB) → سرور → HTML نهایی → مرورگر فقط نشان می‌دهد
```

مثال‌ها:
- PHP / ASP.NET / JSP / Django / Rails که HTML برمی‌گردانند
- `res.render('index', { user })` در Express
- Next.js / Nuxt در حالت SSR

اینجا **رندر روی سرور** انجام شده؛ مرورگر تقریباً فقط نمایش می‌دهد.

---

## ۲) رندر سمت کلاینت (CSR — Client-Side Rendering)

سرور فقط داده‌ی خام (JSON) یا یک پوسته‌ی خالی HTML می‌دهد؛ **مرورگر** با JavaScript DOM می‌سازد.

```
داده (JSON) → مرورگر → JS → DOM/HTML → نمایش
```

مثال‌ها:
- React / Vue / Angular / Svelte
- jQuery که با `.append()` / `.html()` عنصر می‌سازد

اینجا **رندر روی مرورگر (کلاینت)** انجام شده.

---

## ۳) حالا سؤال اصلی: آیا کارِ AJAX «رندر» است؟

**بستگی دارد به این که AJAX چه کاری می‌کند.** AJAX خودش فقط «درخواست بدون رفرش» است. دو حالت:

### حالت الف) AJAX فقط داده می‌آورد → رندر نیست
```js
$.ajax({ url: '/api/users', success: function (data) {
  // data فقط JSON است، هنوز چیزی روی صفحه نیست
}});
```
این **دریافت داده** است، نه رندر. (شبیه Fetch است.)

### حالت ب) AJAX داده می‌آورد و با آن DOM می‌سازد → رندر است
```js
$.ajax({ url: '/api/users', success: function (data) {
  var html = '';
  for (var i = 0; i < data.length; i++) {
    html += '<li>' + data[i].name + '</li>';
  }
  $('#list').html(html);   // ← اینجا رندر کلاینتی اتفاق افتاد
}});
```

**پس:** خودِ «درخواست AJAX» رندر نیست؛ اما **پردازش نتیجه و ساختن DOM از آن** یک نوع **رندر سمت کلاینت** است.

### حالت ج) AJAX قطعه‌ی HTML آماده می‌گیرد → رندر روی سرور بوده
```js
$.ajax({ url: '/partials/user-row', success: function (htmlChunk) {
  $('#list').append(htmlChunk);   // سرور HTML را رندر کرده، مرورگر فقط جاگذاری می‌کند
}});
```
اینجا **رندر روی سرور** انجام شده و AJAX فقط آن را منتقل (و تزریق) کرده.

## جمع‌بندی به زبان ساده

| سناریو | رندر کجاست؟ | AJAX رندر است؟ |
|---|---|---|
| سرور HTML کامل می‌فرستد | سرور | — |
| AJAX فقط JSON می‌آورد | هیچ‌جا (هنوز نه) | ❌ نه |
| AJAX JSON می‌آورد + JS آن را به DOM تبدیل می‌کند | کلاینت | ✅ بله (رندر کلاینتی) |
| AJAX قطعه‌ی HTML آماده می‌آورد | سرور (قبلاً) | ⚠️ فقط تزریق، نه رندر اصلی |

**قاعده‌ی طلایی:** هر جا **داده به نمایش تبدیل شود** = رندر. AJAX فقط «لوله‌ی انتقال» است؛ اگر بعد از آن DOM ساخته شود، آن بخشِ کار رندر کلاینتی محسوب می‌شود، ولی خودِ AJAX به‌تنهایی رندر نیست.
