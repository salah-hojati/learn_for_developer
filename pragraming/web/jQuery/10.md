# جلسه ۱۰: jQuery در برابر JavaScript مدرن + بهینه‌سازی

## 🎯 اهداف این جلسه
- پاسخ به این سؤال مهم: **آیا هنوز باید jQuery یاد بگیریم و استفاده کنیم؟**
- مقایسه گام‌به‌گام jQuery با **Vanilla JS** (جاوااسکریپت خالص مدرن)
- یادگیری تکنیک‌های **بهینه‌سازی (Performance)** در jQuery
- مسیر **مهاجرت تدریجی** از jQuery به JavaScript مدرن
- تصمیم درست برای پروژه‌های آینده

---

## ۱. جایی که هستیم: چرا این جلسه مهم است؟

در ۹ جلسه گذشته jQuery را کامل یاد گرفتی. اما در سال‌های اخیر، مرورگرها بسیار قدرتمند شده‌اند و بسیاری از کارهایی که قبلاً فقط با jQuery راحت بود، حالا با **JavaScript خالص** هم به‌سادگی انجام می‌شود.

مهم است بدانی:
- **کجا jQuery هنوز بهترین انتخاب است**
- **کجا JavaScript مدرن برنده است**
- **چطور کدهای قدیمی را مدرن کنی**

این جلسه به تو دیدِ حرفه‌ای می‌دهد تا در مصاحبه‌ها و پروژه‌ها تصمیم درست بگیری.

## ۲. مزایا و معایب jQuery (خلاصه صادقانه)

### ✅ نقاط قوت jQuery
- **سینتکس کوتاه و خوانا** برای کارهای رایج
- **سازگاری عالی با مرورگرهای قدیمی** (IE9+)
- **اکوسیستم بزرگ پلاگین‌ها** (اسلایدر، تاریخ‌شمار، جدول و…)
- **AJAX ساده** با مدیریت خطا
- **انتخابگرهای قدرتمند** با فیلترهای پیشرفته
- **برای نگهداری پروژه‌های قدیمی** هنوز ضروری است

### ❌ نقاط ضعف jQuery
- **حجم اضافی** (نزدیک ۳۰KB فشرده، برای پروژه‌های کوچک سنگین است)
- **موتور رندر مجزا** از React/Vue/Angular (در این فریم‌ورک‌ها معمولاً لازم نیست)
- **جاوااسکریپت مدرن** همان کارها را بومی انجام می‌دهد
- **DOM دستکاری مستقیم** در اپلیکیشن‌های بزرگ باعث پیچیدگی می‌شود
- **یادگیری** آن وقت می‌گیرد که شاید بهتر باشد روی JS مدرن سرمایه‌گذاری کنی

### 🎯 نتیجه‌گیری
| سناریو | توصیه |
|---|---|
| پروژه کوچک/متوسط با صفحه‌های HTML ساده | jQuery هنوز عالی است |
| نگهداری پروژه قدیمی که از قبل jQuery دارد | بمان با jQuery |
| پروژه جدید با React/Vue/Angular | jQuery لازم نیست |
| پروژه مدرن بدون فریم‌ورک | Vanilla JS گزینه بهتر |
| تیم مسن‌تر / پروژه شرکتی قدیمی | jQuery قابل اعتماد است |
| یادگیری برای مصاحبه | **هر دو** را بدان |

## ۳. مقایسه گام‌به‌گام: jQuery vs Vanilla JS

### ۳.۱ انتخاب عناصر

```javascript
// jQuery
$("#title").text("سلام");
$(".item").addClass("active");
$("li").hide();
```

```javascript
// Vanilla JS
document.querySelector("#title").textContent = "سلام";
document.querySelectorAll(".item").forEach(el => el.classList.add("active"));
document.querySelectorAll("li").forEach(el => el.style.display = "none");
```

| تفاوت | jQuery | Vanilla |
|---|---|---|
| انتخاب تک | `$("#id")` | `document.querySelector()` |
| انتخاب چندتایی | `$(".class")` | `document.querySelectorAll()` |
| اجرای حلقه | خودکار | نیاز به `forEach` |

---

### ۳.۲ رویدادها

```javascript
// jQuery
$("#btn").on("click", function() {
  console.log("کلیک شد");
});
```

```javascript
// Vanilla JS
document.querySelector("#btn").addEventListener("click", () => {
  console.log("کلیک شد");
});
```

### تفویض رویداد (Delegation)

```javascript
// jQuery
$("#list").on("click", "li", function() {
  $(this).toggleClass("done");
});
```

```javascript
// Vanilla JS
document.querySelector("#list").addEventListener("click", function(e) {
  if (e.target.matches("li")) {
    e.target.classList.toggle("done");
  }
});
```
Vanilla کمی طولانی‌تر است اما با `matches()` همان کار را می‌کند.

---

### ۳.۳ دستکاری کلاس‌ها

```javascript
// jQuery
$("#box").addClass("active");
$("#box").removeClass("active");
$("#box").toggleClass("active");
$("#box").hasClass("active");
```

```javascript
// Vanilla JS
const box = document.querySelector("#box");
box.classList.add("active");
box.classList.remove("active");
box.classList.toggle("active");
box.classList.contains("active");
```

---

### ۳.۴ محتوا

```javascript
// jQuery
$("#box").text("متن");           // خواندن/نوشتن متن
$("#box").html("<b>بولد</b>");   // خواندن/نوشتن HTML
$("#input").val("مقدار");        // خواندن/نوشتن مقدار
```

```javascript
// Vanilla JS
const box = document.querySelector("#box");
box.textContent = "متن";
box.innerHTML = "<b>بولد</b>";

const input = document.querySelector("#input");
input.value = "مقدار";
```

---

### ۳.۵ استایل

```javascript
// jQuery
$("#box").css("color", "red");
$("#box").css({ color: "red", fontSize: "20px" });
```

```javascript
// Vanilla JS
const box = document.querySelector("#box");
box.style.color = "red";
box.style.fontSize = "20px";    // نام‌ها camelCase هستند
```

---

### ۳.۶ ویژگی‌ها (Attributes)

```javascript
// jQuery
$("#link").attr("href", "/new");
$("#check").prop("checked", true);
```

```javascript
// Vanilla JS
document.querySelector("#link").setAttribute("href", "/new");
document.querySelector("#check").checked = true;    // برای checked/disabled مستقیم
```

---

### ۳.۷ ساخت و افزودن عنصر

```javascript
// jQuery
var $li = $("<li>").text("آیتم جدید");
$("#list").append($li);
```

```javascript
// Vanilla JS
const li = document.createElement("li");
li.textContent = "آیتم جدید";
document.querySelector("#list").appendChild(li);
```

---

### ۳.۸ AJAX

```javascript
// jQuery
$.getJSON("/api/users")
  .then(data => console.log(data))
  .catch(err => console.error(err));
```

```javascript
// Vanilla JS — Fetch API
fetch("/api/users")
  .then(res => {
    if (!res.ok) throw new Error("HTTP " + res.status);
    return res.json();
  })
  .then(data => console.log(data))
  .catch(err => console.error(err));
```

### حتی بهتر: `async/await`

```javascript
// Vanilla JS مدرن
async function loadUsers() {
  try {
    const res = await fetch("/api/users");
    if (!res.ok) throw new Error("HTTP " + res.status);
    const users = await res.json();
    console.log(users);
  } catch (err) {
    console.error(err);
  }
}
```
`async/await` خواناترین شکل کار با درخواست‌های ناهمگام است.

---

### ۳.۹ انیمیشن

```javascript
// jQuery
$("#box").fadeOut(400).fadeIn(400);
$("#box").animate({ left: "100px" }, 500);
```

```javascript
// Vanilla JS با CSS Transitions
box.style.transition = "opacity 0.4s";
box.style.opacity = 0;

// یا با Web Animations API
box.animate(
  [{ opacity: 1 }, { opacity: 0 }],
  { duration: 400, fill: "forwards" }
);
```

انیمیشن‌های CSS معمولاً **سریع‌تر و نرم‌تر** از انیمیشن‌های jQuery هستند، چون روی thread رندر GPU اجرا می‌شوند.

### ۳.۱۰ جدول چیت‌شیت کامل

| کار | jQuery | Vanilla JS |
|---|---|---|
| انتخاب تک | `$("#x")` | `document.querySelector("#x")` |
| انتخاب چندگانه | `$(".x")` | `document.querySelectorAll(".x")` |
| رویداد | `.on("click", fn)` | `.addEventListener("click", fn)` |
| کلاس | `.addClass()` | `.classList.add()` |
| متن | `.text()` | `.textContent` |
| HTML | `.html()` | `.innerHTML` |
| مقدار | `.val()` | `.value` |
| استایل | `.css()` | `.style.prop` |
| ویژگی | `.attr()` | `.setAttribute()` |
| ساخت عنصر | `$("<li>")` | `document.createElement("li")` |
| افزودن | `.append()` | `.appendChild()` / `.append()` |
| حذف | `.remove()` | `.remove()` |
| AJAX | `$.ajax` / `$.getJSON` | `fetch()` |
| انیمیشن | `.animate()` | CSS Transition / Web Animations |
| Promise | `$.Deferred()` | `Promise` / `async-await` |

## ۴. بهینه‌سازی (Performance) در jQuery

اگر jQuery استفاده می‌کنی، این نکات سرعت را چند برابر می‌کند.

### ۴.۱ انتخابگرها را Cache کن
```javascript
// ❌ هر خط یک جستجوی DOM جدید
$("#list").addClass("a");
$("#list").find("li").addClass("b");
$("#list").show();

// ✅ یک بار انتخاب
var $list = $("#list");
$list.addClass("a");
$list.find("li").addClass("b");
$list.show();
```

### ۴.۲ انتخابگر سمت چپ را دقیق‌تر کن
```javascript
// ❌ کند: همه liهای صفحه جستجو می‌شوند
$("li.active");

// ✅ سریع: محدوده را کوچک کن
$("#menu").find("li.active");
// یا
$("#menu li.active");
```

### ۴.۳ از `id` استفاده کن وقتی ممکن است
جستجوی `#id` سریع‌ترین حالت است چون مرورگر مستقیم به `getElementById` نگاشت می‌کند.

### ۴.۴ عناصری که مخفی هستند را مخفی نگه دار
اگر روی ۱۰۰۰ عنصر مخفی عملیات DOM انجام دهی، مرورگر مرتب Reflow می‌کند:
```javascript
// ✅ سریع‌تر
var $container = $("#container").hide();
$container.find(".item").addClass("active").end().show();
```

### ۴.۵ به‌جای `css()` در حلقه، کلاس بده
```javascript
// ❌ کند: هر عنصر یک استایل جدا
$("li").each(function() {
  $(this).css("color", "red");
});

// ✅ سریع: یک کلاس برای همه
$("li").addClass("red");
```
(و CSS جداست: `.red { color: red; }`)

### ۴.۶ از `document fragment` برای افزودن دسته‌ای استفاده کن
```javascript
// ❌ کند: هر آیتم یک بار Reflow
for (var i = 0; i < 100; i++) {
  $("#list").append("<li>آیتم " + i + "</li>");
}

// ✅ سریع: یک بار append
var html = "";
for (var i = 0; i < 100; i++) {
  html += "<li>آیتم " + i + "</li>";
}
$("#list").append(html);
```

### ۴.۷ انیمیشن‌ها را `stop()` کن
```javascript
$("#btn").on("click", function() {
  $("#box").stop().slideToggle(300);   // ✅ جلوگیری از صف انیمیشن
});
```

### ۴.۸ به‌جای `$(this)` مکرر، یک بار بگیر
```javascript
// ❌
$(".item").on("click", function() {
  $(this).addClass("a");
  $(this).removeClass("b");
  $(this).text("کلیک");
});

// ✅
$(".item").on("click", function() {
  var $this = $(this);
  $this.addClass("a").removeClass("b").text("کلیک");
});
```

### ۴.۹ از `delegation` برای عناصر زیاد استفاده کن
به‌جای بستن رویداد روی ۱۰۰۰ `li`، روی والد ببند (جلسه ۳).

## ۵. مسیر مهاجرت تدریجی به Vanilla JS

اگر پروژه‌ای داری که می‌خواهی از jQuery جدا کنی:

### گام ۱: شناسایی نقاط پرمصرف
جستجو کن کدام APIهای jQuery بیشتر استفاده می‌شوند. معمولاً ۹۰٪ کارها این چندتا هستند:
- `$()` انتخاب
- `.on()` رویداد
- `.addClass/removeClass/toggleClass`
- `.text` / `.html` / `.val`
- `$.ajax` / `$.getJSON`

### گام ۲: یک helper کوچک بساز
```javascript
// به‌جای jQuery، یک wrapper ساده
const $ = (sel, root = document) => root.querySelector(sel);
const $$ = (sel, root = document) => [...root.querySelectorAll(sel)];

const on = (el, ev, fn) => el.addEventListener(ev, fn);
```

### گام ۳: یکی‌یکی جایگزین کن
مثلاً `$("#btn").on("click", ...)` را تبدیل کن به:
```javascript
document.querySelector("#btn").addEventListener("click", ...);
```

### گام ۴: AJAX را به Fetch منتقل کن
```javascript
// قبل
$.getJSON("/api/users", data => render(data));

// بعد
fetch("/api/users").then(r => r.json()).then(render);
```

### گام ۵: انیمیشن‌ها را به CSS منتقل کن
از `.animate()` به `transition` / `animation` برو.

### گام ۶: تست کن
هر بار یک بخش کوچک را تبدیل کن و کامل تست کن، بعد سراغ بخش بعدی.

## ۶. جدول تصمیم نهایی

| سؤال | اگر پاسخ «بله» | انتخاب |
|---|---|---|
| پروژه جدید و مدرن است؟ | بله | Vanilla JS یا فریم‌ورک (React/Vue) |
| پروژه قدیمی با jQuery کار می‌کند؟ | بله | دست نزن، بهبود بده |
| تیم فقط jQuery می‌داند؟ | بله | با jQuery ادامه بده |
| فقط یک صفحه ساده داری (اسلایدر، فرم)؟ | بله | jQuery منطقی است |
| به دنبال شغل مدرن هستی؟ | بله | Vanilla JS + فریم‌ورک |  
| به دنبال شغل نگهداری/پروژه‌های قدیمی هستی؟ | بله | jQuery دانش ضروری است |

**جمع‌بندی منصفانه:** بهترین حالت این است که **هر دو** را بلد باشی. jQuery برای نگهداری و پروژه‌های کوچک، Vanilla JS مدرن برای پروژه‌های جدید.

## ۷. مثال کامل: یک کار در دو نسخه

### نسخه jQuery (اسلایدر ساده)
```javascript
$(function() {
  var $slides = $(".slide");
  var i = 0;

  function show(n) {
    $slides.removeClass("active").eq(n).addClass("active");
  }

  $(".next").on("click", function() {
    i = (i + 1) % $slides.length;
    show(i);
  });

  show(0);
});
```

### نسخه Vanilla JS
```javascript
document.addEventListener("DOMContentLoaded", () => {
  const slides = document.querySelectorAll(".slide");
  let i = 0;

  function show(n) {
    slides.forEach((el, idx) => {
      el.classList.toggle("active", idx === n);
    });
  }

  document.querySelector(".next").addEventListener("click", () => {
    i = (i + 1) % slides.length;
    show(i);
  });

  show(0);
});
```
تفاوت کد اندک است؛ فقط سینتکس تغییر می‌کند. **منطق یکی است.**

## ۸. نکته‌های کلیدی این جلسه

- jQuery هنوز زنده است و در پروژه‌های واقعی زیاد دیده می‌شود.
- **Vanilla JS مدرن** برای پروژه‌های جدید معمولاً سریع‌تر، سبک‌تر و پایدارتر است.
- **انتخابگرها**، **رویدادها**، **کلاس‌ها**، **محتوا**، **AJAX** — همه معادل بومی دارند.
- برای پروژه‌های بزرگ بدون فریم‌ورک، Vanilla JS انتخاب حرفه‌ای است.
- برای نگهداری و پروژه‌های کوچک، jQuery هنوز عالی است.
- **بهترین کار: هر دو را بلد باش.**

## ✍️ تمرین این جلسه

1. کد زیر را از jQuery به Vanilla JS تبدیل کن:
   ```javascript
   $(function() {
     $("#btn").on("click", function() {
       $("#box").toggleClass("active").text("کلیک شد");
     });
   });
   ```

2. لیست زیر را با Vanilla JS بازنویسی کن (رویداد + کلاس):
   ```javascript
   $("#list").on("click", "li", function() {
     $(this).toggleClass("done");
   });
   ```

3. یک درخواست `$.getJSON` را به `fetch` + `async/await` تبدیل کن که خطا را با try/catch مدیریت کند.

4. در کد اسلایدر نسخه jQuery، حداقل **سه** بهبود عملکردی بر اساس بخش ۴ این جلسه اعمال کن و توضیح بده چرا سریع‌تر شده‌اند.
