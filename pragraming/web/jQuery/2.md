# جلسه ۲: انتخابگرها (Selectors) در jQuery

## 🎯 اهداف این جلسه
- انتخاب عناصر بر اساس **عنصر، کلاس و شناسه**
- انتخابگرهای ترکیبی و سلسله‌مراتبی
- انتخابگرهای موقعیت (`:first`، `:last`، `:even`، `:odd`)
- انتخابگرهای فرم
- ذخیره‌سازی انتخابگر (Caching) برای افزایش سرعت

---

## ۱. انتخابگر چیست؟
انتخابگر به jQuery می‌گوید **کدام عنصر(ها)** را هدف بگیرد. تقریباً مثل CSS عمل می‌کند، اما قدرت بیشتری دارد.
</div>

```javascript
$("p")        // همه پاراگراف‌ها
$(".box")     // همه عناصر با کلاس box
$("#header")  // عنصر با شناسه header
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
---

## ۲. انتخابگرهای پایه

### انتخاب بر اساس عنصر
</div>

```javascript
$("h1").css("color", "blue");   // همه h1ها آبی شوند
```

### انتخاب بر اساس کلاس
```javascript
$(".note").hide();   // همه عناصر با کلاس note مخفی شوند
```

### انتخاب بر اساس شناسه
```javascript
$("#title").text("متن جدید");
```
⚠️ شناسه در صفحه باید **یکتا** باشد.

### انتخابگر ستاره (همه عناصر)
```javascript
$("*")   // همه عناصر (کم استفاده است، سنگین است)
```

---

## ۳. انتخابگرهای ترکیبی و سلسله‌مراتبی

```javascript
$("div p")      // همه pهایی که داخل div هستند (هر عمقی)
$("div > p")    // فقط pهای فرزند مستقیم div
$("h2 + p")     // اولین p بلافاصله بعد از هر h2
$("h2 ~ p")     // همه pهای هم‌سطح بعد از h2
```

### انتخاب چندگانه با کاما
```javascript
$("h1, h2, .important")   // هر سه گروه را انتخاب می‌کند
```

---

## ۴. انتخابگرهای موقعیت (Position)

```javascript
$("li:first")    // اولین li
$("li:last")     // آخرین li
$("li:even")     // liهای با ایندکس زوج (۰،۲،۴...)
$("li:odd")      // liهای با ایندکس فرد (۱،۳،۵...)
$("li:eq(2)")    // li با ایندکس ۲ (سومین)
$("li:gt(1)")    // liهای با ایندکس بزرگ‌تر از ۱
$("li:lt(3)")    // liهای با ایندکس کوچک‌تر از ۳
```

**مثال کاربردی:** رنگ‌آمیزی راه‌راه یک جدول
```html
<ul id="list">
  <li>آیتم ۱</li>
  <li>آیتم ۲</li>
  <li>آیتم ۳</li>
  <li>آیتم ۴</li>
</ul>

<script>
$(function() {
  $("#list li:even").css("background", "#eee");
  $("#list li:odd").css("background", "#fff");
});
</script>
```

---

## ۵. انتخابگرهای فرم

```javascript
$(":input")      // همه ورودی‌ها (input، textarea، select، button)
$(":text")       // فقط inputهای متنی
$(":checkbox")   // چک‌باکس‌ها
$(":radio")      // رادیوها
$(":selected")   // گزینه انتخاب‌شده در select
$(":checked")    // چک‌باکس/رادیوهای تیک‌خورده
$(":disabled")   // غیرفعال‌ها
$(":enabled")    // فعال‌ها
```

**مثال:** گرفتن مقدار گزینه انتخاب‌شده
```html
<select id="city">
  <option value="tehran">تهران</option>
  <option value="shiraz">شیراز</option>
</select>
<button id="show">نمایش</button>
<p id="result"></p>

<script>
$(function() {
  $("#show").on("click", function() {
    var city = $("#city option:selected").val();
    $("#result").text("شهر انتخابی: " + city);
  });
});
</script>
```

**مثال:** شمارش چک‌باکس‌های تیک‌خورده
```javascript
var count = $(":checkbox:checked").length;
console.log("تعداد انتخاب‌شده: " + count);
```

## ۶. فیلتر کردن نتیجه انتخاب
گاهی بعد از انتخاب، می‌خواهیم نتیجه را محدودتر کنیم:

```javascript
$("li").filter(".active")   // فقط liهایی که کلاس active دارند
$("li").not(".active")      // liهایی که active ندارند
$("li").first()             // اولین li
$("li").last()              // آخرین li
$("li").eq(1)               // li با ایندکس ۱
```

## ۷. ذخیره‌سازی انتخابگر (Caching) — نکته مهم سرعت
اگر یک انتخابگر را چند بار استفاده می‌کنی، نتیجه را در متغیر ذخیره کن:
</div>


```javascript
// ❌ کند: هر بار DOM جستجو می‌شود
$("#list").addClass("active");
$("#list").css("color", "red");
$("#list").show();

// ✅ سریع: یک بار جستجو، چند بار استفاده
var $list = $("#list");
$list.addClass("active");
$list.css("color", "red");
$list.show();
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

💡 رسم است که متغیرهای jQuery را با `$` شروع کنیم (مثل `$list`).

---

## ۸. نکته‌های کلیدی
- انتخابگرها مثل CSS هستند اما قدرت بیشتری دارند.
- `:even` و `:odd` از **صفر** شروع می‌شوند (ایندکس ۰ زوج است).
- برای سرعت، انتخابگرها را cache کن.
- انتخابگر خیلی عمومی مثل `$("*")` سنگین است؛ کم استفاده کن.

## ✍️ تمرین این جلسه
1. یک لیست ۶ آیتمی بساز. آیتم‌های زوج را آبی و فرد را خاکستری کن.
2. یک فرم با ۳ چک‌باکس بساز و با کلیک روی دکمه، تعداد تیک‌خورده‌ها را نمایش بده.
3. سه پاراگراف بساز و فقط پاراگراف دوم را با `eq()` قرمز کن.

یک جدول ۵ ردیفی بساز و:

- با استفاده از `filter()`، ردیف‌هایی که کلاس `highlight` دارند را بولد کن.
