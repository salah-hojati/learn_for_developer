# جلسه ۹: پروژه‌های عملی (جمع‌بندی جلسات ۱ تا ۸)

## 🎯 اهداف این جلسه
در این جلسه همه مفاهیم قبلی را در قالب **سه پروژه کامل** به کار می‌گیریم:

1. **اسلایدر تصاویر** — انیمیشن + رویداد + پیمایش + زنجیره‌سازی
2. **اعتبارسنجی فرم** — رویدادها + `val()` + کلاس‌ها + `prop()`
3. **لیست کارها با AJAX** — دستکاری DOM + تفویض رویداد + AJAX + Promise

در پایان هر پروژه، بخش «چه چیزی از کدام جلسه استفاده شد» را می‌بینی تا اتصال مفاهیم را حس کنی.

```html
  $(function() {
    var $slides = $("#slider .slide");
    var $dots   = $("#slider .dots");
    var total   = $slides.length;
    var current = 0;
    var timer   = null;
    var AUTOPLAY = 4000;

    // ساخت نقطه‌های ناوبری بر اساس تعداد اسلایدها
    $slides.each(function(i) {
      $("<span>")
        .attr("data-index", i)
        .toggleClass("active", i === 0)
        .appendTo($dots);
    });

    function goTo(index) {
      // نرمال‌سازی ایندکس (چرخش دایره‌ای)
      current = (index + total) % total;

      $slides.removeClass("active").eq(current).addClass("active");
      $dots.find("span").removeClass("active").eq(current).addClass("active");
    }

    function next() { goTo(current + 1); }
    function prev() { goTo(current - 1); }

    function startAuto() {
      stopAuto();
      timer = setInterval(next, AUTOPLAY);
    }
    function stopAuto() {
      if (timer) { clearInterval(timer); timer = null; }
    }

    // رویداد دکمه‌ها
    $("#slider .next").on("click", function() { next(); startAuto(); });
    $("#slider .prev").on("click", function() { prev(); startAuto(); });

    // تفویض رویداد برای dots
    $dots.on("click", "span", function() {
      var i = $(this).data("index");
      goTo(i);
      startAuto();
    });

    // توقف هنگام hover (تجربه بهتر)
    $("#slider")
      .on("mouseenter", stopAuto)
      .on("mouseleave", startAuto);

    // پشتیبانی از کلیدهای جهت‌دار
    $(document).on("keydown", function(e) {
      if (e.key === "ArrowLeft")  { next(); startAuto(); }
      if (e.key === "ArrowRight") { prev(); startAuto(); }
    });

    startAuto();
  });
  </script>
</body>
</html>
```

## چه چیزی از کدام جلسه استفاده شد؟
| مفهوم | جلسه |
|---|---|
| `$(function(){})`، انتخابگرها | ۱ و ۲ |
| `on()`، `mouseenter`، `mouseleave`، تفویض رویداد | ۳ |
| `toggleClass`، `removeClass`، `addClass` | ۵ |
| `eq()`، `find()`، `each()` | ۶ و ۸ |
| `data()` | ۸ |
| زنجیره‌سازی | ۸ |

## ✍️ تمرین پروژه ۱
1. یک دکمه «توقف/پخش» اضافه کن که `autoplay` را کنترل کند.
2. به هر نقطه ناوبری یک tooltip ساده با `attr("title", ...)` بده.
3. تعداد اسلاید را به ۵ برسان و مطمئن شو چرخش دایره‌ای درست کار می‌کند.

# 📝 پروژه ۲: اعتبارسنجی فرم (Form Validation)

## هدف
فرم ثبت‌نام با اعتبارسنجی سمت کلاینت و پیام‌های خطای خط‌به‌خط.

## ساختار HTML
```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>اعتبارسنجی فرم</title>
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <style>
    * { box-sizing: border-box; }
    body { font-family: Tahoma, sans-serif; background: #eef2f7; padding: 30px; }

    .form-box {
      max-width: 420px;
      margin: 0 auto;
      background: #fff;
      padding: 26px;
      border-radius: 12px;
      box-shadow: 0 4px 20px rgba(0,0,0,0.08);
    }

    .field { margin-bottom: 16px; }

    .field label {
      display: block;
      margin-bottom: 6px;
      font-weight: bold;
      color: #333;
    }

    .field input {
      width: 100%;
      padding: 10px 12px;
      border: 2px solid #ddd;
      border-radius: 8px;
      font-size: 15px;
      transition: border-color 0.2s;
    }

    .field input:focus { outline: none; border-color: #4a90e2; }
    .field.error input  { border-color: #e74c3c; }
    .field.success input { border-color: #2ecc71; }

    .msg {
      font-size: 12px;
      margin-top: 6px;
      min-height: 16px;
      color: #e74c3c;
    }

    .field.success .msg { color: #2ecc71; }

    button[type="submit"] {
      width: 100%;
      padding: 12px;
      background: #4a90e2;
      color: #fff;
      border: none;
      border-radius: 8px;
      font-size: 16px;
      cursor: pointer;
      transition: background 0.2s;
    }
    button[type="submit"]:hover { background: #357ab8; }
    button[type="submit"]:disabled { background: #9bb; cursor: wait; }

    #result { text-align: center; margin-top: 16px; font-weight: bold; }
  </style>
</head>
<body>

  <form class="form-box" id="signupForm" novalidate>
    <div class="field" data-field="name">
      <label>نام</label>
      <input type="text" name="name" placeholder="حداقل ۳ حرف">
      <div class="msg"></div>
    </div>

    <div class="field" data-field="email">
      <label>ایمیل</label>
      <input type="text" name="email" placeholder="example@mail.com">
      <div class="msg"></div>
    </div>

    <div class="field" data-field="password">
      <label>رمز عبور</label>
      <input type="password" name="password" placeholder="حداقل ۶ کاراکتر">
      <div class="msg"></div>
    </div>

    <div class="field" data-field="age">
      <label>سن</label>
      <input type="text" name="age" placeholder="بین ۱۸ تا ۹۹">
      <div class="msg"></div>
    </div>

    <button type="submit">ثبت‌نام</button>
    <div id="result"></div>
  </form>

  <script>
  $(function() {
    // قواعد اعتبارسنجی هر فیلد
    var rules = {
      name: {
        validate: function(v) { return v.length >= 3; },
        message: "نام باید حداقل ۳ حرف باشد"
      },
      email: {
        validate: function(v) { return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(v); },
        message: "ایمیل معتبر نیست"
      },
      password: {
        validate: function(v) { return v.length >= 6; },
        message: "رمز عبور باید حداقل ۶ کاراکتر باشد"
      },
      age: {
        validate: function(v) { return /^\d+$/.test(v) && +v >= 18 && +v <= 99; },
        message: "سن باید عددی بین ۱۸ تا ۹۹ باشد"
      }
    };

    // اعتبارسنجی یک فیلد
    function validateField($field) {
      var key = $field.data("field");
      var value = $field.find("input").val().trim();
      var rule = rules[key];
      var ok = rule.validate(value);

      $field
        .toggleClass("error",   !ok)
        .toggleClass("success", ok)
        .find(".msg")
        .text(ok ? "" : rule.message);

      return ok;
    }

    // اعتبارسنجی روی blur (خروج از فیلد)
    $("#signupForm").on("blur", "input", function() {
      validateField($(this).closest(".field"));
    });

    // اعتبارسنجی زنده روی keyup (فقط اگر قبلاً خطا داشته)
    $("#signupForm").on("keyup", "input", function() {
      var $field = $(this).closest(".field");
      if ($field.hasClass("error")) validateField($field);
    });

    // ارسال فرم
    $("#signupForm").on("submit", function(event) {
      event.preventDefault();

      var allOk = true;
      $(this).find(".field").each(function() {
        if (!validateField($(this))) allOk = false;
      });

      if (!allOk) {
        $("#result").text("لطفاً خطاها را برطرف کن").css("color", "#e74c3c");
        return;
      }

      // شبیه‌سازی ارسال به سرور
      var $btn = $(this).find("button").prop("disabled", true).text("در حال ارسال…");

      var formData = $(this).serialize();

      // در پروژه واقعی: $.ajax(...)
      setTimeout(function() {
        $("#result").text("ثبت‌نام با موفقیت انجام شد ✅").css("color", "#2ecc71");
        $btn.prop("disabled", false).text("ثبت‌نام");
        console.log("داده ارسالی:", formData);
      }, 1000);
    });
  });
  </script>
</body>
</html>
```

## چه چیزی از کدام جلسه استفاده شد؟
| مفهوم | جلسه |
|---|---|
| `$(function(){})`، انتخابگرها | ۱ و ۲ |
| `on()`، `blur`، `keyup`، `submit`، تفویض رویداد | ۳ |
| `val()`، `serialize()`، `prop("disabled")` | ۵ و ۷ |
| `toggleClass`، `hasClass`، `closest()`، `find()`، `each()` | ۵ و ۶ و ۸ |
| `preventDefault` | ۳ |

## ✍️ تمرین پروژه ۲
1. فیلد «تکرار رمز عبور» اضافه کن و بررسی کن با رمز اصلی یکسان باشد.
2. یک نشانگر قدرت رمز (ضعیف/متوسط/قوی) با رنگ زیر فیلد اضافه کن.
3. بعد از موفقیت، فرم را با `$form[0].reset()` خالی کن و کلاس‌های `success`/`error` را هم پاک کن.

# ✅ پروژه ۳: لیست کارها با AJAX

## هدف
آخرین پروژه، همه چیز را ترکیب می‌کند: دریافت داده با AJAX، ساخت DOM، تفویض رویداد، فیلتر، و ذخیره‌سازی در `localStorage`.

## ساختار HTML
```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>لیست کارها با AJAX</title>
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <style>
    * { box-sizing: border-box; }
    body { font-family: Tahoma, sans-serif; background: #f7f9fc; padding: 30px; }

    .wrap {

<body>

  <div class="wrap">
    <h2>لیست کارها</h2>

    <div class="add-row">
      <input type="text" id="newTask" placeholder="کار جدید…">
      <button id="addBtn">افزودن</button>
    </div>

    <div class="filters">
      <button data-filter="all"    class="active">همه</button>
      <button data-filter="active">انجام‌نشده</button>
      <button data-filter="done">انجام‌شده</button>
    </div>

    <ul id="todoList"></ul>
    <div id="loading"></div>

    <div class="footer">
      <span id="count">۰ کار</span>
      <button id="clearDone" style="background:none;border:none;color:#e74c3c;cursor:pointer;">
        حذف انجام‌شده‌ها
      </button>
    </div>
  </div>

  <script>
  $(function() {
    var STORAGE_KEY = "my_todos";
    var $list = $("#todoList");
    var $loading = $("#loading");
    var filter = "all";

    // ---------- ابزار ----------
    function loadTodos() {
      var raw = localStorage.getItem(STORAGE_KEY);
      return raw ? JSON.parse(raw) : [];
    }

    function saveTodos(todos) {
      localStorage.setItem(STORAGE_KEY, JSON.stringify(todos));
    }

    function getTodos() { return loadTodos(); }

    // ---------- نمایش ----------
    function render() {
      var todos = getTodos();
      $list.empty();

      // اعمال فیلتر
      var filtered = todos.filter(function(t) {
        if (filter === "active") return !t.done;
        if (filter === "done")   return t.done;
        return true;
      });

      if (!filtered.length) {
        $list.append('<li class="empty">کاری برای نمایش نیست</li>');
      } else {
        filtered.forEach(function(t) {
          var $li = $("<li>")
            .attr("data-id", t.id)
            .toggleClass("done", t.done);

          $li.append(
            $("<span>").addClass("title").text(t.title),
            $("<button>").addClass("del").text("حذف")
          );

          $list.append($li);
        });
      }

      // شمارنده
      var doneCount = todos.filter(function(t) { return t.done; }).length;
      $("#count").text(todos.length + " کار · " + doneCount + " انجام‌شده");
    }

    // ---------- عملیات ----------
    function addTodo(title) {
      var todos = getTodos();
      todos.unshift({
        id: Date.now(),
        title: title,
        done: false
      });
      saveTodos(todos);
      render();
    }

    function removeTodo(id) {
      var todos = getTodos().filter(function(t) { return t.id !== id; });
      saveTodos(todos);
      render();
    }

    function toggleTodo(id) {
      var todos = getTodos();
      todos.forEach(function(t) {
        if (t.id === id) t.done = !t.done;
      });
      saveTodos(todos);
      render();
    }

    function clearDone() {
      var todos = getTodos().filter(function(t) { return !t.done; });
      saveTodos(todos);
      render();
    }

    // ---------- بارگذاری اولیه با AJAX ----------
    function bootstrap() {
      var todos = getTodos();

      if (todos.length) {
        render();
        return;
      }

      // اولین بار: داده نمونه از سرور بگیر
      $loading.text("در حال دریافت داده‌های اولیه…");

      $.getJSON("https://jsonplaceholder.typicode.com/todos?_limit=5")
        .then(function(data) {
          var initial = data.map(function(t) {
            return { id: t.id, title: t.title, done: t.completed };
          });
          saveTodos(initial);
          render();
        })
        .catch(function() {
          $loading.text("دریافت داده‌ها ناموفق بود، خودت اضافه کن :)");
        })
        .always(function() {
          setTimeout(function() { $loading.text(""); }, 1500);
        });
    }

    // ---------- رویدادها ----------
    $("#addBtn").on("click", function() {
      var title = $("#newTask").val().trim();
      if (!title) return;
      addTodo(title);
      $("#newTask").val("").focus();
    });

    // Enter برای افزودن
    $("#newTask").on("keydown", function(e) {
      if (e.key === "Enter") $("#addBtn").trigger("click");
    });

    // تفویض رویداد روی لیست
    $list.on("click", ".title", function() {
      var id = $(this).closest("li").data("id");
      toggleTodo(id);
    });

    $list.on("click", ".del", function() {
      var id = $(this).closest("li").data("id");
      removeTodo(id);
    });

    // فیلترها
    $(".filters").on("click", "button", function() {
      filter = $(this).data("filter");
      $(this).addClass("active").siblings().removeClass("active");
      render();
    });

    // حذف انجام‌شده‌ها
    $("#clearDone").on("click", clearDone);

    // شروع
    bootstrap();
  });
  </script>
</body>
</html>
```

## ✍️ تمرین پروژه ۳
1. یک قابلیت «ویرایش» اضافه کن: با دوبار کلیک روی عنوان، آن را به یک input تبدیل کن و با Enter ذخیره کن (`dblclick`).
2. یک دکمه «پاک‌کردن همه» اضافه کن که پس از تأیید با `confirm()` همه را حذف کند.
3. یک جستجوی زنده بالای لیست اضافه کن (input با `keyup`) که لیست را بر اساس عنوان فیلتر کند.
4. با `$.ajax()` و `ajaxStart` / `ajaxStop`، هنگام دریافت داده اولیه یک spinner کوچک نمایش بده (به‌جای متن ساده).

## 📝 تکلیف نهایی (جمع‌بندی)

یک **پروژه مینی شخصی** بساز؛ مثلاً:
- **گالری تصاویر** با فیلتر دسته‌بندی (Ajax + DOM + رویداد)
- **لیست مخاطبین** با جستجو، افزودن/حذف، ذخیره در localStorage
- **داشبورد آب‌وهوا** با دریافت داده از یک API عمومی (`open-meteo.com` بدون کلید کار می‌کند)

الزامات:
1. حداقل از **سه مفهوم** از جلسات مختلف استفاده کن.
2. کد را **تمیز و کامنت‌گذاری‌شده** بنویس.
3. اگر عملیات ناهمگام دارد، از `.then()` / `.catch()` استفاده کن.
4. حداقل یک پلاگین کوچک سفارشی (مثل جلسه ۸) در پروژه‌ات داشته باش.
