# جلسه ۶: پیمایش DOM (Traversing)

## 🎯 اهداف این جلسه
- پیمایش به سمت پایین: `children()`، `find()`
- پیمایش به سمت بالا: `parent()`، `parents()`، `closest()`
- پیمایش هم‌سطح‌ها: `siblings()`، `next()`، `prev()`، `nextAll()`، `prevAll()`
- فیلتر کردن مجموعه: `filter()`، `not()`، `first()`، `last()`، `eq()`
- کاربردهای عملی در منو، جدول و فرم

---

## ۱. پیمایش چیست؟
تا حالا با انتخابگرها عناصر را پیدا می‌کردیم. اما گاهی می‌خواهیم از یک عنصر شروع کنیم و به **خویشاوندان** آن برویم: والد، فرزند، هم‌سطح و… . این کار «پیمایش» نام دارد و برای ساخت منوهای تودرتو، جدول‌های تعاملی و فرم‌های پیچیده ضروری است.

---

## ۲. پیمایش به سمت پایین (Descendants)

### `children()` — فرزندان مستقیم
```javascript
$("#list").children();          // فقط liهای مستقیم داخل #list
$("#list").children(".active"); // فقط فرزندان مستقیم با کلاس active
```

### `find()` — همه نوادگان (هر عمقی)
```javascript
$("#list").find("li");          // همه liها در هر عمقی
$("#list").find(".item");       // همه عناصر با کلاس item
```

**تفاوت مهم:**
```html
<div id="box">
  <p>فرزند مستقیم</p>
  <div>
    <p>نوه</p>
  </div>
</div>
```
```javascript
$("#box").children("p").length;  // ۱  (فقط فرزند مستقیم)
$("#box").find("p").length;      // ۲  (فرزند + نوه)
```

---

## ۳. پیمایش به سمت بالا (Ancestors)

### `parent()` — والد مستقیم
```javascript
$("#item").parent();            // یک سطح بالا
$("#item").parent(".container"); // والد مستقیم اگر کلاس container داشت
```

### `parents()` — همه والدین تا ریشه
```javascript
$("#item").parents();           // همه والدین (body، html و…)
$("#item").parents("div");      // فقط والدین div
$("#item").parentsUntil(".main"); // تا قبل از رسیدن به .main
```

### `closest()` — نزدیک‌ترین والد مطابق انتخابگر (شامل خود عنصر)
```javascript
$("#item").closest(".card");    // نزدیک‌ترین والد با کلاس card
```

**تفاوت `parents()` با `closest()`:**
- `parents(".card")` → **همه** والدین با کلاس card (ممکن است چند تا باشند).
- `closest(".card")` → **اولین/نزدیک‌ترین** والد با کلاس card.
- `closest()` خود عنصر را هم بررسی می‌کند؛ `parents()` نه.

💡 **`closest()` پرکاربردترین متد در Event Delegation است:**
```javascript
$("#list").on("click", "button.del", function() {
  $(this).closest("li").remove();  // از دکمه به li والد برو و حذف کن
});
```

## ۴. پیمایش هم‌سطح‌ها (Siblings)

```javascript
$("#item").siblings();          // همه هم‌سطح‌ها
$("#item").siblings(".active"); // هم‌سطح‌های با کلاس active

$("#item").next();              // هم‌سطح بعدی
$("#item").prev();              // هم‌سطح قبلی
$("#item").nextAll();           // همه هم‌سطح‌های بعدی
$("#item").prevAll();           // همه هم‌سطح‌های قبلی

$("#item").nextUntil(".end");   // تا قبل از .end
$("#item").prevUntil(".start"); // تا قبل از .start
```

**مثال: تب‌های ساده**
```html
<div class="tabs">
  <button class="tab active">تب ۱</button>
  <button class="tab">تب ۲</button>
  <button class="tab">تب ۳</button>
</div>

<script>
$(function() {
  $(".tab").on("click", function() {
    $(this).addClass("active").siblings().removeClass("active");
  });
});
</script>
```
خط `$(this).addClass("active").siblings().removeClass("active")` یعنی: خودم فعال شو، بقیه هم‌سطح‌ها غیرفعال شوند.

## ۵. فیلتر کردن مجموعه انتخاب‌شده

```javascript
$("li").filter(".active");       // فقط آن‌هایی که کلاس active دارند
$("li").not(".active");          // آن‌هایی که active ندارند
$("li").first();                 // اولین
$("li").last();                  // آخرین
$("li").eq(2);                   // با ایندکس ۲ (سومین)
$("li").slice(1, 4);             // از ایندکس ۱ تا قبل از ۴

// فیلتر با تابع
$("li").filter(function(index) {
  return index % 2 === 0;        // آیتم‌های زوج
});
```

### `is()` — بررسی تطابق
```javascript
if ($("#item").is(".active")) {
  console.log("فعال است");
}
if ($("#item").is(":visible")) {
  console.log("دیده می‌شود");
}
```

### `has()` — بررسی داشتن فرزند
```javascript
$("li").has("ul");              // liهایی که داخلشان ul دارند
```

## ۶. مثال جامع: منوی تودرتو (Accordion Menu)

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>منوی تودرتو</title>
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <style>
    ul { list-style: none; padding-right: 20px; }
    .submenu { display: none; }
    .toggle { cursor: pointer; color: steelblue; font-weight: bold; }
    .open > .submenu { display: block; }
    .open > .toggle::before { content: "▼ "; }
    .toggle::before { content: "▶ "; }
  </style>
</head>
<body>
  <ul id="menu">
    <li>
      <span class="toggle">دسته ۱</span>
      <ul class="submenu">
        <li>زیرمنو ۱-۱</li>
        <li>زیرمنو ۱-۲</li>
      </ul>
    </li>
    <li>
      <span class="toggle">دسته ۲</span>
      <ul class="submenu">
        <li>زیرمنو ۲-۱</li>
      </ul>
    </li>
  </ul>

  <script>
    $(function() {
      $(".toggle").on("click", function() {
        $(this).parent("li").toggleClass("open");
      });
    });
  </script>
</body>
</html>
```

**در این مثال:**
- `$(this).parent("li")` → از span به li والد می‌رویم.
- `toggleClass("open")` → کلاس open را اضافه/حذف می‌کنیم.
- CSS با `.open > .submenu` زیرمنو را نمایش می‌دهد.

اگر بخواهیم با انیمیشن هم باز شود:
```javascript
$(".toggle").on("click", function() {
  $(this).siblings(".submenu").stop().slideToggle(300);
});
```
اینجا از `siblings()` استفاده کردیم تا به زیرمنوی هم‌سطح برویم.

## ۷. مثال جامع: انتخاب سطر جدول

```html
<table id="users" border="1">
  <tr><th>نام</th><th>عملیات</th></tr>
  <tr>
    <td>علی</td>
    <td><button class="edit">ویرایش</button></td>
  </tr>
  <tr>
    <td>سارا</td>
    <td><button class="edit">ویرایش</button></td>
  </tr>
</table>

<script>
$(function() {
  $("#users").on("click", ".edit", function() {
    var name = $(this).closest("tr").find("td:first").text();
    alert("ویرایش: " + name);
  });
});
</script>
```

**زنجیره پیمایش:**
1. `$(this)` → دکمه
2. `.closest("tr")` → سطر والد
3. `.find("td:first")` → اولین سلول همان سطر
4. `.text()` → نام کاربر

این الگو (closest + find) در جدول‌های تعاملی **خیلی** پرکاربرد است.

---

## ۸. نکته‌های کلیدی
- `children` فقط فرزند مستقیم؛ `find` هر عمقی.
- `parent` یک سطح؛ `parents` همه سطوح؛ `closest` نزدیک‌ترین مطابق (شامل خود).
- `siblings` بقیه هم‌سطح‌ها را می‌دهد (خود عنصر نه).
- `filter` و `not` برای محدود کردن نتیجه انتخاب‌شده.
- ترکیب `closest()` + `find()` ستون فقرات پیمایش در رویدادهای delegation است.
- پیمایش‌ها را می‌توان **زنجیره** کرد: `$(this).closest("li").find(".title").text()`.

---

## ✍️ تمرین این جلسه
1. یک لیست ۳ آیتمی بساز. با کلیک روی هر آیتم، **هم‌سطح‌های** آن رنگ دیگری بگیرند.
2. سه div تودرتو بساز. با کلیک روی داخلی‌ترین، با `parents()` همه والدین را کنسول کن و با `closest(".outer")` فقط والد بیرونی را پیدا کن.
3. یک جدول ۳ سطری بساز که هر سطر یک دکمه «حذف» داشته باشد. با کلیک روی دکمه، همان سطر حذف شود (با `closest`).
4. یک لیست بساز و با `filter()` فقط آیتم‌هایی که متنشان شامل حرف «ا» است را هایلایت کن.

---

## 📝 تکلیف
یک **منوی آبشاری سه‌سطحی** بساز:
- سطح اول: ۲ آیتم اصلی
- سطح دوم: هر کدام ۲ زیرآیتم
- سطح سوم: هر زیرآیتم ۲ آیتم نهایی
- کلیک روی هر آیتم → زیرمنوی همان آیتم با `siblings()` و `slideToggle` باز/بسته شود
- از `stop()` استفاده کن تا کلیک‌های سریع باگ ایجاد نکنند
