# جلسه ۸: مباحث پیشرفته jQuery

## 🎯 اهداف این جلسه
- درک عمیق **زنجیره‌سازی متدها (Chaining)** و شرط لازم برای آن
- کار با `$.Deferred()` و الگوی Promise در jQuery
- استفاده از `data()` برای ذخیره داده روی عناصر
- پیمایش مجموعه‌ها با `each()` و `$.each()`
- مدیریت تداخل با `noConflict()`
- نوشتن یک **پلاگین سفارشی** کامل

---

## ۱. زنجیره‌سازی متدها (Chaining)

در جلسات قبل بارها چیزی مثل این نوشتیم:
```javascript
$("#box").addClass("active").css("color", "red").slideDown(300);
```

### چرا کار می‌کند؟
بیشتر متدهای jQuery در پایان **خود مجموعه jQuery** را برمی‌گردانند (`return this`). بنابراین می‌توانی متد بعدی را روی خروجی متد قبلی صدا بزنی.

### شرط زنجیره‌سازی
هر متدی که **مقدار** برمی‌گرداند، زنجیره را می‌شکند:

```javascript
// ❌ زنجیره شکسته: text() مقدار رشته برمی‌گرداند
var txt = $("#box").text().addClass("active");   // خطا

// ✅ جدا کن
var txt = $("#box").text();
$("#box").addClass("active");
```

### فهرست متدهایی که زنجیره را می‌شکنند
- `text()`، `html()`، `val()` (بدون آرگومان → خواندن)
- `attr("name")`، `prop("checked")`، `css("color")` (بدون مقدار → خواندن)
- `width()`، `height()` (بدون آرگومان)
- `is()`، `hasClass()`
- `index()`، `get()`

💡 **قاعده:** اگر متد آرگومان نگیری و بخواهی مقدار بگیری، زنجیره می‌شکند.

### زنجیره با `.end()`
`.end()` به انتخابگر قبلی برمی‌گردد:
```javascript
$("#list")
  .find("li")
    .addClass("item")
  .end()              // برگرد به #list
  .addClass("container");
```
این برای وقتی است که روی زیرمجموعه کار کردی و می‌خواهی به والد برگردی، بدون انتخاب مجدد.

## ۲. `$.Deferred()` و Promise

در جلسه ۷ دیدیم که `$.ajax()` یک Promise برمی‌گرداند. اما `$.Deferred()` ابزار عمومی‌تری است که خودت می‌توانی با آن **عملیات ناهمگام سفارشی** بسازی.

### ساختار پایه
```javascript
var deferred = $.Deferred();

deferred
  .done(function(val) { console.log("موفق:", val); })
  .fail(function(err) { console.log("ناموفق:", err); })
  .always(function() { console.log("پایان"); });

// بعداً در جایی:
deferred.resolve("نتیجه");     // done را فعال می‌کند
// یا
deferred.reject("خطا");        // fail را فعال می‌کند
```

### روش‌های تغییر وضعیت
| متد | اثر |
|---|---|
| `resolve(value)` | Promise را موفق اعلام می‌کند → `done` اجرا می‌شود |
| `reject(reason)` | ناموفق اعلام می‌کند → `fail` اجرا می‌شود |
| `notify(value)` | ارسال پیشرفت → `progress` اجرا می‌شود |

### Promise چیست و چه تفاوتی دارد؟
```javascript
var d = $.Deferred();
var p = d.promise();   // فقط بخش خواندنی (done/fail/then) را می‌دهد
```
`promise()` یک آبجکت **فقط‌خواندنی** برمی‌گرداند: مصرف‌کننده می‌تواند `.done()` و `.then()` بزند ولی **نمی‌تواند** `resolve` یا `reject` کند. این کار کنترل را نزد سازنده نگه می‌دارد.

### مثال کاربردی: تایمر به‌صورت Promise
```javascript
function wait(ms) {
  var d = $.Deferred();
  setTimeout(function() {
    d.resolve("گذشت " + ms + " میلی‌ثانیه");
  }, ms);
  return d.promise();
}

wait(1000)
  .done(function(msg) { console.log(msg); })
  .always(function() { console.log("تایمر تمام شد"); });
```

### `$.when()` برای ترکیب چند Promise
```javascript
$.when(wait(500), wait(1000))
  .done(function(res1, res2) {
    console.log("هر دو تمام شدند", res1, res2);
  });
```

⚠️ **نکته مهم:** Promiseهای jQuery کاملاً با استاندارد Promises/A+ سازگار نیستند (مثلاً `.catch()` در نسخه‌های قدیمی وجود ندارد و باید `.fail()` بزنی). در jQuery 3+ وضعیت بهتر شده، اما برای پروژه‌های جدید، `async/await` بومی گزینه بهتری است.

## ۳. `data()` — ذخیره داده روی عناصر

گاهی می‌خواهی اطلاعاتی به یک عنصر HTML بچسبانی بدون اینکه در ویژگی‌های HTML ظاهر شود.

```javascript
// نوشتن
$("#user").data("id", 42);
$("#user").data("role", "admin");

// خواندن
var id = $("#user").data("id");       // 42
var role = $("#user").data("role");   // "admin"

// حذف
$("#user").removeData("role");
```

### `data-*` در HTML
اگر در HTML بنویسی:
```html
<div id="product" data-id="7" data-price="12000"></div>
```
با `data()` بخوان:
```javascript
$("#product").data("id");     // 7  (عدد، نه رشته)
$("#product").data("price");  // 12000
```
⚠️ jQuery مقادیر عددی و بولین را **خودکار تبدیل** می‌کند.

### کاربرد عملی
در Event Delegation خیلی مفید است:
```javascript
$("#list").on("click", "li", function() {
  var userId = $(this).data("id");
  console.log("کاربر:", userId);
});
```

## ۴. `each()` و `$.each()`

### `each()` — پیمایش مجموعه jQuery
```javascript
$("li").each(function(index, element) {
  console.log(index, $(element).text());
  // this === element
});
```
- `this` و `element` هر دو همان عنصر DOM هستند.
- برای استفاده از متدهای jQuery باید `$(this)` بزنی.
- `return false` حلقه را متوقف می‌کند (مثل `break`).

### `$.each()` — پیمایش آرایه یا آبجکت ساده
```javascript
$.each([10, 20, 30], function(i, val) {
  console.log(i, val);
});

$.each({ name: "علی", age: 25 }, function(key, val) {
  console.log(key, val);
});
```

### `map()` — ساخت آرایه جدید
```javascript
var names = $("li").map(function() {
  return $(this).text();
}).get();    // get() آرایه jQuery را به آرایه ساده تبدیل می‌کند
```

## ۵. `noConflict()` — جلوگیری از تداخل

اگر صفحه‌ات از کتابخانه دیگری (مثل Prototype) استفاده می‌کند که `$` را اشغال کرده، با `noConflict()` کنترل `$` را آزاد کن:

```javascript
var jq = $.noConflict();

jq(document).ready(function() {
  jq("#box").hide();     // به جای $ از jq استفاده کن
});
```
از این به بعد `$` متعلق به کتابخانه دیگر است و jQuery با `jq` (یا هر نام دیگر) در دسترس است.

## ۶. نوشتن پلاگین سفارشی

وقتی یک قطعه کد را چند جا تکرار می‌کنی، وقت آن است که آن را به یک پلاگین قابل استفاده مجدد تبدیل کنی.

### ساختار استاندارد
```javascript
(function($) {
  $.fn.highlight = function(options) {
    // ادغام گزینه‌های پیش‌فرض با گزینه‌های کاربر
    var settings = $.extend({
      color: "yellow",
      duration: 400
    }, options);

    // return this تا زنجیره‌سازی حفظ شود
    return this.each(function() {
      $(this).css("background-color", settings.color);
    });
  };
}(jQuery));
```

### چه چیزهایی مهم است؟
- **`(function($){...}(jQuery))`**: یک IIFE که `$` را به‌عنوان پارامتر می‌گیرد تا حتی در حالت `noConflict` هم داخل پلاگین `$` کار کند.
- **`$.fn.NAME`**: افزودن متد به prototype جی‌کوئری، تا روی هر مجموعه در دسترس باشد.
- **`return this.each(...)`**: پیمایش همه عناصر مجموعه و حفظ زنجیره‌سازی.
- **`$.extend`**: ادغام تنظیمات پیش‌فرض با ورودی کاربر.

### استفاده
```javascript
$(".note").highlight();                     // رنگ پیش‌فرض زرد
$(".alert").highlight({ color: "tomato" }); // رنگ دلخواه

// زنجیره‌سازی کار می‌کند:
$(".note").highlight({ color: "pink" }).addClass("done");
```

### نسخه پیشرفته‌تر: پلاگین با انیمیشن و callback
```javascript
(function($) {
  $.fn.flash = function(options) {
    var settings = $.extend({
      color: "gold",
      duration: 300,
      count: 2,
      complete: null
    }, options);

    return this.each(function() {
      var $el = $(this);
      var original = $el.css("background-color");
      var i = 0;

      function toggle() {
        if (i >= settings.count * 2) {
          $el.css("background-color", original);
          if (typeof settings.complete === "function") settings.complete.call(this);
          return;
        }
        $el.animate({ opacity: 0.4 }, settings.duration)
           .animate({ opacity: 1 }, settings.duration, toggle);
        i++;
      }
      toggle();
    });
  };
}(jQuery));
```

### روش‌های دیگر برای ذخیره تنظیمات
- `$.data($el, "pluginName", settings)` یا `$el.data("pluginName", ...)` برای نگه‌داشتن حالت روی عنصر.
- فایل پلاگین را جدا نگه دار (مثلاً `plugins/flash.js`) و بعد از jQuery لود کن.

## ۷. مثال جامع: پلاگین شمارنده

یک پلاگین که عددی را از صفر تا مقدار هدف انیمیت می‌کند:

```javascript
(function($) {
  $.fn.countTo = function(target, options) {
    var settings = $.extend({
      duration: 1000,
      easing: "swing",
      complete: null
    }, options);

    return this.each(function() {
      var $el = $(this);
      var start = parseInt($el.text(), 10) || 0;
      var range = target - start;
      var startTime = null;

      function step(timestamp) {
        if (!startTime) startTime = timestamp;
        var progress = Math.min((timestamp - startTime) / settings.duration, 1);
        $el.text(Math.floor(start + range * progress));
        if (progress < 1) {
          requestAnimationFrame(step);
        } else if (typeof settings.complete === "function") {
          settings.complete.call($el);
        }
      }
      requestAnimationFrame(step);
    });
  };
}(jQuery));

// استفاده
$("#counter").countTo(1000, {
  duration: 1500,
  complete: function() { console.log("شمارش تمام شد"); }
});
```

## ۸. نکته‌های کلیدی این جلسه
- زنجیره‌سازی فقط وقتی کار می‌کند که متد `return this` کند.
- متدهای «خواندن مقدار» زنجیره را می‌شکنند؛ `.end()` به انتخابگر قبلی برمی‌گردد.
- `$.Deferred()` برای ساخت Promise سفارشی؛ `promise()` نسخه فقط‌خواندنی می‌دهد.
- `data()` برای چسباندن داده به عناصر؛ `data-*` را خودکار تبدیل نوع می‌کند.
- `each()` روی مجموعه jQuery، `$.each()` روی آرایه/آبجکت.
- `noConflict()` تداخل `$` با کتابخانه‌های دیگر را حل می‌کند.
- پلاگین استاندارد = IIFE + `$.fn.NAME` + `return this.each()` + `$.extend`.

## ✍️ تمرین این جلسه
1. زنجیره زیر را طوری بنویس که `end()` هم استفاده شود: به همه `liها` کلاس `item` بده، سپس به `ul` والد برگرد و کلاس `menu` بده.
2. تابعی بساز با نام `delayMsg` که با `$.Deferred` بعد از N ثانیه پیامی برمی‌گرداند و با `.done()` آن را نمایش بده.
3. سه عنصر با `data-price` بساز و با `each()` مجموع قیمت‌ها را حساب کن.
4. یک پلاگین کوچک با نام `$.fn.borderize` بنویس که به هر عنصر یک حاشیه با رنگ دلخواه بدهد. تست کن که زنجیره‌سازی کار کند.

## 📝 تکلیف

یک **پلاگین Tooltip** بساز:
- روی هر عنصری که پلاگین صدا زده شود، وقتی ماوس وارد شد یک `<div>` کوچک با متن `data-tip` عنصر نمایش داده شود.
- با خروج ماوس، tooltip با `fadeOut` محو شود.
- گزینه‌های `position` (بالا/پایین) و `color` قابل تنظیم باشد.
- از `$.extend` برای ادغام تنظیمات، از `each()` برای پیمایش، و از `on()` برای رویدادها استفاده کن.
- مطمئن شو که زنجیره‌سازی حفظ می‌شود (`return this.each`).
