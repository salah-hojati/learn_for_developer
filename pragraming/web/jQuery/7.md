# جلسه ۷: AJAX با jQuery

## 🎯 اهداف این جلسه
- درک مفهوم AJAX و نقش آن در بارگذاری داده بدون رفرش صفحه
- تسلط بر متد اصلی `$.ajax()` و پارامترهای مهم آن
- استفاده از متدهای میان‌بر `$.get()`، `$.post()`، `$.getJSON()`
- مدیریت نتیجه با سبک Promise (`.then()` / `.catch()`)
- آشنایی با رویدادهای سراسری AJAX (نمایش وضعیت بارگذاری)
- انجام دو مثال عملی: بارگذاری پویا لیست + ارسال ناهمگام فرم

---

## ۱. AJAX چیست و jQuery چه نقشی دارد؟

AJAX به این معناست: **بدون رفرش کل صفحه، با سرور تبادل داده کن و بخشی از صفحه را به‌روز کن.**

زیر پوسته از `XMLHttpRequest` مرورگر استفاده می‌شود، اما نوشتن دستی آن طولانی است. jQuery آن را کپسوله کرده و مراحل ارسال درخواست، پردازش پاسخ و مدیریت خطا را در چند متد کوتاه فشرده است.

jQuery دو دسته متد AJAX دارد:

| نوع | متدها | کاربرد |
|---|---|---|
| عمومی (سطح پایین) | `$.ajax(options)` | کنترل کامل (timeout، header، cache، مدیریت خطا) |
| میان‌بر | `$.get` / `$.post` / `$.getJSON` | GET / POST / دریافت JSON معمولی، سینتکس کوتاه‌تر |

> ⚠️ توجه: jQuery 4.0 جایگاه callbackهای `success` / `error` را تضعیف کرده و استفاده از سبک Promise (`.then()` / `.catch()`) توصیه می‌شود. در ادامه هر دو روش نمایش داده می‌شود، اما در پروژه واقعی از Promise استفاده کن.

## ۲. متد اصلی: `$.ajax(options)`

`$.ajax()` پایه‌ای‌ترین و منعطف‌ترین متد است. بقیه متدهای میان‌بر در واقع پوششی روی همین هستند.

### سینتکس پایه
```javascript
$.ajax({
  url: "https://api.example.com/data",
  type: "GET",              // یا method: "GET" (jQuery 1.9+)
  dataType: "json",         // نوع پاسخ موردانتظار: json / html / text / xml / script
  data: { id: 1 },          // داده‌های ارسالی (آبجکت یا رشته)
  success: function(data) { /* موفق */ },
  error: function(xhr, status, error) { /* خطا */ }
});
```

### جدول سریع پارامترهای پرکاربرد

| پارامتر | نوع | توضیح |
|---|---|---|
| `url` | String | آدرس درخواست |
| `type` / `method` | String | `GET` (پیش‌فرض) یا `POST` |
| `dataType` | String | نوع پاسخ موردانتظار: `json`، `html`، `text`، `xml`، `script` |
| `data` | Object/String | داده ارسالی به سرور |
| `timeout` | Number | میلی‌ثانیه؛ در صورت تجاوز، `error` فعال می‌شود |
| `cache` | Boolean | `false` کش مرورگر را غیرفعال می‌کند (برای GET پرکاربرد) |
| `async` | Boolean | پیش‌فرض `true` (ناهمگام). **هرگز `false` نگذار** چون صفحه قفل می‌شود |
| `contentType` | String | نوع کدگذاری داده ارسالی، پیش‌فرض `application/x-www-form-urlencoded` |
| `headers` | Object | هدرهای سفارشی (مثلاً Token) |
| `beforeSend` | Function | قبل از ارسال اجرا می‌شود (نمایش وضعیت بارگذاری) |
| `complete` | Function | بعد از پایان (موفق یا ناموفق) اجرا می‌شود |

## ۳. متدهای میان‌بر

### `$.get()` — دریافت داده
```javascript
// سینتکس: $.get(url, [data], [success], [dataType])
$.get("/api/users", { page: 1 }, function(data) {
  console.log(data);
}, "json");
```

### `$.post()` — ارسال داده
```javascript
// سینتکس: $.post(url, [data], [success], [dataType])
$.post("/api/users", { name: "علی", age: 25 }, function(res) {
  console.log("با موفقیت ساخته شد", res);
}, "json");
```

### `$.getJSON()` — مخصوص دریافت JSON
`$.getJSON()` معادل `$.ajax({ url, dataType: "json" })` است و ساده‌ترین سینتکس را دارد:
```javascript
$.getJSON("/api/products", function(data) {
  // data به‌طور خودکار به آبجکت جاوااسکریپت تبدیل شده است
  console.log(data[0].name);
});
```
⚠️ `$.getJSON()` **ناهمگام** است؛ کد داخل callback اجرای بقیه کدها را متوقف نمی‌کند.

## ۴. سبک Promise: روش توصیه‌شده

از jQuery 1.5 به بعد، `$.ajax()` و متدهای میان‌بر یک **Promise** برمی‌گردانند که با `.then()`، `.catch()`، `.always()` می‌توان آن را سازمان‌دهی کرد.

### استفاده پایه
```javascript
$.ajax({
  url: "/api/data",
  dataType: "json"
})
  .then(function(data) {
    console.log("موفق:", data);
    return data;               // می‌توانی return کنی تا به .then بعدی برسد
  })
  .catch(function(xhr, status, error) {
    console.error("ناموفق:", error);
  })
  .always(function() {
    console.log("در هر حالت (موفق یا ناموفق) اجرا می‌شود");
  });
```

### درخواست‌های زنجیره‌ای (یکی پس از دیگری)
```javascript
$.getJSON("/api/user/1")
  .then(function(user) {
    console.log("کاربر:", user.name);
    return $.getJSON("/api/orders?userId=" + user.id);   // Promise دوم را return کن
  })
  .then(function(orders) {
    console.log("تعداد سفارش‌ها:", orders.length);
  })
  .catch(function(err) {
    console.error("هر مرحله‌ای از زنجیره که خطا بدهد اینجا می‌افتد", err);
  });
```
مزیت این سبک: جلوگیری از «هرم callback» و کد تخت‌تر و خواناتر.

### درخواست‌های موازی
```javascript
$.when(
  $.getJSON("/api/a"),
  $.getJSON("/api/b")
).done(function(resA, resB) {
  console.log("هر دو تمام شدند", resA[0], resB[0]);
});
```
`$.when()` معادل `Promise.all()` در جاوااسکریپت مدرن است.

## ۵. رویدادهای سراسری AJAX: نشانگر بارگذاری

نیازی نیست در هر درخواست جداگانه «در حال بارگذاری» بنویسی؛ با رویدادهای سراسری یک‌جا مدیریت کن:

```javascript
// در صفحه یک عنصر بارگذاری مخفی بگذار
// <div id="loading" style="display:none;">در حال بارگذاری…</div>

$(document)
  .ajaxStart(function() {
    $("#loading").show();       // با شروع اولین درخواست Ajax نمایش بده
  })
  .ajaxStop(function() {
    $("#loading").hide();       // با پایان همه درخواست‌ها مخفی کن
  });
```

رویدادهای سراسری پرکاربرد:

| رویداد | زمان فعال شدن |
|---|---|
| `ajaxStart` | شروع اولین درخواست Ajax |
| `ajaxStop` | اتمام همه درخواست‌ها |
| `ajaxSuccess` | موفقیت هر درخواست |
| `ajaxError` | خطای هر درخواست |
| `ajaxComplete` | اتمام هر درخواست (موفق یا ناموفق) |

## ۶. اشتباهات رایج و نکات مهم

### ① برای `checked` / `disabled` از `attr()` استفاده نکن
در جلسه ۵ هم تأکید شد، اما در سناریوی فرم + AJAX خیلی رایج است: برای خواندن/تنظیم وضعیت چک‌باکس از `prop()` استفاده کن، نه `attr()`.

### ② به GETها `cache: false` اضافه کن
IE و بعضی پروکسی‌ها پاسخ GET را کش می‌کنند و داده قدیمی برمی‌گردانند:
```javascript
$.ajax({ url: "/api/list", cache: false });
```
برای `$.getJSON()` می‌توانی یک timestamp به URL اضافه کنی، یا در `$.ajaxSetup` یک‌جا تنظیم کنی.

### ③ مدیریت خطا باید timeout را هم پوشش دهد
```javascript
$.ajax({
  url: "/api/slow",
  timeout: 5000,
  error: function(xhr, status, error) {
    if (status === "timeout") {
      console.warn("درخواست تایم‌اوت شد");
    } else {
      console.error("درخواست شکست خورد", error);
    }
  }
});
```

### ④ هرگز `async: false` نگذار
AJAX همگام کل UI مرورگر را قفل می‌کند و در توسعه مدرن تقریباً هرگز نباید استفاده شود.

### ⑤ سریالایز کردن فرم
برای ارسال کل فرم، `$(form).serialize()` مطمئن‌تر از جمع‌کردن دستی هر فیلد است:
```javascript
$.post("/api/save", $("form").serialize(), function(res) {
  console.log(res);
});
```

## ۷. مثال اول: بارگذاری پویا لیست کاربران

```html
<button id="loadBtn">بارگذاری کاربران</button>
<ul id="userList"></ul>
<div id="loading" style="display:none;">در حال بارگذاری…</div>

<script>
$(function() {
  $(document)
    .ajaxStart(function() { $("#loading").show(); })
    .ajaxStop(function() { $("#loading").hide(); });

  $("#loadBtn").on("click", function() {
    $("#userList").empty();

    $.getJSON("https://jsonplaceholder.typicode.com/users")
      .then(function(users) {
        $.each(users, function(index, user) {
          $("#userList").append(
            $("<li>").text(user.name + " — " + user.email)
          );
        });
      })
      .catch(function() {
        $("#userList").append("<li>بارگذاری ناموفق بود، بعداً دوباره تلاش کن</li>");
      });
  });
});
</script>
```

اینجا از `empty()`، `append()`، `$("<li>")` (جلسه ۵)، `on()` (جلسه ۳) و منطق پیمایش (جلسه ۶) استفاده شده است.

## ۸. مثال دوم: ارسال ناهمگام فرم (بدون رفرش)

```html
<form id="myForm">
  <input type="text" name="name" placeholder="نام" required>
  <input type="email" name="email" placeholder="ایمیل" required>
  <button type="submit">ارسال</button>
</form>
<p id="result"></p>

<script>
$(function() {
  $("#myForm").on("submit", function(event) {
    event.preventDefault();   // جلسه ۳: جلوگیری از ارسال پیش‌فرض

    var $form = $(this);
    var $btn = $form.find("button").prop("disabled", true);  // جلوگیری از ارسال تکراری

    $.ajax({
      url: "/api/submit",
      type: "POST",
      data: $form.serialize(),
      dataType: "json"
    })
      .then(function(res) {
        $("#result").text("با موفقیت ارسال شد: " + res.message).css("color", "green");
        $form[0].reset();
      })
      .catch(function(xhr) {
        var msg = xhr.status === 400 ? "داده‌ها معتبر نیستند" : "خطای سرور";
        $("#result").text(msg).css("color", "red");
      })
      .always(function() {
        $btn.prop("disabled", false);   // در هر حالت دکمه را فعال کن
      });
  });
});
</script>
```

## ۹. مرور نکات کلیدی این جلسه

- `$.ajax()` متد پایه است؛ `$.get` / `$.post` / `$.getJSON` میان‌برهایی روی آن هستند.
- متدهای AJAX **Promise** برمی‌گردانند؛ از `.then()` / `.catch()` به‌جای callbackهای `success` / `error` استفاده کن.
- رویدادهای سراسری `ajaxStart` / `ajaxStop` برای مدیریت یک‌جای وضعیت بارگذاری مناسب‌اند.
- `cache: false`، `timeout`، و `prop("disabled", true)` تنظیمات دفاعی رایج در محیط عملیاتی هستند.
- برای فرم از `serialize()` و `event.preventDefault()` استفاده کن.

## ✍️ تمرین این جلسه

1. با `$.getJSON()` به `https://jsonplaceholder.typicode.com/posts` درخواست بده و `title` پنج پست اول را در یک `<ul>` نمایش بده.
2. به همان درخواست `.catch()` اضافه کن تا در صورت خطا «بارگذاری ناموفق» در صفحه نشان داده شود.
3. برای تمرین ۱ با `ajaxStart` / `ajaxStop` یک نشانگر بارگذاری اضافه کن.
4. مثال دوم را تغییر بده: بعد از ارسال موفق، کاربر جدید را با `prepend()` به بالای یک لیست اضافه کن، نه فقط نمایش یک پیام.

## 📝 تکلیف

یک **ویجت پیشنهاد جستجو** بساز:
- یک input متنی
- با تایپ (رویداد `keyup`، با یک `setTimeout` ۳۰۰ میلی‌ثانیه‌ای برای **debounce**) به `https://jsonplaceholder.typicode.com/users?name_like=کلیدواژه` درخواست GET بفرست
- در یک `<ul>` زیر input، نام کاربران مطابق را نمایش بده
- قبل از هر درخواست پیشنهادهای قبلی را پاک کن و با `.catch()` خطا را مدیریت کن
- با `ajaxStart` / `ajaxStop` یک متن کوچک «در حال بارگذاری» نشان بده
