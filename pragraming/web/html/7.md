## CSS چیست؟
CSS مخفف **Cascading Style Sheets** است. با CSS می‌گویی هر تگ چه شکلی باشد: رنگ، فونت، اندازه، فاصله، چیدمان.

## ۱. سه راه اتصال CSS به HTML

**روش ۱ — فایل جدا (بهترین روش):**
```html
<head>
  <link rel="stylesheet" href="style.css">
</head>
```
در فایل `style.css` می‌نویسی:
```css
body {
  background-color: #f0f0f0;
}
```

**روش ۲ — داخلی در `<head>`:**
```html
<head>
  <style>
    body { background-color: #f0f0f0; }
  </style>
</head>
```

**روش ۳ — inline روی خود تگ (کم استفاده):**
```html
<p style="color: red;">متن قرمز</p>
```

> ✅ همیشه روش ۱ را استفاده کن. فایل `style.css` را کنار `index.html` بساز.

## ۲. ساختار قاعده CSS

```css
انتخابگر {
  ویژگی: مقدار;
  ویژگی: مقدار;
}
```

مثال:
```css
h1 {
  color: blue;
  font-size: 32px;
}
```

- **انتخابگر (Selector):** چه چیزی را استایل بدهم؟
- **ویژگی (Property):** چه چیزی را تغییر بدهم؟
- **مقدار (Value):** چقدر/چه رنگی؟
- هر خط با `;` تمام می‌شود.

## ۳. انواع انتخابگرها

```css
/* تگ */
p { color: gray; }

/* کلاس — با نقطه، روی هر تگی با class="box" */
.box { background: yellow; }

/* آی‌دی — با #، فقط یک بار در صفحه */
#main { background: white; }

/* همه عناصر */
* { margin: 0; padding: 0; }

/* چند انتخابگر با هم */
h1, h2, h3 { color: navy; }

/* فرزند مستقیم */
nav > a { color: red; }

/* همه لینک‌های داخل nav */
nav a { text-decoration: none; }

/* حالت‌ها (pseudo-class) */
a:hover { color: orange; }
button:focus { outline: 2px solid blue; }
```

**تفاوت class و id:**
- `class` را می‌توانی روی چند تگ بگذاری: `<div class="card">`
- `id` باید یکتا باشد: `<div id="header">`

## ۴. رنگ‌ها

```css
p {
  color: red;                  /* نام رنگ */
  color: #ff0000;              /* Hex */
  color: rgb(255, 0, 0);       /* RGB */
  color: rgba(255, 0, 0, 0.5); /* RGB با شفافیت */
  color: hsl(0, 100%, 50%);    /* Hue Saturation Lightness */
}
```

- `color`: رنگ متن
- `background-color`: رنگ پس‌زمینه

## ۵. فونت

```css
body {
  font-family: "Vazirmatn", Tahoma, Arial, sans-serif;
  font-size: 16px;
  font-weight: normal;  /* یا bold، 100-900 */
  font-style: normal;  /* یا italic */
  line-height: 1.6;
  text-align: right;
}
```

- `font-family`: لیست فونت‌ها؛ مرورگر اولی را که دارد استفاده می‌کند
- `font-size`: اندازه
- `font-weight`: ضخامت (bold یا عدد)
- `line-height`: فاصله بین خطوط
- `text-align`: چپ/راست/وسط (`left`, `right`, `center`)

**فونت فارسی پیشنهادی** — از Google Fonts:
```html
<link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@400;700&display=swap" rel="stylesheet">
```

## ۶. تزئین متن

```css
p {
  text-decoration: underline;   /* خط زیر / none برای حذف خط لینک */
  text-transform: uppercase;    /* بزرگ کردن حروف (انگلیسی) */
  letter-spacing: 1px;          /* فاصله حروف */
  text-shadow: 2px 2px 4px gray; /* سایه متن */
}
```

برای حذف خط زیر لینک:
```css
a { text-decoration: none; }
```

## کد کامل تمرین درس ۱

**فایل `index.html`:**

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>درس ۱ CSS</title>
  <link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@400;700&display=swap" rel="stylesheet">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 class="title">سلام، دنیای استایل‌دار!</h1>

  <p class="intro">
    این پاراگراف با <strong>CSS</strong> استایل گرفته است.
  </p>

  <div class="box">
    <h2>درباره من</h2>
    <p>من در حال یادگیری <em>CSS</em> هستم.</p>
    <a href="https://www.google.com" target="_blank">برو به گوگل</a>
  </div>

  <p id="special">این پاراگراف آی‌دی دارد و استایل خاص خودش را می‌گیرد.</p>
</body>
</html>
```

**فایل `style.css`:**

```css
/* تنظیمات کلی */
body {
  font-family: "Vazirmatn", Tahoma, sans-serif;
  background-color: #f5f5f5;
  color: #333;
  line-height: 1.8;
  padding: 20px;
}

/* عنوان اصلی */
.title {
  color: #2c3e50;
  font-size: 36px;
  text-align: center;
  text-shadow: 1px 1px 2px #ccc;
}

/* پاراگراف معرفی */
.intro {
  font-size: 18px;
  color: #555;
  background-color: #fff;
  padding: 15px;
  border-right: 4px solid #3498db;
}

/* جعبه */
.box {
  background-color: #ffffff;
  border: 1px solid #ddd;
  padding: 20px;
  margin-top: 20px;
  border-radius: 8px;
}

.box h2 {
  color: #3498db;
  font-size: 24px;
}

/* لینک */
a {
  color: #e74c3c;
  text-decoration: none;
  font-weight: bold;
}

a:hover {
  color: #c0392b;
  text-decoration: underline;
}

/* آی‌دی */
#special {
  color: #8e44ad;
  font-style: italic;
  border-top: 2px dashed #8e44ad;
  padding-top: 10px;
}
```

## نکات مهم
1. همیشه `style.css` را با `<link>` در `<head>` وصل کن.
2. `margin: 0; padding: 0;` روی `*` را بعداً یاد می‌گیریم (درس Box Model).
3. اسم کلاس‌ها را **معنادار** انتخاب کن: `card`، `title`، `intro` — نه `red-text`.
4. در CSS ترتیب بالا‌به‌پایین مهم است؛ استایل بعدی استایل قبلی را اگر برنده شود بازنویسی می‌کند.

## تمرین درس ۱
1. فایل `index.html` و `style.css` را بساز و کد بالا را بنویس.
2. در مرورگر ببین.
3. رنگ `body` را به یک رنگ ملایم دیگر تغییر بده.
4. یک `class="highlight"` بساز و به یک `<span>` داخل متن بده؛ رنگ پس‌زمینه زرد بهش بده.
5. یک `:hover` روی `h1` بگذار که وقتی موس رویش می‌رود رنگش عوض شود.

یک صفحه با این‌ها بساز و فقط با CSS استایل بده:
