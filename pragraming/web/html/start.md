## ۱. ابزار لازم
- یک مرورگر: Chrome یا Firefox
- یک ادیتور: **VS Code**
- افزونه **Live Server** در VS Code
- یک پوشه برای تمرین‌ها

## ۲. اولین کد HTML
یک فایل به نام `index.html` بساز و این کد را داخلش بنویس:
</div>

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>اولین صفحه من</title>
</head>
<body>
  <h1>سلام دنیا!</h1>
  <p>این اولین پاراگراف من است.</p>
</body>
</html>
```

بعد فایل را در مرورگر باز کن. اگر Live Server داشته باشی، با راست‌کلیک و Open with Live Server می‌بینی.

## ۳. مفاهیم پایه که باید یاد بگیری
- **تگ**: مثل `<p>` و `</p>`
- **عنصر**: کل چیزی که بین تگ باز و بسته است
- **صفت**: مثل `href` در لینک یا `src` در تصویر
- **تگ خودبسته**: مثل `<img>` و `<br>`
- **تودرتویی**: قرار دادن تگ داخل تگ

## ۴. تگ‌های مهم به ترتیب یادگیری
1. عنوان‌ها: `h1` تا `h6`
2. پاراگراف: `p`
3. متن مهم: `strong`، `em`، `mark`، `small`
4. لینک: `a href="..."` و `target="_blank"`
5. تصویر: `img src="..." alt="..."`
6. لیست‌ها: `ul`، `ol`، `li`
7. جدول: `table`، `tr`، `th`، `td`
8. فرم: `form`، `input`، `label`، `textarea`، `select`، `button`
9. تگ‌های معنایی: `header`، `nav`، `main`، `section`، `article`، `aside`، `footer`
   10.多媒体: `video`، `audio`، `iframe`

## ۵. نقشه راه ۴ هفته‌ای
**هفته ۱:** ساختار صفحه، متن، لینک، تصویر، لیست  
**هفته ۲:** جدول، فرم، تگ‌های معنایی، meta tag  
**هفته ۳:** سه پروژه کوچک بساز:
- صفحه معرفی خودت
- صفحه رزومه ساده
- فرم ثبت‌نام

**هفته ۴:** اعتبارسنجی با W3C Validator، رعایت `alt` برای تصاویر، `label` برای فرم‌ها، ترتیب درست عنوان‌ها. بعد برو سراغ **CSS**.
