## Box Model چیست؟

در CSS هر عنصر یک **جعبه** است. هر جعبه ۴ لایه دارد، از داخل به بیرون:

```
┌──────────────────────────────┐
│           Margin             │
│  ┌────────────────────────┐  │
│  │        Border          │  │
│  │  ┌──────────────────┐  │  │
│  │  │    Padding       │  │  │
│  │  │  ┌────────────┐  │  │  │
│  │  │  │  Content   │  │  │  │
│  │  │  └────────────┘  │  │  │
│  │  └──────────────────┘  │  │
│  └────────────────────────┘  │
└──────────────────────────────┘
```

| لایه | کار |
|------|------|
| **Content** | محتوا (متن، تصویر) |
| **Padding** | فاصله داخلی بین محتوا و کادر |
| **Border** | خط دور جعبه |
| **Margin** | فاصله بیرونی با عناصر دیگر |

## ۱. Width و Height

```css
.box {
  width: 300px;
  height: 150px;
}
```

اندازه **محتوا** را تعیین می‌کند (نه کل جعبه). اگر `padding` و `border` داشته باشی، اندازه کل جعبه بزرگ‌تر می‌شود.

## ۲. Padding (فاصله داخلی)

```css
.box {
  padding: 20px;                      /* همه طرف */
  padding: 10px 20px;                 /* بالا/پایین ۱۰، چپ/راست ۲۰ */
  padding: 10px 20px 30px 40px;       /* بالا راست پایین چپ */
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 10px;
  padding-left: 20px;
}
```

## ۳. Margin (فاصله بیرونی)

```css
.box {
  margin: 20px;                       /* همه طرف */
  margin: 0 auto;                     /* وسط‌چین افقی (با عرض مشخص) */
  margin-top: 30px;
  margin-bottom: 30px;
}
```

**نکته:** `margin: 0 auto;` یک جعبه با عرض مشخص را وسط‌چین می‌کند.

## ۴. Border (خط دور)

```css
.box {
  border: 2px solid black;            /* ضخامت نوع رنگ */
  /* انواع: solid, dashed, dotted, double, none */
  border-width: 2px;
  border-style: solid;
  border-color: red;
  border-radius: 8px;                 /* گوشه‌های گرد */
}

/* فقط یک طرف */
.box {
  border-top: 3px solid blue;
  border-bottom: 1px dashed gray;
}

/* دایره */
.circle {
  width: 100px;
  height: 100px;
  border-radius: 50%;
}
```

- `border-radius: 50%` روی عنصر مربعی، **دایره** می‌سازد.
- `border-radius` را می‌توانی به هر گوشه جدا بدهی: `border-top-left-radius: 20px;`

## ۵. box-sizing — نکته خیلی مهم!

به‌طور پیش‌فرض، `width` فقط محتوا را می‌گیرد و `padding` + `border` به آن اضافه می‌شوند. یعنی:

```css
.box {
  width: 300px;
  padding: 20px;
  border: 5px solid black;
}
/* عرض واقعی = 300 + 40 + 10 = 350px 😱 */
```

با `box-sizing: border-box;` عرض **کل جعبه** ثابت می‌ماند:

```css
* {
  box-sizing: border-box;
}
```

> ✅ **همیشه** این را در ابتدای CSS بنویس. زندگی‌ات را نجات می‌دهد.

## ۶. Overflow

اگر محتوا از جعبه بزرگ‌تر شود:

```css
.box {
  width: 200px;
  height: 100px;
  overflow: hidden;      /* مخفی کردن */
  overflow: scroll;      /* اسکرول همیشه */
  overflow: auto;        /* اسکرول فقط اگر لازم باشد */
}
```

## ۷. Outline (خط دور بدون تأثیر در چیدمان)

```css
.box {
  outline: 2px dashed red;
}
```

تفاوت با `border`: `outline` در چیدمان حساب نمی‌شود (مثل حلقه فوکوس مرورگر).

## ۸. Margin Collapse

اگر دو عنصر عمودی `margin` داشته باشند، مرورگر بزرگ‌ترین را می‌گیرد (نه جمع):

```css
.p1 { margin-bottom: 30px; }
.p2 { margin-top: 20px; }
/* فاصله بینشان = 30px نه 50px */
```

برای دور زدن، از `padding` یا `gap` در flex استفاده کن.

## نکات مهم
1. **همیشه** `* { box-sizing: border-box; }` در بالای CSS.
2. `margin` فاصله بیرونی، `padding` فاصله داخلی. اشتباه نگیر!
3. `padding` رنگ پس‌زمینه دارد، `margin` ندارد (شفاف است).
4. `border-radius: 50%` روی مربع = دایره.
5. `margin: 0 auto;` با `width` مشخص = وسط‌چین افقی.

## تفاوت padding و margin در یک نگاه

```css
.card {
  background-color: white;
  padding: 20px;          /* فاصله سفید داخل جعبه */
  margin: 20px;           /* فاصله بین این جعبه و بقیه */
  border: 1px solid #ccc;
}
```

## تمرین درس ۲
1. کد بالا را بنویس و در مرورگر ببین.
2. `box1` را بدون `box-sizing: border-box` امتحان کن و تفاوت عرض را ببین (با inspect مرورگر).
3. یک `div` با `width: 200px; height: 200px;` بساز و بهش `border-radius: 20px` بده.
4. یک دایره قرمز ۱۵۰×۱۵۰ بساز.
5. یک جعبه با `margin: 0 auto` وسط‌چین کن.

## 🎯 چالش
یک **کارت پروفایل** بساز:
- عرض ۳۰۰ پیکسل
- وسط‌چین
- `padding: 20px`
- `border-radius: 12px`
- `border: 1px solid #ddd`
- `box-shadow` نرم (این را بعداً یاد می‌گیریم، فعلاً امتحان کن: `box-shadow: 0 2px 8px rgba(0,0,0,0.1);`)
- داخلش یک `h2`، یک `p` و یک عکس کوچک با `border-radius: 50%` (دایره)
