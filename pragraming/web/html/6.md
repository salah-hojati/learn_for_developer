## مرور سریع چیزهایی که یاد گرفتی

✅ ساختار صفحه (`DOCTYPE`, `html`, `head`, `body`)  
✅ متن (`h1`-`h6`, `p`, `strong`, `em`, `br`, `hr`)  
✅ لینک و تصویر (`a`, `img`)  
✅ لیست‌ها (`ul`, `ol`, `li`)  
✅ جدول (`table`, `tr`, `th`, `td`, `caption`, `colspan`)  
✅ تگ‌های معنایی (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)  
✅ فرم‌ها (`form`, `input`, `label`, `select`, `textarea`, `button`)  
✅ رسانه‌ها (`video`, `audio`, `picture`, `figure`, `iframe`)

## 🏆 پروژه پایانی HTML: صفحه معرفی خودت

قبل از رفتن به CSS، این پروژه را بساز تا همه چیز را با هم تمرین کنی. حداقل شامل این‌ها باشد:

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>صفحه شخصی من</title>
</head>
<body>
  <header>
    <h1>سلام، من [اسم تو] هستم</h1>
    <nav>
      <a href="#about">درباره</a> |
      <a href="#skills">مهارت‌ها</a> |
      <a href="#contact">تماس</a>
    </nav>
  </header>

  <main>
    <section id="about">
      <h2>درباره من</h2>
      <figure>
        <img src="https://picsum.photos/200" alt="عکس من" width="150">
        <figcaption>این منم!</figcaption>
      </figure>
      <p>من در حال یادگیری <strong>طراحی وب</strong> هستم و <em>عاشق</em> یادگیری چیزهای جدیدم.</p>
    </section>

    <section id="skills">
      <h2>مهارت‌های من</h2>
      <ol>
        <li>HTML — تازه شروع کردم ✅</li>
        <li>CSS — به‌زودی</li>
        <li>JavaScript — بعداً</li>
      </ol>

      <h3>سرگرمی‌ها</h3>
      <ul>
        <li>کتاب</li>
        <li>ورزش</li>
        <li>موسیقی</li>
      </ul>
    </section>

    <section id="contact">
      <h2>با من در تماس باش</h2>
      <form action="#" method="post">
        <p>
          <label for="n">نام:</label><br>
          <input type="text" id="n" name="name" required>
        </p>
        <p>
          <label for="e">ایمیل:</label><br>
          <input type="email" id="e" name="email" required>
        </p>
        <p>
          <label for="m">پیام:</label><br>
          <textarea id="m" name="msg" rows="4" cols="40"></textarea>
        </p>
        <button type="submit">ارسال</button>
      </form>
    </section>
  </main>

  <footer>
    <p>© ۲۰۲۶ — ساخته‌شده با HTML</p>
  </footer>
</body>
</html>
```

خودت اطلاعات را پر کن و اگر خواستی چیزهای بیشتری (ویدیو، جدول، iframe) هم اضافه کن.

# 🎨 حالا بریم CSS!

**CSS** زبان استایل‌دهی است. کاری که CSS می‌کند:

> HTML = **اسکلت** صفحه  
> CSS = **ظاهر** (رنگ، فونت، فاصله، چیدمان، اندازه)

## نقشه راه CSS (۸ درس)

| درس | موضوع |
|-----|-------|
| ۱ | اتصال CSS به HTML، انتخابگرها (Selectors)، رنگ و فونت |
| ۲ | Box Model: `margin`, `padding`, `border`, `width` |
| ۳ | Display و واحدها (`px`, `%`, `rem`, `em`, `vh`, `vw`) |
| ۴ | رنگ‌ها، پس‌زمینه، Gradient |
| ۵ | Flexbox — چیدمان مدرن |
| ۶ | Grid — چیدمان شبکه‌ای |
| ۷ | Position، z-index، سایه‌ها، Transition |
| ۸ | Responsive و Media Query |

بعد از این ۸ درس، می‌توانی یک صفحه واقعاً قشنگ بسازی. ✨
