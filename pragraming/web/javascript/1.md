# Level 1 — Foundations (today)

## 1. Variables

```js
let age = 25;        // can be reassigned
const name = "Sam";  // cannot be reassigned (use this by default)
var old = "avoid";   // legacy — don't use it
```

**Rule:** use `const` unless the value must change, then `let`.

## 2. Data types

```js
let s = "hello";        // string
let n = 42;             // number (no separate int/float)
let b = true;           // boolean
let u = undefined;      // declared but no value
let nul = null;         // intentional "nothing"
let obj = { a: 1 };     // object
let arr = [1, 2, 3];    // array (a kind of object)
```

Check types with `typeof`:

```js
typeof "hi"      // "string"
typeof 42        // "number"
typeof true      // "boolean"
typeof {}        // "object"
typeof []        // "object"  (arrays are objects!)
typeof undefined // "undefined"
```

## 3. Operators

```js
// arithmetic
2 + 3   // 5
10 % 3  // 1  (remainder)
2 ** 3  // 8  (exponent)

// comparison — ALWAYS use === and !==
5 === 5   // true   (strict: value AND type)
5 == "5"  // true   (loose — avoid! it coerces types)
5 === "5" // false

// logical
true && false  // false (AND)
true || false  // true  (OR)
!true          // false (NOT)
```

## 4. Conditionals

```js
const temp = 30;

if (temp > 30) {
  console.log("Hot");
} else if (temp > 20) {
  console.log("Nice");
} else {
  console.log("Cold");
}

// Ternary — one-line if/else
const label = temp > 20 ? "warm" : "cool";
```

## 5. Loops

```js
// for
for (let i = 0; i < 3; i++) {
  console.log(i); // 0, 1, 2
}

// while
let x = 0;
while (x < 3) {
  console.log(x);
  x++;
}

// for...of — iterate values (arrays, strings)
for (const ch of "abc") {
  console.log(ch); // a, b, c
}
```

## 6. Functions

```js
// declaration
function add(a, b) {
  return a + b;
}

// arrow function (modern, concise)
const add2 = (a, b) => a + b;

// default parameters
function greet(name = "friend") {
  return `Hello, ${name}!`;   // template literal with backticks
}

add(2, 3);       // 5
greet();         // "Hello, friend!"
greet("Sam");    // "Hello, Sam!"
```

**Key idea:** functions take inputs (parameters) and **return** outputs. `return` stops the function and sends a value back.

## ✏️ Practice exercises (do these before Level 2)

1. Write a function `isEven(n)` that returns `true`/`false`.
2. Write `max(a, b, c)` that returns the largest of three numbers.
3. Loop from 1 to 20 and print `"Fizz"` if divisible by 3, `"Buzz"` if divisible by 5, `"FizzBuzz"` if both, else the number.
4. Write a function `reverseString(str)` that returns the string backwards (hint: `str.split("").reverse().join("")` — we'll cover arrays next).
5. Write a function `sumTo(n)` that returns `1 + 2 + ... + n` using a loop.
