# CSS Grid — The Complete Beginner's Guide

**CSS Grid** is the most powerful layout system in CSS. While Flexbox handles **1D layouts** (a row *or* a column), Grid handles **2D layouts** (rows *and* columns simultaneously).

```
Flexbox:  →→→→→→→→→   (one direction)
Grid:     ┌───┬───┬───┐
          ├───┼───┼───┤   (rows + columns)
          └───┴───┴───┘
```

---

## 1. The Core Idea

Put `display: grid` on a **container**. Define **columns** and **rows**. Place items into the grid cells.

```html
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
</div>
```

```css
.grid {
  display: grid;
  grid-template-columns: 200px 200px 200px;
  grid-template-rows: 100px 100px;
  gap: 10px;
}
```

Result:
```
┌──────┬──────┬──────┐
│  1   │  2   │  3   │
├──────┼──────┼──────┤
│  4   │      │      │
└──────┴──────┴──────┘
```

---

## 2. Defining Columns & Rows

### Fixed sizes

```css
.grid {
  grid-template-columns: 200px 100px 300px;  /* 3 columns */
  grid-template-rows: 80px 120px;            /* 2 rows */
}
```

### The `fr` unit — "fraction of free space" ⭐

This is Grid's superpower. `fr` divides the available space.

```css
.grid {
  grid-template-columns: 1fr 1fr 1fr;  /* 3 equal columns */
}
.grid {
  grid-template-columns: 2fr 1fr;      /* first col twice as wide */
}
.grid {
  grid-template-columns: 200px 1fr;    /* fixed sidebar + flexible main */
}
```

### `repeat()` — avoid repetition

```css
.grid {
  grid-template-columns: repeat(3, 1fr);        /* = 1fr 1fr 1fr */
  grid-template-columns: repeat(4, 100px);      /* 4 cols of 100px */
}
```

### `minmax()` — flexible min & max

```css
.grid {
  grid-template-columns: repeat(3, minmax(200px, 1fr));
  /* each column: at least 200px, at most 1fr */
}
```

### The magic responsive line 🪄

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}
```

**This is one of the most useful CSS snippets ever written.** It creates:
- As many columns as fit
- Each at least 250px wide
- Fills the row perfectly

Resize the browser and watch it adapt — **no media queries needed!**

## 3. Placing Items in the Grid

By default, items auto-fill cells left-to-right, top-to-bottom. But you can place items **precisely**.

### Grid lines (numbered from 1)

```
       col1      col2      col3
       line1     line2     line3     line4
        │         │         │         │
row1 ───┼─────────┼─────────┼─────────┤
        │         │         │         │
row2 ───┼─────────┼─────────┼─────────┤
        │         │         │         │
row3 ───┼─────────┼─────────┼─────────┘
```

### Position via grid lines

```css
.item {
  grid-column: 1 / 3;    /* start at line 1, end at line 3 (spans 2 cols) */
  grid-row: 1 / 2;       /* start line 1, end line 2 */
}
```

Or use the shorthand:
```css
.item {
  grid-area: 1 / 1 / 2 / 3;
  /* row-start / column-start / row-end / column-end */
}
```

### Span keyword (easier to read)

```css
.item {
  grid-column: span 2;   /* take up 2 columns */
  grid-row: span 2;      /* take up 2 rows */
}
```

## 4. Named Grid Areas ⭐ (the friendliest way)

Give areas **names** and place items by name. This is often the easiest approach for real layouts.

```css
.layout {
  display: grid;
  grid-template-areas:
    "header  header  header"
    "sidebar main    main"
    "footer  footer  footer";
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: 80px 1fr 60px;
  gap: 10px;
  height: 100vh;
}

.header  { grid-area: header;  }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main;    }
.footer  { grid-area: footer;  }
```

```html
<div class="layout">
  <div class="header">Header</div>
  <div class="sidebar">Sidebar</div>
  <div class="main">Main</div>
  <div class="footer">Footer</div>
</div>
```

Result — a classic **holy grail layout**:
```
┌──────────────────────────────┐
│           header             │
├────────┬─────────────────────┤
│sidebar │       main          │
├────────┴─────────────────────┤
│           footer             │
└──────────────────────────────┘
```

The **visual grid map** in `grid-template-areas` literally *looks* like the layout. Beautiful. 🎨

> ⚠️ Every row must have the same number of area names. Use `.` for an empty cell.

## 5. Aligning Items (like Flexbox)

### On the container:

```css
.grid {
  justify-content: center;    /* align the whole grid horizontally */
  align-content: center;      /* align the whole grid vertically */
  justify-items: center;      /* align items inside their cells (horizontal) */
  align-items: center;        /* align items inside their cells (vertical) */
  place-items: center;        /* shorthand for both ⭐ */
}
```

### On individual items:

```css
.item {
  justify-self: end;     /* align one item horizontally in its cell */
  align-self: start;     /* align one item vertically */
  place-self: center;    /* both */
}
```

---

## 6. Grid vs Flexbox — When to Use Which?

| Use **Flexbox** when… | Use **Grid** when… |
|---|---|
| Laying out items in one row *or* column | You need rows *and* columns |
| Aligning items along one axis | You want precise 2D placement |
| Navbar, button group, card contents | Page layout, image gallery, dashboards |
| Content determines size (content-first) | Layout determines size (layout-first) |

> 💡 **In real projects, you use both.** Grid for the page skeleton, Flexbox inside components (navbars, buttons, cards).

## 7. Complete Example — Responsive Photo Gallery

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    * { box-sizing: border-box; margin: 0; }
    body { font-family: Arial, sans-serif; padding: 20px; background: #f4f4f4; }

    .gallery {
      display: grid;
      grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
      gap: 15px;
    }

    .photo {
      background: white;
      border-radius: 10px;
      overflow: hidden;
      box-shadow: 0 2px 8px rgba(0,0,0,0.1);
    }

    .photo img {
      width: 100%;
      height: 150px;
      object-fit: cover;
      display: block;
    }

    .photo p {
      padding: 10px;
      text-align: center;
      color: #555;
    }
  </style>
</head>
<body>
  <div class="gallery">
    <div class="photo"><img src="https://picsum.photos/300/200?1"><p>Photo 1</p></div>
    <div class="photo"><img src="https://picsum.photos/300/200?2"><p>Photo 2</p></div>
    <div class="photo"><img src="https://picsum.photos/300/200?3"><p>Photo 3</p></div>
    <div class="photo"><img src="https://picsum.photos/300/200?4"><p>Photo 4</p></div>
    <div class="photo"><img src="https://picsum.photos/300/200?5"><p>Photo 5</p></div>
    <div class="photo"><img src="https://picsum.photos/300/200?6"><p>Photo 6</p></div>
  </div>
</body>
</html>
```

**One line** — `grid-template-columns: repeat(auto-fit, minmax(200px, 1fr))` — makes it fully responsive. Try resizing the window. 🎯

## 8. Complete Example — Dashboard Layout

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    * { box-sizing: border-box; margin: 0; }
    body { font-family: Arial, sans-serif; }

    .dashboard {
      display: grid;
      grid-template-areas:
        "nav    nav    nav"
        "side   main   main"
        "side   widgets widgets";
      grid-template-columns: 220px 1fr 1fr;
      grid-template-rows: 60px 1fr 150px;
      gap: 12px;
      height: 100vh;
      padding: 12px;
      background: #ecf0f1;
    }

    .nav     { grid-area: nav;     background: #2c3e50; color: white; }
    .side    { grid-area: side;    background: #34495e; color: white; }
    .main    { grid-area: main;    background: white; }
    .widgets { grid-area: widgets; background: white; }

    .dashboard > div {
      border-radius: 8px;
      padding: 20px;
    }
  </style>
</head>
<body>
  <div class="dashboard">
    <div class="nav">Navbar</div>
    <div class="side">Sidebar</div>
    <div class="main">Main content</div>
    <div class="widgets">Widgets</div>
  </div>
</body>
</html>
```

You just built a **real dashboard layout** in ~20 lines of CSS. 🚀

## 9. Cheat Sheet 📋

**Container:**
| Property | Purpose |
|---|---|
| `display` | `grid` |
| `grid-template-columns` | define column sizes |
| `grid-template-rows` | define row sizes |
| `grid-template-areas` | name areas visually |
| `gap` | space between cells |
| `justify-content` / `align-content` | align the whole grid |
| `justify-items` / `align-items` | align items in cells |
| `place-items` | shorthand for both |

**Item:**
| Property | Purpose |
|---|---|
| `grid-column: start / end` | place horizontally |
| `grid-row: start / end` | place vertically |
| `grid-area: name` | place by area name |
| `grid-column: span 2` | span columns |
| `justify-self` / `align-self` | self alignment |
| `place-self` | shorthand |

**Key functions:**
- `repeat(n, size)` — repeat tracks
- `minmax(min, max)` — flexible sizing
- `auto-fit` / `auto-fill` — auto-responsive columns
- `fr` unit — fractions of free space

---

## 10. The Difference: `auto-fit` vs `auto-fill`

```css
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
grid-template-columns: repeat(auto-fit,  minmax(200px, 1fr));
```

- **`auto-fill`** → creates *empty* tracks to fill the row (items stay their min width)
- **`auto-fit`** → *collapses* empty tracks so items stretch to fill

For most responsive layouts → use **`auto-fit`**. ✅

## 12. Debugging Tip 🐛

In Chrome DevTools (F12):
1. Inspect a grid container
2. Look for the **"grid"** badge next to `display: grid`
3. Click it → toggles a **visual overlay** showing grid lines, track numbers, and item placement

This is the single best way to understand a grid you're working with. 🎯
