# Lesson 2: State and events with `useState`

## 1. Why state?

So far, our components only display data passed from outside (props).  
But real apps need to **change** over time: a counter, a form, a toggle, a list.

In React, data that can change inside a component is called **state**.

When state changes, React re-renders the component automatically.

## 2. The `useState` hook

We import it from React:

```jsx
import { useState } from "react";
```

Then inside a component:

```jsx
const [count, setCount] = useState(0);
```

- `count` is the current value.
- `setCount` is the function you call to update it.
- `0` is the initial value.

**Never** do `count = count + 1`. Always use the setter: `setCount(count + 1)`.

## 3. Example: a simple counter

```jsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount(count - 1)}>-1</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}

export default Counter;
```

Use it in `App.jsx`:

```jsx
import Counter from "./Counter";

function App() {
  return (
    <div>
      <Counter />
    </div>
  );
}

export default App;
```

### Key points

- `onClick` is a React event prop. It expects a function.
- We use an arrow function: `() => setCount(count + 1)`.  
  If we wrote `onClick={setCount(count + 1)}`, it would run immediately — wrong.
- Each `Counter` component has its own independent state.

## 4. Another example: toggle visibility

```jsx
import { useState } from "react";

function Toggle() {
  const [isVisible, setIsVisible] = useState(true);

  return (
    <div>
      <button onClick={() => setIsVisible(!isVisible)}>
        {isVisible ? "Hide" : "Show"}
      </button>
      {isVisible && <p>Now you see me!</p>}
    </div>
  );
}
```

- `!isVisible` flips true/false.
- `{isVisible && <p>...</p>}` shows the paragraph only when `isVisible` is true.
