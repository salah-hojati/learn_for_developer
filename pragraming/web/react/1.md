# Lesson 1: React mental model + your first app

## 1. The core idea

React is a JavaScript library for building user interfaces.

The main mental model is:

> UI = f(state)

Meaning: your screen is a function of your data. When data changes, React updates the UI.

A React app is made of **components**. A component is a JavaScript function that returns **JSX**.

Example:

```jsx
function Welcome() {
  return <h1>Hello, React!</h1>;
}
```

`Welcome` is a component. It returns JSX that looks like HTML but is actually JavaScript.

## 2. Setup

Install Node.js if you don’t have it. Then in your terminal:

```bash
npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install
npm run dev
```

Open the local URL it gives you, usually `http://localhost:5173`.

Important files:

- `src/main.jsx` — starts the app
- `src/App.jsx` — your main component
- `src/index.css` — styles

## 3. Your first component edit

Open `src/App.jsx`. Replace everything with:

```jsx
function App() {
  return (
    <div>
      <h1>Hello React</h1>
      <p>This is my first component.</p>
    </div>
  );
}

export default App;
```

Save it. The browser should update automatically.

JSX rules to remember:

1. Return **one parent element**.
2. Use `className`, not `class`.
3. Use `{ }` to insert JavaScript.
4. Component names must start with a capital letter.

## 4. Props: passing data into components

Props are like function arguments for components.

```jsx
function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>;
}

function App() {
  return (
    <div>
      <Greeting name="Alex" />
      <Greeting name="Sam" />
      <Greeting name="Taylor" />
    </div>
  );
}

export default App;
```

Here `name` is a prop. Props are **read-only**. A component should never change its own props.
