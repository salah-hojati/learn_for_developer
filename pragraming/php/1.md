# Stage 1: Setup & Basics

## 1.1 Install PHP

**Option A — Easiest (XAMPP/WAMP/MAMP):**
- Download [XAMPP](https://www.apachefriends.org/) (Windows/Linux) or [MAMP](https://www.mamp.info/) (Mac)
- Install, start **Apache**
- Put your files in `htdocs` (XAMPP) or `htdocs` (MAMP)
- Visit `http://localhost/yourfile.php`

**Option B — PHP built-in server (recommended if you have PHP installed):**
```bash
php -S localhost:8000
```
Then visit `http://localhost:8000/yourfile.php`.

**Check installation:**
```bash
php -v
```

---

## 1.2 Your First PHP File

Create `hello.php`:

```php
<?php
echo "Hello, World!";
?>
```

Open it in your browser. You should see: `Hello, World!`

> **Rule:** PHP code goes inside `<?php ... ?>`. Everything outside those tags is sent as plain HTML.

---

## 1.3 PHP + HTML

```php
<!DOCTYPE html>
<html>
<body>
    <h1><?php echo "My first PHP page"; ?></h1>
    <p>Today is <?php echo date("l, F j, Y"); ?></p>
</body>
</html>
```

You can open and close `<?php ?>` as many times as you want inside HTML.

## 1.4 Variables

Variables start with `$` and don't need type declarations:

```php
<?php
$name = "Alice";
$age = 25;
$height = 1.68;
$isStudent = true;

echo "Name: $name<br>";
echo "Age: $age<br>";
echo "Height: $height<br>";
echo "Student: " . ($isStudent ? "yes" : "no");
?>
```

**Rules:**
- Start with `$`
- Letters, numbers, underscores (can't start with a number)
- Case-sensitive (`$Name` ≠ `$name`)

## 1.5 Data Types

| Type | Example |
|------|---------|
| string | `"hello"`, `'world'` |
| int | `42`, `-7` |
| float | `3.14`, `1.0e3` |
| bool | `true`, `false` |
| array | `[1, 2, 3]` |
| null | `null` |
| object | `new DateTime()` |

**Check the type:**
```php
var_dump($age);      // int(25)
gettype($age);       // "integer"
```

## 1.6 Strings — the essentials

```php
<?php
$first = "John";
$last  = "Doe";

// Concatenation
$full = $first . " " . $last;   // "John Doe"

// Interpolation (double quotes only)
echo "Hello, $first!";          // Hello, John!

// Handy functions
echo strlen("hello");           // 5
echo strtoupper("hello");       // HELLO
echo str_replace("world", "PHP", "hello world"); // hello PHP
echo trim("  hi  ");            // "hi"
?>
```

---

## 1.7 Numbers & Math

```php
<?php
$a = 10;
$b = 3;

echo $a + $b;    // 13
echo $a - $b;    // 7
echo $a * $b;    // 30
echo $a / $b;    // 3.3333...
echo $a % $b;    // 1  (modulus)
echo $a ** $b;   // 1000 (power)

// Rounding
echo round(3.7);   // 4
echo floor(3.7);   // 3
echo ceil(3.1);    // 4
?>
```
