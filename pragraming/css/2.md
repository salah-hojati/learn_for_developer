# CSS Flexbox — The Complete Beginner's Guide

**Flexbox** (Flexible Box Layout) is the modern way to arrange items in a row or column, and to center/space them easily. Once you learn it, you'll use it in almost every project.

---

## 1. The Core Idea

You put `display: flex` on a **container**. Its **direct children** become **flex items** and get arranged automatically.

```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
.container {
  display: flex;
}
```

That's it — the three items now sit in a row. 🎉

```
Before:           After (display: flex):
┌───────┐         ┌──────────────────────┐
│   1   │         │  1  │  2  │  3        │
│   2   │         └──────────────────────┘
│   3   │
└───────┘
```

---

## 2. Two Axes (memorize this!)

Flexbox works along two axes:

```
        main axis (→)  ← controlled by flex-direction
   ┌──────────────────────────────┐
   │  item   item   item          │  cross axis (↓)
   └──────────────────────────────┘
```

- **Main axis** → direction items flow (default: horizontal, left→right)
- **Cross axis** → perpendicular to main axis

---

## 3. Container Properties (set on the parent)

### `flex-direction` — which way items flow

```css
.container { flex-direction: row; }            /* → default */
.container { flex-direction: row-reverse; }    /* ← */
.container { flex-direction: column; }         /* ↓ */
.container { flex-direction: column-reverse; } /* ↑ */
```

### `justify-content` — align along the **main axis**

```css
.container { justify-content: flex-start; }    /* items packed left (default) */
.container { justify-content: flex-end; }      /* packed right */
.container { justify-content: center; }        /* centered */
.container { justify-content: space-between; } /* first & last at edges, even gaps */
.container { justify-content: space-around; }  /* equal space around each */
.container { justify-content: space-evenly; }  /* perfectly even gaps */
```

Visual:
```
space-between:  [1]        [2]        [3]
space-around:    [1]    [2]    [3]
space-evenly:     [1]   [2]   [3]
```

### `align-items` — align along the **cross axis**

```css
.container { align-items: stretch; }     /* fill height (default) */
.container { align-items: flex-start; }  /* top */
.container { align-items: flex-end; }    /* bottom */
.container { align-items: center; }      /* vertically centered ⭐ */
.container { align-items: baseline; }    /* align text baselines */
```

### `flex-wrap` — allow items to wrap to next line

```css
.container { flex-wrap: nowrap; }  /* default, all in one line */
.container { flex-wrap: wrap; }    /* wraps to next line when out of space */
```

### `gap` — space between items (modern & clean)

```css
.container {
  display: flex;
  gap: 20px;          /* space between every item */
  gap: 10px 30px;     /* row-gap column-gap */
}
```

> 💡 **Pro tip:** Use `gap` instead of margins on items — much cleaner.

### `align-content` — like `align-items`, but for **wrapped rows**

Only matters when items wrap onto multiple lines.
```css
.container { align-content: center; }
.container { align-content: space-between; }
```

---

## 4. Item Properties (set on the children)

### `flex-grow` — how much an item expands to fill extra space

```css
.item { flex-grow: 1; }   /* all items grow equally */
```
```
[  1  ][  2  ][  3  ]     ← all flex-grow: 1
[ 1 ][   2 (grow 2)   ]   ← item 2 takes twice the extra space
```

### `flex-shrink` — how much an item shrinks when space is tight

```css
.item { flex-shrink: 1; }  /* default: allowed to shrink */
.item { flex-shrink: 0; }  /* won't shrink — keeps its width */
```

### `flex-basis` — starting size before growing/shrinking

```css
.item { flex-basis: 200px; }
```

### The `flex` shorthand ⭐ (you'll use this most)

```css
.item { flex: 1; }          /* grow:1, shrink:1, basis:0 — equal widths */
.item { flex: 0 0 200px; }  /* fixed 200px, no grow/shrink */
.item { flex: 2; }          /* takes twice the space of flex:1 siblings */
```

### `align-self` — override `align-items` for one item

```css
.item.special {
  align-self: flex-end;   /* this one goes to the bottom */
}
```

### `order` — reorder items visually

```css
.item { order: 0; }        /* default */
.item.first { order: -1; } /* appears first */
```

## 5. The Famous Centering Trick ⭐

Centering something used to be painful. Flexbox makes it one line:

```css
.container {
  display: flex;
  justify-content: center;  /* horizontal */
  align-items: center;      /* vertical */
  height: 100vh;            /* full viewport height */
}
```

Perfectly centered — horizontally AND vertically. This is one of the most-used CSS snippets ever.

## 6. Complete Example — A Navbar

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    * { box-sizing: border-box; margin: 0; }
    body { font-family: Arial, sans-serif; }

    .navbar {
      display: flex;
      justify-content: space-between;  /* logo left, links right */
      align-items: center;             /* vertically centered */
      padding: 15px 30px;
      background: #2c3e50;
      color: white;
    }

    .logo {
      font-size: 22px;
      font-weight: bold;
    }

    .links {
      display: flex;
      gap: 20px;
      list-style: none;
    }

    .links a {
      color: white;
      text-decoration: none;
    }

    .links a:hover {
      color: #3498db;
    }

    .btn {
      background: #3498db;
      padding: 8px 16px;
      border-radius: 5px;
    }
  </style>
</head>
<body>
  <nav class="navbar">
    <div class="logo">MySite</div>
    <ul class="links">
      <li><a href="#">Home</a></li>
      <li><a href="#">About</a></li>
      <li><a href="#">Contact</a></li>
      <li><a href="#" class="btn">Sign Up</a></li>
    </ul>
  </nav>
</body>
</html>
```

Two flex containers here:
1. `.navbar` → logo on left, links on right
2. `.links` → links in a row with equal gaps

## 7. Example — Cards Row That Wraps

```css
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
  padding: 20px;
}

.card {
  flex: 1 1 250px;          /* grow, shrink, min-width 250px */
  background: white;
  border-radius: 10px;
  padding: 20px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}
```

- On wide screens: 3–4 cards per row
- On narrow screens: cards wrap to fewer columns automatically
- `flex: 1 1 250px` means "be at least 250px, grow to fill space"

This is a **responsive card layout in 6 lines of CSS** — no media queries needed!

## 8. Cheat Sheet 📋

**Container:**
| Property | Values |
|---|---|
| `display` | `flex` |
| `flex-direction` | `row` `column` `row-reverse` `column-reverse` |
| `justify-content` | `flex-start` `center` `flex-end` `space-between` `space-around` `space-evenly` |
| `align-items` | `stretch` `flex-start` `center` `flex-end` `baseline` |
| `flex-wrap` | `nowrap` `wrap` |
| `gap` | any length |
| `align-content` | (for wrapped lines) |

**Item:**
| Property | Purpose |
|---|---|
| `flex` | shorthand: `grow shrink basis` |
| `flex-grow` | how much to expand |
| `flex-shrink` | how much to shrink |
| `flex-basis` | starting size |
| `align-self` | override alignment for one item |
| `order` | reorder |

## 9. Practice Tasks 🏋️

Try these to lock it in:

1. **Center a box** — one div, centered both ways in the viewport.
2. **Navbar** — logo left, three links right, all vertically centered.
3. **Three equal columns** — 3 divs, each `flex: 1`, with `gap: 16px`.
4. **Holy grail layout** — header on top, footer on bottom, sidebar + main content in the middle (hint: `flex-direction: column` on the page wrapper).
5. **Profile card** — avatar on the left, name & bio on the right, using `flex` + `align-items: center`.

---

## 10. Debugging Tip 🐛

If flexbox isn't behaving, add a temporary border to see the boxes:

```css
* { border: 1px solid red; }
```

Or open your browser's DevTools (F12) → inspect the container → look for the **flex** badge. It shows an overlay of the flex axes and item sizes in real time. 🎯
