## فصل ۱: آشنایی با jQuery و راه‌اندازی

### ۱.۱ jQuery چیست و چرا از آن استفاده می‌کنیم؟
- تعریف jQuery به عنوان یک کتابخانه سریع و مختصر جاوااسکریپت
- مزایا: سادگی در نوشتن کد، سازگاری با مرورگرهای مختلف، جامعه بزرگ کاربران، و وجود پلاگین‌های فراوان

### ۱.۲ نصب و افزودن jQuery به صفحه
- دانلود فایل jQuery از سایت رسمی (نسخه فشرده‌شده برای کاهش حجم)
- افزودن از طریق CDN (مثلاً Google CDN)
- قرار دادن تگ `<script>` در HTML و بررسی صحت بارگذاری با کنسول مرورگر (`$` یا `jQuery`)

### ۱.۳ ساختار و سینتکس پایه
- تابع اصلی `$()` و تفاوت آن با `jQuery()`
- رویداد `$(document).ready()` برای اجرای کد پس از آماده شدن DOM

```javascript
$(document).ready(function() {
  // کدهای jQuery در اینجا قرار می‌گیرد
});
```

## فصل ۲: انتخابگرها (Selectors)

### ۲.۱ انتخابگرهای پایه
- انتخاب بر اساس **عنصر** (`$("p")`)، **کلاس** (`$(".myClass")`)، و **شناسه** (`$("#myId")`)
- انتخابگرهای ترکیبی و سلسله‌مراتبی

### ۲.۲ انتخابگرهای پیشرفته
- انتخابگرهای موقعیت (`:first`، `:last`، `:even`، `:odd`)
- انتخابگرهای فرم (`:input`، `:checkbox`، `:selected`)
- انتخابگرهای سفارشی و فیلترها

### ۲.۳ ذخیره‌سازی انتخابگرها (Caching)
- ذخیره نتیجه انتخاب در یک متغیر برای جلوگیری از جستجوی مکرر در DOM

## فصل ۳: رویدادها (Events)

### ۳.۱ اتصال رویدادها
- متدهای `click()`، `hover()`، `mouseenter()`، `mouseleave()`
- متد `on()` به عنوان روش مدرن و قدرتمند اتصال رویدادها

### ۳.۲ رویدادهای صفحه‌کلید و فرم
- رویدادهای `keyup`، `keydown`، `keypress`
- رویداد `submit` فرم‌ها و جلوگیری از رفتار پیش‌فرض با `event.preventDefault()`

### ۳.۳ مفاهیم پیشرفته رویداد
- **تفویض رویداد (Event Delegation)** با `on()` برای عناصر پویا
- **فضای نام رویداد (Event Namespace)** برای مدیریت بهتر رویدادها
- **رویدادهای سفارشی** و `trigger()`

## فصل ۷: AJAX با jQuery

### ۷.۱ مقدمه‌ای بر AJAX
- مفهوم درخواست‌های ناهمگام و نقش آن در بارگذاری داده بدون رفرش صفحه

### ۷.۲ متدهای مختصر AJAX
- `$.get()`، `$.post()`، `$.getJSON()`، `$.load()`

### ۷.۳ متد اصلی `$.ajax()`
- تنظیمات کامل (URL، type، data، dataType، success، error)

```javascript
$.ajax({
  url: "data.json",
  type: "GET",
  dataType: "json",
  success: function(data) {
    console.log(data);
  },
  error: function(xhr, status, error) {
    console.error(error);
  }
});
```
