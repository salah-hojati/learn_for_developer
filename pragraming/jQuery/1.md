# جلسه ۱: آشنایی با jQuery و راه‌اندازی

## 🎯 اهداف این جلسه
- jQuery چیست و چه کاری انجام می‌دهد؟
- چطور jQuery را به صفحه HTML اضافه کنیم؟
- اولین کد jQuery را بنویسیم.
- با `$`، انتخابگر ساده و رویداد `click` آشنا شویم.

---

## ۱. jQuery چیست؟
**jQuery** یک کتابخانه سریع و سبک از **JavaScript** است که کارهایی مثل:
- انتخاب عناصر HTML
- تغییر محتوا و استایل
- مدیریت رویدادها (کلیک، هاور، ارسال فرم و...)
- انیمیشن
- درخواست‌های AJAX

را بسیار ساده‌تر از JavaScript خالص می‌کند.

⚠️ نکته مهم: jQuery **خودش یک زبان جدید نیست**؛ یک کتابخانه JavaScript است. پس دانش پایه JavaScript لازم است.

---

## ۲. اضافه کردن jQuery به صفحه
ساده‌ترین راه، استفاده از **CDN** است. داخل تگ `<head>` این خط را اضافه کن:
</div>

```html
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
این نسخه ۳.۷.۱ است و برای این دوره از همین استفاده می‌کنیم.

---

## ۳. ساختار آماده‌سازی صفحه
کد jQuery را باید بعد از بارگذاری jQuery و معمولاً بعد از آماده شدن DOM بنویسیم:
</div>

```javascript
$(document).ready(function() {
  // کدهای jQuery
});
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
یا شکل کوتاه‌تر و رایج‌تر:
</div>

```javascript
$(function() {
  // کدهای jQuery
});
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
این یعنی: «صبر کن تا HTML کامل بارگذاری شود، بعد کدها را اجرا کن.»

---

## ۴. اولین مثال کامل

یک فایل به نام `index.html` بساز و این کد را داخلش قرار بده:
</div>

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>جلسه ۱ jQuery</title>
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
</head>
<body>

  <h1 id="title">سلام jQuery</h1>
  <button id="btn">تغییر متن</button>

  <script>
    $(function() {
      $("#btn").click(function() {
        $("#title").text("اولین کد jQuery اجرا شد!");
      });
    });
  </script>

</body>
</html>
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

### این کد چه می‌کند؟
- `$("#btn")` → دکمه با شناسه `btn` را انتخاب می‌کند.
- `.click(function(){...})` → وقتی روی دکمه کلیک شد، تابع اجرا شود.
- `$("#title")` → عنوان با شناسه `title` را انتخاب می‌کند.
- `.text("...")` → متن آن را تغییر می‌دهد.

---

## ۵. نکته‌های مهم
- علامت `$` همان `jQuery` است؛ این دو یکی هستند:

</div>

  ```javascript
  $("#title")
  jQuery("#title")
  ```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
- اگر کد کار نکرد، اول مطمئن شو jQuery درست لود شده است. در کنسول مرورگر (F12) بنویس:
</div>

  ```javascript
  $
  ```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
  اگر تابع نشان داد، jQuery لود شده است.
- کدهای jQuery را بهتر است قبل از بسته شدن `</body>` یا داخل `$(function(){})` بنویسی.
