# جلسه ۵: دستکاری DOM و محتوا

## 🎯 اهداف این جلسه
- خواندن و نوشتن محتوا با `text()`، `html()`، `val()`
- افزودن و حذف عناصر با `append()`، `prepend()`، `after()`، `before()`، `remove()`، `empty()`
- کار با کلاس‌ها با `addClass()`، `removeClass()`، `toggleClass()`، `hasClass()`
- کار با ویژگی‌ها (Attributes) با `attr()`، `prop()`، `removeAttr()`
- استایل‌دهی با `css()` و گرفتن ابعاد

---

## ۱. خواندن و نوشتن محتوا

### `text()` — متن خالص
```javascript
// خواندن
var content = $("#box").text();

// نوشتن (تگ‌های HTML را به عنوان متن نمایش می‌دهد)
$("#box").text("سلام <b>دنیا</b>");
// خروجی: سلام <b>دنیا</b>  (تگ اجرا نمی‌شود)
```

### `html()` — محتوای HTML
```javascript
// خواندن
var content = $("#box").html();

// نوشتن (تگ‌ها اجرا می‌شوند)
$("#box").html("سلام <b>دنیا</b>");
// خروجی: سلام **دنیا** (بولد شده)
```

### `val()` — مقدار ورودی‌ها
```javascript
// خواندن مقدار input
var name = $("#name").val();

// نوشتن مقدار
$("#name").val("علی");

// برای select
$("#city").val("shiraz");

// برای textarea
$("#msg").val("متن جدید");
```

**نکته امنیتی:** هنگام نمایش داده‌های کاربر از `text()` استفاده کن، نه `html()`؛ چون `html()` می‌تواند منجر به حملات XSS شود.

---

## ۲. افزودن عناصر

```javascript
$("#list").append("<li>آیتم جدید</li>");    // به انتهای عنصر
$("#list").prepend("<li>آیتم اول</li>");   // به ابتدای عنصر
$("#list").after("<p>بعد از لیست</p>");     // بعد از خود عنصر
$("#list").before("<p>قبل از لیست</p>");    // قبل از خود عنصر
```

### تفاوت append با after
- `append` → **داخل** عنصر، به انتها
- `after` → **بیرون** عنصر، بلافاصله بعد از آن

### افزودن عنصر ساخته‌شده با jQuery
```javascript
var $newItem = $("<li>").text("آیتم ساخته‌شده");
$("#list").append($newItem);
```
یا با ویژگی‌ها:
```javascript
$("<a>").attr("href", "https://example.com").text("لینک").appendTo("#container");
```

---

## ۳. حذف و خالی کردن

```javascript
$("#item").remove();   // عنصر و رویدادهایش کاملاً حذف می‌شود
$("#list").empty();    // محتوای داخل را خالی می‌کند (خود عنصر می‌ماند)
$("#item").detach();   // مثل remove، اما رویدادها و داده‌ها حفظ می‌شوند
```

### تفاوت remove با detach
- `remove()` → عنصر + رویدادها + داده‌ها حذف می‌شوند
- `detach()` → عنصر حذف می‌شود اما می‌توان بعداً همان را با رویدادهایش برگرداند

```javascript
var $el = $("#item").detach();   // جدا کن
$("#container").append($el);     // دوباره وصل کن (رویدادها حفظ شده‌اند)
```

## ۴. کار با کلاس‌ها

```javascript
$("#box").addClass("active");        // افزودن کلاس
$("#box").removeClass("active");     // حذف کلاس
$("#box").toggleClass("active");     // جابه‌جایی (دارد → حذف، ندارد → افزودن)

// بررسی وجود کلاس
if ($("#box").hasClass("active")) {
  console.log("کلاس active دارد");
}

// چند کلاس با هم
$("#box").addClass("red big bold");
```

**مثال کاربردی:** دکمه‌ای که حالت فعال/غیرفعال را عوض می‌کند
```html
<button id="toggleBtn">فعال/غیرفعال</button>
<div id="box" style="padding:20px;background:#eee;">جعبه</div>

<script>
$(function() {
  $("#toggleBtn").on("click", function() {
    $("#box").toggleClass("active");
    // برای دیده شدن تغییر، CSS لازم است
  });
});
</script>

<style>
  .active { background: gold; }
</style>
```

## ۵. کار با ویژگی‌ها (Attributes)

### `attr()` — ویژگی‌های HTML
```javascript
// خواندن
var href = $("#link").attr("href");
var title = $("#img").attr("title");

// نوشتن
$("#link").attr("href", "https://google.com");
$("#img").attr("alt", "تصویر جدید");

// چند ویژگی با هم
$("#img").attr({
  src: "new.jpg",
  alt: "تصویر جدید",
  width: 300
});

// حذف
$("#link").removeAttr("target");
```

### `prop()` — ویژگی‌های DOM (مخصوص چک‌باکس و رادیو)
```javascript
// برای checked، disabled، selected از prop استفاده کن
$("#check").prop("checked", true);
$("#btn").prop("disabled", true);

var isChecked = $("#check").prop("checked");
```

**تفاوت `attr` و `prop`:**
- `attr` → مقدار اولیه‌ای که در HTML نوشته شده
- `prop` → وضعیت فعلی عنصر در DOM
- برای `checked`، `disabled`، `selected` همیشه از `prop` استفاده کن.

## ۶. استایل‌دهی با `css()`

```javascript
// خواندن
var color = $("#box").css("color");
var width = $("#box").css("width");

// نوشتن یک ویژگی
$("#box").css("color", "red");

// چند ویژگی با هم
$("#box").css({
  "background-color": "lightblue",
  "font-size": "20px",
  "border-radius": "8px"
});
```
⚠️ در نام‌های CSS با خط تیره، از **کوتیشن** استفاده کن یا از حالت camelCase:
```javascript
$("#box").css("background-color", "red");   // ✅
$("#box").css("backgroundColor", "red");    // ✅
```

## ۷. ابعاد عناصر

```javascript
$("#box").width();       // عرض محتوا (بدون padding و border)
$("#box").height();      // ارتفاع محتوا

$("#box").innerWidth();  // عرض + padding
$("#box").outerWidth();  // عرض + padding + border
$("#box").outerWidth(true); // + margin
```

**مثال: تنظیم عرض**
```javascript
$("#box").width(300);      // عرض را ۳۰۰px کن
$("#box").height("50%");   // به درصد هم می‌شود
```

## ۸. مثال جامع: لیست کارها (To-Do List)

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>To-Do List</title>
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <style>
    .done { text-decoration: line-through; color: gray; }
    li { cursor: pointer; padding: 5px; }
  </style>
</head>
<body>
  <input type="text" id="taskInput" placeholder="کار جدید...">
  <button id="addBtn">افزودن</button>
  <ul id="taskList"></ul>

  <script>
    $(function() {
      $("#addBtn").on("click", function() {
        var task = $("#taskInput").val().trim();
        if (task === "") return;

        // ساخت آیتم جدید
        var $li = $("<li>").text(task);
        $li.append(" ");
        var $del = $("<button>").text("حذف").addClass("del");
        $li.append($del);

        $("#taskList").append($li);
        $("#taskInput").val("").focus();
      });

      // تفویض رویداد برای آیتم‌های پویا
      $("#taskList").on("click", "li", function(event) {
        if ($(event.target).hasClass("del")) {
          $(this).remove();
        } else {
          $(this).toggleClass("done");
        }
      });
    });
  </script>
</body>
</html>
```

**در این مثال:**
- `val()` برای گرفتن و خالی کردن ورودی
- `$("<li>")` برای ساخت عنصر جدید
- `text()` برای نوشتن متن امن
- `append()` برای افزودن
- `remove()` برای حذف
- `toggleClass()` برای تغییر وضعیت
- `hasClass()` برای تشخیص دکمه حذف

---

## ۹. نکته‌های کلیدی
- `text()` امن است؛ `html()` فقط برای محتوای مطمئن.
- برای چک‌باکس و رادیو از `prop()` استفاده کن، نه `attr()`.
- `remove()` رویدادها را هم پاک می‌کند؛ `detach()` نگه می‌دارد.
- `empty()` محتوا را خالی می‌کند اما خود عنصر باقی می‌ماند.
- عناصر پویا → رویدادها را با **تفویض** (جلسه ۳) روی والد ببند.

---

## ✍️ تمرین این جلسه
1. یک `<div>` با متن بساز و با کلیک روی دکمه، متن آن را با `text()` تغییر بده.
2. با کلیک روی دکمه‌ای دیگر، همین div را با `html()` به `<b>متن بولد</b>` تبدیل کن و تفاوت را ببین.
3. یک چک‌باکس بساز و با کلیک روی دکمه‌ای، وضعیت `checked` آن را با `prop()` تغییر بده.
4. یک `<ul>` خالی بساز و با کلیک روی دکمه، سه آیتم با `append()` اضافه کن.

---

## 📝 تکلیف
یک **گالری تصاویر ساده** بساز:
- یک `<div>` بزرگ برای نمایش تصویر اصلی
- سه تصویر کوچک (thumbnail) در پایین
- با کلیک روی هر thumbnail، آدرس آن با `attr("src", ...)` روی تصویر اصلی تنظیم شود.
- تصویر فعال با `addClass` و `removeClass` حاشیه رنگی بگیرد.
