# جلسه ۳: رویدادها (Events) در jQuery

## 🎯 اهداف این جلسه
- اتصال رویدادها با `click()`، `hover()` و `on()`
- رویدادهای صفحه‌کلید و فرم
- جلوگیری از رفتار پیش‌فرض با `preventDefault()`
- آشنایی مقدماتی با **تفویض رویداد (Event Delegation)**

---

## ۱. رویداد چیست؟
رویداد = اتفاقی که در صفحه می‌افتد (کلیک، تایپ، ارسال فرم، حرکت ماوس و...).  
jQuery به ما اجازه می‌دهد به این اتفاقات «گوش بدهیم» و واکنش نشان دهیم.

---

## ۲. رویداد کلیک
```javascript
$("#btn").click(function() {
  alert("کلیک شد!");
});
```
رویدادهای مشابه: `dblclick()` (دوبار کلیک)

---

## ۳. رویدادهای ماوس
```javascript
$("#box").mouseenter(function() {
  $(this).css("background", "lightblue");
});

$("#box").mouseleave(function() {
  $(this).css("background", "white");
});
```
- `mouseenter` / `mouseleave` → ورود و خروج ماوس (بدون تکرار)
- `hover()` → ترکیب هر دو در یک متد:
```javascript
$("#box").hover(
  function() { $(this).css("background", "lightblue"); },  // ورود
  function() { $(this).css("background", "white"); }       // خروج
);
```

---

## ۴. رویدادهای صفحه‌کلید
```javascript
$("#input").keyup(function() {
  console.log("کاراکتر تایپ شد: " + $(this).val());
});

$("#input").keydown(function(event) {
  console.log("کد کلید: " + event.key);
});
```
- `keyup` → بعد از رها کردن کلید (مناسب برای گرفتن مقدار ورودی)
- `keydown` → هنگام فشار دادن کلید
- `keypress` → هنگام تایپ کاراکتر (برای کلیدهای ویژه مثل Shift کار نمی‌کند)

**مثال کاربردی:** نمایش زنده تعداد کاراکترها
```html
<textarea id="txt"></textarea>
<p id="count">۰ کاراکتر</p>

<script>
$(function() {
  $("#txt").keyup(function() {
    var len = $(this).val().length;
    $("#count").text(len + " کاراکتر");
  });
});
</script>
```

---

## ۵. رویدادهای فرم
```javascript
$("form").submit(function(event) {
  event.preventDefault(); // جلوگیری از ارسال واقعی فرم
  console.log("فرم ارسال شد (شبیه‌سازی)");
});
```
- `submit()` → هنگام ارسال فرم
- `change()` → وقتی مقدار یک ورودی تغییر کند (مفید برای `select` و `checkbox`)
- `focus()` / `blur()` → گرفتن و از دست دادن فوکوس

**مثال:** اعتبارسنجی ساده
```html
<form id="myForm">
  <input type="text" id="name" placeholder="نام خود را وارد کنید">
  <button type="submit">ارسال</button>
</form>
<p id="result"></p>

<script>
$(function() {
  $("#myForm").submit(function(event) {
    event.preventDefault();
    var name = $("#name").val().trim();
    if (name === "") {
      $("#result").text("لطفاً نام را وارد کنید!").css("color", "red");
    } else {
      $("#result").text("خوش آمدی " + name).css("color", "green");
    }
  });
});
</script>
```

## ۶. متد `on()` — روش مدرن و قدرتمند
در jQuery جدید، `on()` روش اصلی اتصال رویدادهاست و انعطاف بیشتری دارد:

```javascript
$("#btn").on("click", function() {
  alert("کلیک با on()");
});
```

### اتصال چند رویداد به یک عنصر
```javascript
$("#input").on({
  keyup: function() { console.log("تایپ"); },
  focus: function() { console.log("فوکوس گرفت"); },
  blur:  function() { console.log("فوکوس رفت"); }
});
```

### حذف رویداد با `off()`
```javascript
$("#btn").off("click");
```

## ۷. تفویض رویداد (Event Delegation) — مهم!
مشکل: اگر عنصری **بعداً** به صفحه اضافه شود، رویدادهای متصل مستقیم روی آن کار نمی‌کنند.  
راه‌حل: رویداد را روی **والد** متصل می‌کنیم و انتخابگر فرزند را می‌دهیم.

```html
<ul id="list">
  <li>آیتم ۱</li>
  <li>آیتم ۲</li>
</ul>
<button id="add">افزودن آیتم</button>

<script>
$(function() {
  // تفویض: حتی آیتم‌های جدید هم کلیک‌پذیرند
  $("#list").on("click", "li", function() {
    $(this).toggleClass("done");
  });

  $("#add").on("click", function() {
    $("#list").append("<li>آیتم جدید</li>");
  });
});
</script>
```
✅ اگر به جای `$("#list").on(...)` از `$("li").click(...)` استفاده می‌کردیم، آیتم‌های جدید واکنش نمی‌دادند. **این مفهوم در پروژه‌ها خیلی پرکاربرد است.**

---

## ۸. نکته‌های کلیدی
- برای عناصر ثابت می‌توان از `click()` استفاده کرد، اما **عادت کن از `on()` استفاده کنی**.
- همیشه پارامتر `event` را بگیر و در صورت نیاز `event.preventDefault()` بزن.
- برای عناصر پویا از **تفویض رویداد** استفاده کن.

---

## ✍️ تمرین این جلسه
1. یک `textarea` بساز که با تایپ، تعداد کاراکترها را زیر آن نشان دهد.
2. یک لیست بساز و دکمه‌ای برای افزودن آیتم جدید. با کلیک روی هر آیتم، رنگ آن تغییر کند (با `on` و delegation).
3. فرمی با فیلد ایمیل بساز که اگر خالی بود پیام خطا نشان دهد و از ارسال جلوگیری کند.
