Learning Apache Struts 1.3 is a great way to understand the foundations of Java web development, even though it's considered a legacy framework today. It's built on the Model-View-Controller (MVC) design pattern, which is a core concept in modern web frameworks.

Here is a structured guide to help you get started with Struts 1.3.

### 🏛️ Understand the Core: The MVC Architecture

Struts 1.3 is an implementation of the **Model 2** architecture, a variation of MVC specifically for web applications. Understanding these three layers is key:

*   **Model**: This represents your application's data and business logic. It typically consists of JavaBeans that interact with a database.
*   **View**: This is the user interface, usually built with JSP (JavaServer Pages) and Struts' custom tag libraries, like the `html` and `bean` tags.
*   **Controller**: This is the heart of the framework. It's responsible for receiving user requests and directing them to the appropriate application logic. The controller is primarily composed of the **`ActionServlet`** and your custom **`Action`** classes.

### 🧩 Meet the Key Components

To build a Struts 1.3 application, you'll work with these core components:

| Component | Role |
| :--- | :--- |
| **`ActionServlet`** | The central controller. It's configured in your `web.xml` file to intercept specific URLs and manage the request processing flow. |
| **`Action`** | You'll write classes that extend `Action`. Each one handles a specific type of request (e.g., a login submission) and contains your business logic. Its `execute` method returns an `ActionForward` to tell the framework where to go next. |
| **`ActionForm`** | A JavaBean that acts as a buffer to hold data entered by the user in an HTML form. It's automatically populated by the framework from the request parameters. |
| **`ActionForward`** | An object that represents a destination, like a JSP page. It's used by an `Action` to direct the user to the next view after processing. |
| **`struts-config.xml`** | The central configuration file that ties everything together. It maps form beans to actions and defines the navigation flow (forwards) for your application. |

### 🗺️ Your Step-by-Step Learning Path

The official Struts documentation outlines a typical development sequence. Here’s a practical path to follow:

1.  **Set Up Your Environment**: You'll need the **Java Development Kit (JDK)**, a web server like **Apache Tomcat**, and the **Struts 1.3 libraries** (JAR files). An IDE like **Eclipse** or **MyEclipse** will make development much easier.
2.  **Create Your First JSP (The View)**: Start by creating a simple JSP page with a form. Use the Struts `html` tag library to create form elements (e.g., `<html:form>`, `<html:text>`) that link to your `ActionForm` properties.
3.  **Create an `ActionForm`**: Write a Java class that extends `ActionForm`. For each property in your JSP form, create a corresponding `getter` and `setter` method. For example, a `city` input field needs a `getCity()` and `setCity()` method.
4.  **Create an `Action` Class**: Write a class that extends `Action` and override the `execute` method. This is where you'll place your logic. The method receives the `ActionForm` (pre-populated with user data), the `ActionMapping`, and the request/response objects.
5.  **Configure `struts-config.xml`**: This is the crucial step. You need to:
    *   **Form Beans**: Declare your `ActionForm` using `<form-bean>` elements.
    *   **Actions**: Map a URL path to your `Action` class using `<action>` elements. Associate the form bean with the action and define `<forward>` elements to specify where to go on success or failure.
6.  **Update `web.xml`**: Configure the `ActionServlet` in your deployment descriptor to handle incoming requests. You'll also need to specify the location of your `struts-config.xml` file.

### 💡 A Simple Example: The "Hello World" of Struts

Let's look at a minimal example of how a `struts-config.xml` and an `Action` class connect:

**A snippet from `struts-config.xml`:**

```xml
<form-beans>
    <form-bean name="helloForm" type="com.example.HelloForm"/>
</form-beans>
<action-mappings>
    <action path="/hello"
            type="com.example.HelloAction"
            name="helloForm"
            validate="true"
            input="/hello.jsp">
        <forward name="success" path="/welcome.jsp"/>
        <forward name="failure" path="/hello.jsp"/>
    </action>
</action-mappings>
```

**The corresponding `HelloAction.java`:**

```java
package com.example;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import org.apache.struts.action.Action;
import org.apache.struts.action.ActionForm;
import org.apache.struts.action.ActionForward;
import org.apache.struts.action.ActionMapping;

public class HelloAction extends Action {
    @Override
    public ActionForward execute(ActionMapping mapping, ActionForm form,
                                 HttpServletRequest request, HttpServletResponse response) 
            throws Exception {
        
        HelloForm helloForm = (HelloForm) form;
        String userName = helloForm.getName();

        if (userName != null && !userName.isEmpty()) {
            request.setAttribute("userName", userName);
            return mapping.findForward("success");
        } else {
            return mapping.findForward("failure");
        }
    }
}
```
