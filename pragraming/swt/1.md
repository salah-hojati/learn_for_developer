Here is a complete, step-by-step guide to setting up a simple SWT project using Maven. This setup is designed to automatically detect your operating system and download the correct native SWT libraries.

### 📁 Step 1: Create the Project Structure
First, create a standard Maven directory layout for your project. You can do this manually or let your IDE handle it. The structure should look like this:

```
my-swt-app/
├── pom.xml
└── src/
    └── main/
        └── java/
            └── com/
                └── example/
                    └── swt/
                        └── HelloWorld.java
```

### 📄 Step 2: Configure the `pom.xml`
The most important part of the setup is the `pom.xml`. Because SWT uses native libraries, you need to ensure Maven fetches the correct JAR file for your specific operating system (Windows, macOS, or Linux) and architecture (Intel or ARM).

The following configuration uses the `os-maven-plugin` to automatically detect your environment and activate the right dependency using Maven profiles. This means the same `pom.xml` will work on almost any developer's machine.

Create a file named `pom.xml` in your project root and paste the following content:

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example.swt</groupId>
    <artifactId>my-swt-app</artifactId>
    <version>1.0.0-SNAPSHOT</version>
    <packaging>jar</packaging>

    <properties>
        <maven.compiler.source>17</maven.compiler.source>
        <maven.compiler.target>17</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <swt.version>3.124.200</swt.version>
    </properties>

    <build>
        <extensions>
            <!-- Detects os.detected.classifier: windows-x86_64, osx-aarch_64, etc. -->
            <extension>
                <groupId>kr.motd.maven</groupId>
                <artifactId>os-maven-plugin</artifactId>
                <version>1.7.1</version>
            </extension>
        </extensions>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-compiler-plugin</artifactId>
                <version>3.11.0</version>
            </plugin>
        </plugins>
    </build>

    <profiles>
        <!-- Windows 64-bit -->
        <profile>
            <id>windows-x86_64</id>
            <activation>
                <os><family>windows</family><arch>amd64</arch></os>
            </activation>
            <dependencies>
                <dependency>
                    <groupId>org.eclipse.platform</groupId>
                    <artifactId>org.eclipse.swt.win32.win32.x86_64</artifactId>
                    <version>${swt.version}</version>
                </dependency>
            </dependencies>
        </profile>
        <!-- macOS Intel -->
        <profile>
            <id>macos-x86_64</id>
            <activation>
                <os><family>mac</family><arch>x86_64</arch></os>
            </activation>
            <dependencies>
                <dependency>
                    <groupId>org.eclipse.platform</groupId>
                    <artifactId>org.eclipse.swt.cocoa.macosx.x86_64</artifactId>
                    <version>${swt.version}</version>
                </dependency>
            </dependencies>
        </profile>
        <!-- macOS Apple Silicon (M-series ARM64) -->
        <profile>
            <id>macos-aarch64</id>
            <activation>
                <os><family>mac</family><arch>aarch64</arch></os>
            </activation>
            <dependencies>
                <dependency>
                    <groupId>org.eclipse.platform</groupId>
                    <artifactId>org.eclipse.swt.cocoa.macosx.aarch64</artifactId>
                    <version>${swt.version}</version>
                </dependency>
            </dependencies>
        </profile>
        <!-- Linux 64-bit AMD/Intel -->
        <profile>
            <id>linux-x86_64</id>
            <activation>
                <os><family>unix</family><name>linux</name><arch>amd64</arch></os>
            </activation>
            <dependencies>
                <dependency>
                    <groupId>org.eclipse.platform</groupId>
                    <artifactId>org.eclipse.swt.gtk.linux.x86_64</artifactId>
                    <version>${swt.version}</version>
                </dependency>
            </dependencies>
        </profile>
    </profiles>
</project>
```
This configuration is adapted from a production-ready example that supports Windows, macOS (Intel and Apple Silicon), and Linux.

### ☕ Step 3: Write the HelloWorld Java Class
Now, create the Java class that will contain your SWT application. This example creates a window with a label, a text field, and a button that updates the label when clicked. This is the same code provided in the official Eclipse SWT README.

Create the file `src/main/java/com/example/swt/HelloWorld.java` and paste this code:

```java
package com.example.swt;

import org.eclipse.swt.SWT;
import org.eclipse.swt.layout.GridData;
import org.eclipse.swt.layout.GridLayout;
import org.eclipse.swt.widgets.Button;
import org.eclipse.swt.widgets.Display;
import org.eclipse.swt.widgets.Label;
import org.eclipse.swt.widgets.Shell;
import org.eclipse.swt.widgets.Text;

public class HelloWorld {
    public static void main(String[] args) {
        // 1. Create the Display (handles the OS event loop) and Shell (the window)
        final Display display = new Display();
        final Shell shell = new Shell(display);
        shell.setText("Hello World");
        shell.setLayout(new GridLayout(2, false));

        // 2. Create the widgets
        final Label label = new Label(shell, SWT.LEFT);
        label.setText("Your &Name:");
        label.setLayoutData(new GridData(SWT.FILL, SWT.CENTER, false, false));

        final Text text = new Text(shell, SWT.BORDER | SWT.SINGLE);
        final GridData data = new GridData(SWT.FILL, SWT.CENTER, true, false);
        data.minimumWidth = 120;
        text.setLayoutData(data);

        final Button button = new Button(shell, SWT.PUSH);
        button.setText("Say Hello");
        shell.setDefaultButton(button);
        button.setLayoutData(new GridData(SWT.END, SWT.CENTER, false, false, 2, 1));

        final Label output = new Label(shell, SWT.CENTER);
        output.setLayoutData(new GridData(SWT.FILL, SWT.CENTER, true, false, 2, 1));

        // 3. Add an event listener to the button
        button.addListener(SWT.Selection, event -> {
            String name = text.getText().trim();
            if (name.length() == 0) { name = "world"; }
            output.setText("Hello " + name + "!");
        });

        // 4. Open the window and start the event loop
        shell.setSize(shell.computeSize(SWT.DEFAULT, SWT.DEFAULT));
        shell.open();
        while (!shell.isDisposed()) {
            if (!display.readAndDispatch()) {
                display.sleep();
            }
        }
        display.dispose();
    }
}
```

### 🚀 Step 4: Build and Run
Open your terminal, navigate to the project's root directory (where the `pom.xml` is located), and run the following Maven commands.

**1. Compile the project:**
```bash
cd code
mvn clean compile
```

**2. Run the application:**
The command to run the app depends on your operating system.

**On Windows & Linux:**
```bash
cd code
mvn exec:java -Dexec.mainClass="com.example.swt.HelloWorld"
```

**On macOS:**
SWT requires a special JVM flag on macOS (`-XstartOnFirstThread`) because of how the Cocoa framework handles threads. Without it, the application will crash with an "Invalid thread access" error. You must pass this flag when running the application:
```bash
mvn exec:java -Dexec.mainClass="com.example.swt.HelloWorld" -Dexec.args="" -Dexec.jvmArgs="-XstartOnFirstThread"
```
*Note: If you are running the app from within an IDE like Eclipse or IntelliJ, you will need to add `-XstartOnFirstThread` to the VM options in your run configuration.*

After running the command, a small window titled "Hello World" should appear. You have successfully set up and run a simple SWT project.
