آفرین! 👏 حالا بریم **درس ۲: لینک، تصویر و لیست**

این درس سه چیز مهم را یاد می‌گیری که در هر سایتی لازم است.

## ۱. لینک — تگ `<a>`

```html
<a href="https://www.google.com">برو به گوگل</a>
<a href="https://www.google.com" target="_blank">گوگل در تب جدید</a>
<a href="about.html">صفحه درباره من</a>
```

- `href`: آدرس مقصد
- `target="_blank"`: باز شدن در تب جدید
- می‌توانی به یک فایل دیگر هم لینک بدهی

## ۲. تصویر — تگ `<img>`

```html
<img src="cat.jpg" alt="یک گربه" width="300">
```

- `src`: آدرس تصویر (فایل کنار `index.html` یا لینک اینترنتی)
- `alt`: توضیح تصویر؛ اگر تصویر لود نشود یا کاربر نابینا باشد، خوانده می‌شود. **همیشه بنویس.**
- `width` و `height`: اندازه
- این تگ **بسته نمی‌شود**.

## ۳. لیست‌ها

**لیست نامرتب (نقطه‌ای):**
```html
<ul>
  <li>چای</li>
  <li>قهوه</li>
  <li>آب</li>
</ul>
```

**لیست مرتب (شماره‌دار):**
```html
<ol>
  <li>بیدار شو</li>
  <li>صبحانه بخور</li>
  <li>HTML یاد بگیر</li>
</ol>
```

## کد کامل تمرین درس ۲

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>درس ۲</title>
</head>
<body>
  <h1>صفحه تمرین من</h1>

  <h2>لینک‌ها</h2>
  <p>برای جستجو به <a href="https://www.google.com" target="_blank">گوگل</a> برو.</p>

  <h2>تصویر</h2>
  <img src="https://picsum.photos/300/200" alt="تصویر تصادفی" width="300">

  <h2>سرگرمی‌های من</h2>
  <ul>
    <li>کتاب خواندن</li>
    <li>ورزش</li>
    <li>برنامه‌نویسی</li>
  </ul>

  <h2>کارهای روزانه من</h2>
  <ol>
    <li>بیدار شدن</li>
    <li>صبحانه</li>
    <li>تمرین HTML</li>
  </ol>
</body>
</html>
```

> نکته: آدرس `https://picsum.photos/300/200` یک تصویر تصادفی اینترنتی می‌دهد؛ نیازی به دانلود فایل نداری.

## تمرین درس ۲
1. کد بالا را در همان `index.html` یا یک فایل جدید بنویس.
2. یک لینک به سایت موردعلاقه‌ات اضافه کن که در تب جدید باز شود.
3. یک تصویر از اینترنت یا کامپیوترت اضافه کن.
4. یک لیست از ۵ غذای موردعلاقه‌ات با `<ul>` بساز.
5. یک لیست از ۵ کار روزانه با `<ol>` بساز.

## چالش کوچک
یک لینک تصویری بساز؛ یعنی تصویری که وقتی رویش کلیک کنی، به یک سایت برود:

```html
<a href="https://www.google.com" target="_blank">
  <img src="https://picsum.photos/200" alt="تصویر لینک" width="200">
</a>
```

وقتی انجام دادی، بنویس **«تمام شد»** یا کدت را بفرست تا بررسی کنیم. بعد می‌رویم **درس ۳: جدول و تگ‌های معنایی**.
