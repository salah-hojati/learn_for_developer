## بخش ۱: جدول — `<table>`

جدول برای نمایش داده‌های ردیفی و ستونی است (مثل لیست قیمت، برنامه هفتگی).

```html
<table border="1">
  <tr>
    <th>نام</th>
    <th>سن</th>
    <th>شهر</th>
  </tr>
  <tr>
    <td>علی</td>
    <td>۲۵</td>
    <td>تهران</td>
  </tr>
  <tr>
    <td>مریم</td>
    <td>۳۰</td>
    <td>شیراز</td>
  </tr>
</table>
```

- `<table>`: کل جدول
- `<tr>`: یک ردیف (Table Row)
- `<th>`: سلول عنوان (Heading)؛ معمولاً بولد
- `<td>`: سلول داده (Table Data)
- `border="1"`: خط دور جدول (فعلاً برای دیدن ساختار؛ بعداً با CSS قشنگ‌ترش می‌کنیم)

**جدول با عنوان و ادغام سلول:**

```html
<table border="1">
  <caption>برنامه هفتگی</caption>
  <tr>
    <th>روز</th>
    <th>درس</th>
  </tr>
  <tr>
    <td>شنبه</td>
    <td>ریاضی</td>
  </tr>
  <tr>
    <td colspan="2">تعطیل</td>
  </tr>
</table>
```

- `<caption>`: عنوان جدول
- `colspan="2"`: یک سلول به اندازه دو ستون
- `rowspan="2"`: یک سلول به اندازه دو ردیف

## بخش ۲: تگ‌های معنایی (Semantic)

این تگ‌ها به مرورگر و موتور جستجو می‌گویند هر بخش صفحه چه نقشی دارد. ساختار یک صفحه استاندارد:

```html
<body>
  <header>
    <h1>سایت من</h1>
    <nav>
      <a href="#">خانه</a> |
      <a href="#">درباره</a> |
      <a href="#">تماس</a>
    </nav>
  </header>

  <main>
    <section>
      <h2>درباره من</h2>
      <p>من در حال یادگیری HTML هستم.</p>
    </section>

    <article>
      <h2>آخرین مقاله</h2>
      <p>متن مقاله...</p>
    </article>
  </main>

  <aside>
    <h3>لینک‌های مفید</h3>
    <ul>
      <li><a href="#">MDN</a></li>
      <li><a href="#">W3Schools</a></li>
    </ul>
  </aside>

  <footer>
    <p>© ۲۰۲۶ - همه حقوق محفوظ است.</p>
  </footer>
</body>
```

- `<header>`: سرصفحه (لوگو، عنوان، منو)
- `<nav>`: منوی ناوبری
- `<main>`: محتوای اصلی صفحه (فقط یکی در هر صفحه)
- `<section>`: یک بخش موضوعی
- `<article>`: محتوای مستقل (مثل یک پست یا خبر)
- `<aside>`: محتوای کناری (تبلیغ، لینک مرتبط)
- `<footer>`: پاصفحه

## کد کامل تمرین درس ۳

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>درس ۳</title>
</head>
<body>
  <header>
    <h1>برنامه هفتگی من</h1>
    <nav>
      <a href="#table">جدول</a> |
      <a href="#info">اطلاعات</a>
    </nav>
  </header>

  <main>
    <section id="table">
      <h2>کلاس‌های هفته</h2>
      <table border="1">
        <caption>برنامه درسی</caption>
        <tr>
          <th>روز</th>
          <th>درس</th>
          <th>ساعت</th>
        </tr>
        <tr>
          <td>شنبه</td>
          <td>ریاضی</td>
          <td>۸ تا ۱۰</td>
        </tr>
        <tr>
          <td>یکشنبه</td>
          <td>HTML</td>
          <td>۱۰ تا ۱۲</td>
        </tr>
        <tr>
          <td colspan="3">پنجشنبه و جمعه تعطیل</td>
        </tr>
      </table>
    </section>

    <section id="info">
      <h2>اطلاعات من</h2>
      <p>من در حال یادگیری <strong>HTML</strong> هستم.</p>
    </section>
  </main>

  <footer>
    <p>ساخته‌شده توسط [اسم تو]</p>
  </footer>
</body>
</html>
```

## تمرین درس ۳
1. کد بالا را بنویس و در مرورگر ببین.
2. یک جدول از ۳ دوستت بساز: نام، سن، شهر (حداقل ۳ ردیف داده).
3. از `colspan` یا `rowspan` حداقل یک بار استفاده کن.
4. ساختار صفحه‌ات را با `header`، `nav`، `main`، `section`، `footer` بساز.
5. در `nav` سه لینک بگذار که با `#` به بخش‌های صفحه وصل شوند.

## نکته مهم
تگ‌های معنایی ظاهر صفحه را تغییر نمی‌دهند؛ فقط **معنا** می‌دهند. قشنگ‌کردن ظاهر کار **CSS** است که در درس‌های بعد می‌آید.

وقتی انجام دادی، بنویس **«تمام شد»** تا برویم **درس ۴: فرم‌ها** — مهم‌ترین بخش HTML برای تعامل با کاربر.
