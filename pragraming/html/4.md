 **درس ۴: فرم‌ها (Forms)** — مهم‌ترین بخش HTML برای گرفتن اطلاعات از کاربر.

## فرم چیست؟
فرم‌ها همان چیزی هستند که کاربر با آن اطلاعات وارد می‌کند: کادر ورود، رمز عبور، دکمه، چک‌باکس، انتخاب و...

## ساختار کلی فرم
</div>


```html
<form action="/submit" method="post">
  <!-- فیلدها اینجا می‌آیند -->
</form>
```

- `action`: آدرسی که اطلاعات به آنجا فرستاده می‌شود
- `method`: روش ارسال (`get` یا `post`)
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

فعلاً چون سرور نداریم، `action` را خالی می‌گذاریم یا `#` می‌گذاریم.

## ۱. کادر متن — `<input type="text">`
</div>


```html
<label for="name">نام:</label>
<input type="text" id="name" name="name" placeholder="نام خود را بنویسید">
```

- `<label for="name">`: برچسب فیلد. `for` باید با `id` فیلد یکی باشد.
- `placeholder`: متن راهنمای داخل کادر
- `name`: نام فیلد هنگام ارسال
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

## ۲. انواع مهم `<input>`
</div>


```html
<input type="text">      <!-- متن -->
<input type="password">  <!-- رمز -->
<input type="email">     <!-- ایمیل (با اعتبارسنجی) -->
<input type="number">    <!-- عدد -->
<input type="tel">       <!-- تلفن -->
<input type="date">      <!-- تاریخ -->
<input type="checkbox">  <!-- چک‌باکس -->
<input type="radio">     <!-- دکمه رادیویی (تک‌انتخابی) -->
<input type="file">      <!-- آپلود فایل -->
<input type="color">     <!-- انتخاب رنگ -->
```

## ۳. دکمه — `<button>`

```html
<button type="submit">ارسال</button>
<button type="reset">پاک کردن</button>
<button type="button">دکمه معمولی</button>
```

## ۴. لیست کشویی — `<select>`

```html
<label for="city">شهر:</label>
<select id="city" name="city">
  <option value="tehran">تهران</option>
  <option value="shiraz">شیراز</option>
  <option value="mashhad">مشهد</option>
</select>
```

## ۵. متن چندخطی — `<textarea>`

```html
<label for="msg">پیام:</label>
<textarea id="msg" name="msg" rows="5" cols="30"></textarea>
```

## ۶. ویژگی‌های مفید

```html
<input type="text" required>         <!-- اجباری -->
<input type="text" maxlength="20">    <!-- حداکثر کاراکتر -->
<input type="text" readonly>          <!-- فقط خواندنی -->
<input type="text" disabled>          <!-- غیرفعال -->
<input type="text" value="مقدار پیش‌فرض">
```

## کد کامل تمرین درس ۴

## نکات مهم
- هر `input` را با `label` مرتبط کن (`for` = `id`). این کار دسترس‌پذیری و تجربه کاربری را بهتر می‌کند.
- دکمه‌های رادیویی با `name` یکسان، یک گروه می‌سازند (فقط یکی انتخاب می‌شود).
- ویژگی `required` جلوی ارسال فرم خالی را می‌گیرد.
- با `type="email"` مرورگر خودش ایمیل را بررسی می‌کند.

## تمرین درس ۴
1. کد بالا را بنویس و در مرورگر ببین. روی **ثبت‌نام** کلیک کن و ببین مرورگر چه پیامی می‌دهد.
2. یک فیلد **تاریخ تولد** با `type="date"` اضافه کن.
3. یک فیلد **شماره تماس** با `type="tel"` اضافه کن.
4. یک `select` برای **مدرک تحصیلی** اضافه کن.
5. یک `textarea` برای **نظر شما** اضافه کن.

## چالش
فرم را طوری بساز که **همه** فیلدهای اجباری ستاره قرمز داشته باشند (با `required`). بعد ببین مرورگر چه رفتار می‌کند.

وقتی انجام دادی، بنویس **«تمام شد»**. بعد می‌رویم **درس ۵: تگ‌های صوتی و تصویری (video و audio) و iframe** — و بعد از آن آماده‌ایم برای **CSS**.
