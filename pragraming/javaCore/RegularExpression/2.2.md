# regex کد ملی ایران (فقط قالب)

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```regex
^(?!000)[0-9]{10}$
```

</div>


## در جاوا

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```java
private static final Pattern IR_NATIONAL_CODE =
        Pattern.compile("^(?!000)[0-9]{10}$");

public static boolean isValidNationalCodeFormat(String code) {
    return code != null && IR_NATIONAL_CODE.matcher(code).matches();
}
```

</div>


اگر بخواهید از `\d` استفاده کنید، در جاوا باید دوبار بک‌اسلش بنویسید:

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```java
"^(?!000)\\d{10}$"
```

</div>


اما `[0-9]` مطمئن‌تر است، چون `\d` در بعضی تنظیمات یونیکد ارقام غیرلاتین را هم می‌پذیرد.

## توضیح اجزا

| جزء | معنی |
|---|---|
| `^` | ابتدای رشته |
| `(?!000)` | lookahead منفی: سه کاراکتر بعدی نباید دقیقاً `000` باشند |
| `[0-9]{10}` | دقیقاً ۱۰ رقم ASCII |
| `$` | انتهای رشته |

## مثال

| ورودی | نتیجه |
|---|---|
| `0012345678` | ✅ معتبر (سه رقم اول `001` است) |
| `1234567890` | ✅ معتبر |
| `0001234567` | ❌ نامعتبر (سه رقم اول `000`) |
| `0000000000` | ❌ نامعتبر |
| `123456789` | ❌ نامعتبر (۹ رقم) |
| `12345678901` | ❌ نامعتبر (۱۱ رقم) |
| `12345abcde` | ❌ نامعتبر (حرف دارد) |

## نکته مهم

این regex فقط **قالب** را بررسی می‌کند. کد ملی ایران یک **رقم کنترل** هم دارد (الگوریتم وزن‌دار). اگر اعتبارسنجی واقعی می‌خواهید، بعد از عبور از regex باید checksum را هم چک کنید:

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```java
public static boolean isValidIranianNationalCode(String code) {
    if (code == null || !code.matches("^(?!000)[0-9]{10}$")) return false;

    int check = Character.getNumericValue(code.charAt(9));
    int sum = 0;
    for (int i = 0; i < 9; i++) {
        sum += Character.getNumericValue(code.charAt(i)) * (10 - i);
    }
    int r = sum % 11;
    return (r < 2 && check == r) || (r >= 2 && check == 11 - r);
}
```

</div>


اگر فقط همان دو شرطی که گفتید کافی است، همان regex بالا پاسخ کامل است.
