# 📚 ۳۰۰ مثال Regular Expression در جاوا

> ⚠️ **نکته مهم:** تمام الگوها در **فرم raw** نمایش داده شده‌اند. در String جاوا، هر `\` را باید `\\` بنویسی.
> مثال: `\d{8}` در جاوا `"\\d{8}"` نوشته می‌شود.

---

## 🎯 جمع‌بندی و نکات استفاده

### ✅ این مثال‌ها رو چطور استفاده کنی؟

1. **کپی کن و در `Pattern.compile()` بذار** — ولی یادت باشه `\` را در جاوا `\\` کنی
2. **همیشه تست کن** — در `regex101.com` یا `jshell`
3. **`^$` را برای اعتبارسنجی ننداز** — امن‌تره
4. **`static final Pattern`** برای استفاده مکرر
5. **`normalizeDigits` + `strip()`** قبل از اعتبارسنجی

### 🚨 تله‌های این لیست

| الگو | تله |
|------|-----|
| `\d+` برای کد ملی | چک‌سام را چک نمی‌کند — کد جاوا لازمه |
| `[0-9-]{10}` برای کد پستی | `-` را به عنوان کاراکتر مجاز می‌گیره — اشتباه |
| `.*` در ایمیل | blacklist، ناامن — از whitelist استفاده کن |
| `<.*>` برای HTML | greedy، همه را یک‌جا match می‌کنه — `.*?` lazy استفاده کن |
| `(.*)+` | 💀 ReDoS |
| `trim()` | Unicode-aware نیست — `strip()` استفاده کن |
| `\w` پیش‌فرض | فارسی را نمی‌گیره — `(?U)` لازمه |
| `matches()` روی `null` | NPE — اول null-check کن |

### 📖 مرجع سریع

| نماد | معنی |
|------|------|
| `\d` `\D` | رقم / غیر رقم |
| `\w` `\W` | word / غیر word |
| `\s` `\S` | space / غیر space |
| `.` | هر کاراکتری (به‌جز newline) |
| `*` `+` `?` | ۰+ / ۱+ / ۰ یا ۱ |
| `{n}` `{n,m}` | دقیقاً n / بین n تا m |
| `*?` `+?` | lazy |
| `*+` `++` | possessive |
| `()` `(?:)` `(?<name>)` | گروه شماره‌دار / بدون شمارش / نام‌دار |
| `(?=)` `(?!)` | lookahead |
| `(?<=)` `(?<!)` | lookbehind |
| `\1` `\k<name>` | backreference |
