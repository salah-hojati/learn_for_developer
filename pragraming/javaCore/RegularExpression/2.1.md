# معنی `\\` در `"[a\\-z]"`

## دو مرحله‌ی جدا

رشته‌ی `"[a\\-z]"` در جاوا اول توسط **کامپایلر جاوا** پردازش می‌شود، بعد توسط **موتور regex**. پس باید دو لایه را از هم جدا کرد:

| لایه | چیزی که می‌بیند | نتیجه |
|---|---|---|
| رشته‌ی جاوا | `[a\\-z]` | `\\` → یک بک‌اسلش `\` |
| رشته‌ی واقعی (ورودی regex) | `[a\-z]` | `\-` → خط تیره‌ی literal |
| معنای regex | یک کلاس کاراکتر شامل `a`، `-`، `z` | |

## `\\` در جاوا چیست؟

در رشته‌های جاوا، بک‌اسلش یک کاراکتر escape است. برای اینکه یک بک‌اسلش **واقعی** در رشته قرار بگیرد، باید دوتا بنویسید:

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```java
"\\"        // رشته‌ای با یک کاراکتر: \
"\n"        // رشته‌ای با یک کاراکتر: newline
"\-"        // ❌ خطای کامپایل: \- یک escape معتبر جاوا نیست
```

</div>


پس `\\` صرفاً یعنی «یک بک‌اسلش به موتور regex بده».

## `\-` در regex چه معنایی دارد؟

داخل کلاس کاراکتر `[...]`، خط تیره `-` معمولاً **بازه** می‌سازد:

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```regex
[a-z]   → هر حرف کوچک از a تا z
[0-9]   → هر رقم
```

</div>


اگر بخواهید خود کاراکتر `-` را هم داخل کلاس داشته باشید، باید آن را escape کنید:

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```regex
[a\-z]  → دقیقاً یکی از سه کاراکتر: a ، - ، z
```

</div>


پس `[a\-z]` یعنی «a یا خط تیره یا z» — نه بازه.

> نکته: می‌توانستید `\-` را در جاوا به‌صورت `"[-az]"` هم بنویسید (خط تیره در ابتدا یا انتهای کلاس بازه نمی‌سازد). اما استفاده از `\\-` صریح‌تر است و بعضی سبک‌ها آن را ترجیح می‌دهند.

## جدول معادل‌ها

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```java
"[a\\-z]"   // regex: [a\-z]   → a یا - یا z
"[a-z]"     // regex: [a-z]    → بازه‌ی a تا z
"[a\\-z]" == "[a\\-z]"
```

</div>


اگر کنجکاوید ببینید regex واقعی چیست:

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```java
System.out.println("[a\\-z]");   // چاپ می‌کند: [a\-z]
```

</div>


## چرا در کد قبلی `\\` زیاد دیدید؟

در همان کد ادغام Markdown، الگوهایی مثل:

<div dir="ltr" style="text-align: left; font-family: 'B Nazanin', Tahoma, sans-serif;">

```java
"(<img\\b[^>]*?\\bsrc\\s*=\\s*)([\"'])([^\"']+)\\2"
```

</div>


هر `\\b`، `\\s`، `\\2` در واقع `\b`، `\s`، `\2` به موتور regex هستند. اگر `"\b"` می‌نوشتید، جاوا آن را «backspace» تفسیر می‌کرد و regex خراب می‌شد. به همین دلیل برای هر بک‌اسلشِ regex باید `\\` بنویسید.

### جمع‌بندی

- `\\` = escape جاوا برای تولید یک `\` واقعی
- `\-` = escape regex برای اینکه `-` به‌عنوان کاراکتر literal در نظر گرفته شود، نه عملگر بازه
- `[a\-z]` = مجموعه‌ی {a, -, z}
</div>
