## ۱) لیست (List)
لیست یعنی یک لیست از چیزها. با `[]` ساخته می‌شود.
</div>

```python
fruits = ["سیب", "موز", "پرتقال"]

print(fruits[0])      # سیب
print(fruits[-1])     # پرتقال
print(len(fruits))    # 3

fruits.append("انگور")   # اضافه کردن به آخر
fruits.remove("موز")     # حذف کردن

for f in fruits:
    print(f)
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
نکته: شماره‌گذاری از **0** شروع می‌شود.

## ۲) تاپل (Tuple)
مثل لیست است ولی **تغییرناپذیر**. با `()` ساخته می‌شود.
</div>

```python
point = (3, 5)
x, y = point

print(x)  # 3
print(y)  # 5
```

## ۳) دیکشنری (Dictionary)
دیکشنری داده‌ها را به صورت **کلید: مقدار** نگه می‌دارد.

</div>

```python
person = {
    "name": "علی",
    "age": 15,
    "city": "تهران"
}

print(person["name"])   # علی

person["age"] = 16      # تغییر مقدار
person["email"] = "ali@example.com"  # اضافه کردن کلید جدید

for key, value in person.items():
    print(key, ":", value)
```

## ۴) مجموعه (Set)
مجموعه یعنی لیستی که **عضو تکراری ندارد**.

</div>

```python
numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)

print(unique)  # {1, 2, 3}
```

## ۵) List Comprehension
روش کوتاه برای ساختن لیست.
</div>

```python
squares = [x * x for x in range(1, 6)]
print(squares)  # [1, 4, 9, 16, 25]

evens = [x for x in range(10) if x % 2 == 0]
print(evens)    # [0, 2, 4, 6, 8]
```

## ۶) تابع با return
قبلاً `print` داخل تابع داشتیم. حالا تابع می‌تواند یک **مقدار برگرداند**.
</div>

```python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)  # 7
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

</div>

def greet(name, message="سلام"):

## ۸) پروژه کوچک: دفترچه تلفن ساده
</div>

```python
contacts = {}

def add_contact(name, phone):
    contacts[name] = phone
    print(f"{name} اضافه شد.")

def show_contacts():
    for name, phone in contacts.items():
        print(f"{name}: {phone}")

def search(name):
    if name in contacts:
        print(f"{name}: {contacts[name]}")
    else:
        print("پیدا نشد.")

add_contact("علی", "0912...")
add_contact("سارا", "0935...")

show_contacts()
search("علی")
```

1. لیست اعداد 5 تا 15 بساز و فقط زوج‌ها را چاپ کن.
</div>

```python

evens = [n for n in nums if n % 2 == 0]

```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

2. تابعی بنویس که لیست بگیرد و بزرگ‌ترین عدد را برگرداند.
</div>

```python
def max_number(numbers):
    biggest = numbers[0]
    for n in numbers:
        if n > biggest:
            biggest = n
    return biggest

print(max_number([4, 9, 2, 7]))
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">


3. دیکشنری نمرات بساز و میانگین را حساب کن.
</div>

```python
grades = {"ریاضی": 18, "علوم": 16, "ادبیات": 19}

total = sum(grades.values())
average = total / len(grades)
print(average)
```
