## ۲) JSON

JSON فرمت رایج برای ذخیره و انتقال داده است.
</div>


```python
import json

data = {
    "name": "علی",
    "age": 15,
    "skills": ["پایتون", "ریاضی"]
}

# ذخیره در فایل
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# خواندن از فایل
with open("data.json", "r", encoding="utf-8") as f:
    loaded = json.load(f)

print(loaded["name"])
print(loaded["skills"][0])
```

## ۳) lambda، map، filter، sorted
</div>


```python
add = lambda a, b: a + b
print(add(2, 3))

nums = [1, 2, 3, 4, 5]

# map: اعمال تابع روی همه اعضا
squares = list(map(lambda x: x * x, nums))
print(squares)

# filter: فیلتر کردن
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)

# sorted با کلید
people = [("علی", 20), ("سارا", 18), ("رضا", 22)]
by_age = sorted(people, key=lambda p: p[1])
print(by_age)
```

## ۴) تابع بازگشتی (Recursion)
</div>


```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120
```

## ۵) Generator

به جای ساختن کل لیست، مقادیر را یکی‌یکی می‌سازد. برای داده‌های بزرگ عالی است.
</div>


```python
def count_up(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for x in count_up(5):
    print(x)
```

## ۶) Decorator

تابعی که یک تابع دیگر را تغییر می‌دهد.
</div>


```python
def logger(func):
    def wrapper(*args, **kwargs):
        print(f"صدا زدن {func.__name__}")
        result = func(*args, **kwargs)
        print(f"نتیجه: {result}")
        return result
    return wrapper

@logger
def add(a, b):
    return a + b

add(3, 4)
```

## ۹) Context Manager سفارشی
</div>


```python
class Timer:
    def __enter__(self):
        import time
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc, tb):
        import time
        print("زمان:", round(time.time() - self.start, 3), "ثانیه")

with Timer():
    total = sum(range(1_000_000))
```

## ۱۰) پروژه: وضعیت هوا
</div>


```python
import requests

def get_weather(city: str) -> None:
    url = f"https://wttr.in/{city}?format=j1"
    try:
        r = requests.get(url, timeout=10)
        r.raise_for_status()
        data = r.json()

        current = data["current_condition"][0]
        print(f"شهر: {city}")
        print(f"دما: {current['temp_C']}°C")
        print(f"وضعیت: {current['weatherDesc'][0]['value']}")

    except requests.RequestException as e:
        print("خطا در اتصال:", e)

get_weather("Tehran")
```

## تمرین‌ها

1. با `json` یک لیست از کارها (to-do) در فایل ذخیره و بازخوانی کن.
2. با `sorted` لیست دیکشنری‌های دانشجو را بر اساس نمره مرتب کن.
3. یک generator بنویس که اعداد فیبوناچی تولید کند.
4. یک decorator بنویس که زمان اجرای تابع را چاپ کند.
5. با یک API عمومی (مثل wttr.in یا GitHub) اطلاعات بگیر و در فایل JSON ذخیره کن.
