## ۱) کار با فایل

### نوشتن در فایل
```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("سلام\n")
    f.write("این یک فایل متنی است.\n")
```

حالت‌ها:
- `"w"` = نوشتن (اگر فایل باشد، پاک می‌شود)
- `"a"` = اضافه کردن به آخر
- `"r"` = خواندن

### خواندن فایل
```python
with open("notes.txt", "r", encoding="utf-8") as f:
    text = f.read()
    print(text)
```

### خواندن خط به خط
```python
with open("notes.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

### اضافه کردن به فایل
```python
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("خط جدید\n")
```

## ۲) مدیریت خطا

گاهی برنامه خطا می‌دهد. با `try/except` جلوی crash را می‌گیریم.

```python
try:
    age = int(input("سن خود را وارد کن: "))
    print(10 / age)
except ValueError:
    print("لطفاً یک عدد وارد کن.")
except ZeroDivisionError:
    print("تقسیم بر صفر ممکن نیست.")
except Exception as e:
    print("یک خطای دیگر رخ داد:", e)
else:
    print("همه چیز درست بود.")
finally:
    print("این بخش همیشه اجرا می‌شود.")
```

## ۳) کلاس و شیء

کلاس مثل یک قالب است. از آن شیء می‌سازیم.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def greet(self):
        print(f"سلام {self.name}، من {self.age} ساله هستم.")

    def birthday(self):
        self.age += 1


p1 = Person("علی", 15)
p1.greet()
p1.birthday()
p1.greet()
```

- `__init__` = سازنده
- `self` = خود شیء
- `p1` = یک شیء از کلاس `Person`

### ارث‌بری
```python
class Student(Person):
    def __init__(self, name, age, field):
        super().__init__(name, age)
        self.field = field

    def greet(self):
        print(f"سلام {self.name}، دانش‌آموز رشته {self.field} هستم.")


s1 = Student("سارا", 16, "ریاضی")
s1.greet()
```

## ۴) ماژول و import

می‌توانی کدها را در فایل جدا بنویسی و جای دیگر استفاده کنی.

فایل `mymath.py`:
```python
def add(a, b):
    return a + b

def sub(a, b):
    return a - b
```

فایل دیگر:
```python
import mymath

print(mymath.add(3, 4))
print(mymath.sub(10, 2))
```

یا:
```python
from mymath import add

print(add(5, 6))
```

## ۵) پروژه کوچک: دفتر نمرات با فایل

```python
def save_grade(name, grade):
    with open("grades.txt", "a", encoding="utf-8") as f:
        f.write(f"{name},{grade}\n")

def show_grades():
    try:
        with open("grades.txt", "r", encoding="utf-8") as f:
            for line in f:
                name, grade = line.strip().split(",")
                print(f"{name}: {grade}")
    except FileNotFoundError:
        print("هنوز فایلی ساخته نشده.")

while True:
    print("\n1) افزودن نمره")
    print("2) نمایش نمرات")
    print("3) خروج")

    choice = input("انتخاب کن: ")

    if choice == "1":
        name = input("اسم: ")
        grade = input("نمره: ")
        save_grade(name, grade)
    elif choice == "2":
        show_grades()
    elif choice == "3":
        break
    else:
        print("گزینه نامعتبر است.")
```
