## ۱) اولین برنامه: print
`print` یعنی «چاپ کن».

```python
print("سلام دنیا!")
print("من دارم پایتون یاد می‌گیرم.")
```

خروجی:

```text
سلام دنیا!
من دارم پایتون یاد می‌گیرم.
```

## ۲) متغیر
متغیر مثل یک جعبه است که یک مقدار داخلش می‌گذاریم.

```python
name = "علی"
age = 15

print("اسم من", name, "است")
print("سن من", age, "سال است")
```

خروجی:

```text
اسم من علی است
سن من 15 سال است
```

## ۴) گرفتن ورودی از کاربر
با `input` از کاربر سوال می‌پرسیم.

```python
name = input("اسمت چیه؟ ")
print("سلام", name)
```

نکته مهم: `input` همیشه متن برمی‌گرداند. اگر عدد می‌خواهی باید تبدیلش کنی:

```python
age = input("سن شما چند است؟ ")
age = int(age)   # تبدیل متن به عدد

print("سال بعد سن شما می‌شود:", age + 1)
```

## ۵) شرط: if / else

```python
age = int(input("سن خود را وارد کن: "))

if age >= 18:
    print("شما بزرگسال هستید")
else:
    print("شما کوچک‌تر از 18 سال هستید")
```

نکته: فاصله اول خط‌ها مهم است. به آن «تورفتگی» می‌گویند و در پایتون اجباری است.

## ۶) حلقه for

```python
for i in range(5):
    print("عدد", i)
```

خروجی اعداد 0 تا 4 است.

اگر بخواهی 1 تا 5 باشد:

```python
for i in range(1, 6):
    print(i)
```

---

## ۷) حلقه while

```python
i = 1
while i <= 5:
    print(i)
    i = i + 1
```

این هم اعداد 1 تا 5 را چاپ می‌کند.

## تمرین کوچک
برنامه‌ای بنویس که:
1. اسم کاربر را بپرسد.
2. سن او را بپرسد.
3. بگوید: سلام [اسم]، تو [سن] سالته و سال بعد [سن+1] ساله می‌شی.

راه‌حل:

```python
name = input("اسمت چیه؟ ")
age = int(input("سن شما چند است؟ "))

print("سلام", name, "، تو", age, "سالته و سال بعد", age + 1, "ساله می‌شی.")
```

اگر این‌ها را تمرین کنی، پایه‌ات خیلی خوب می‌شود.
