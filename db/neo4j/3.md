Let's get your development environment ready. In this step, we'll set up two things: a running **Neo4j database** and a **Java project** configured to connect to it.

---

### 🗄️ Part 1: Set Up Your Neo4j Database

You have three main options. Choose the one that fits your workflow best.

#### Option A: Neo4j Aura (Cloud — Easiest, Recommended for Beginners)

Neo4j Aura is a fully managed cloud service with a free tier that requires no credit card.

1.  Go to **[console.neo4j.io](https://console.neo4j.io)** and sign up (you can use a Google account).
2.  Click **New Instance** and choose **AuraDB Free** (the $0 plan).
3.  Select a region close to you and click **Create**.
4.  **Crucial:** Neo4j will generate a password. **Save it immediately**—it will not be shown again.
5.  After creation, download the **`.env` file** (or copy the connection details). You will need:
    *   **URI**: Starts with `neo4j+s://` (e.g., `neo4j+s://xxxxxxxx.databases.neo4j.io`)
    *   **Username**: `neo4j`
    *   **Password**: The one you just saved

> **Note:** Free-tier Aura instances automatically pause after 3 days of inactivity. You can resume them from the console when you return.

#### Option B: Docker (Local — Best for Offline Work)

If you have Docker installed, you can run Neo4j locally with a single command.

**Using `docker run` (Quickest):**
```bash
docker run \
  --restart always \
  --publish=7474:7474 \
  --publish=7687:7687 \
  --env NEO4J_AUTH=neo4j/your_password \
  neo4j:latest
```
This starts Neo4j with the Browser on `http://localhost:7474` and the Bolt protocol (used by the Java driver) on port `7687`.

**Using Docker Compose (Recommended for Projects):**
Create a `docker-compose.yml` file:
```yaml
services:
  neo4j:
    image: neo4j:latest
    volumes:
      - /$HOME/neo4j/logs:/logs
      - /$HOME/neo4j/conf:/conf
      - /$HOME/neo4j/data:/data
      - /$HOME/neo4j/plugins:/plugins
    environment:
      - NEO4J_AUTH=neo4j/your_password
    ports:
      - "7474:7474"
      - "7687:7687"
    restart: always
```
Then run `docker compose up -d` to start it in detached mode.

#### Option C: Neo4j Desktop (GUI — Good for Learning)

Download and install **Neo4j Desktop** from the official Neo4j website. It provides a graphical interface to create and manage local databases, which is helpful if you prefer a visual tool.

### ☕ Part 2: Set Up Your Java Project

Now, let's create a Java project and add the Neo4j Java Driver dependency.

**Requirements:** The Neo4j Java Driver **v6** requires **Java 17** or higher.

#### Option A: Using Maven

If you don't have a project yet, create one, then add the driver to your `pom.xml`:

```xml
<dependency>
    <groupId>org.neo4j.driver</groupId>
    <artifactId>neo4j-java-driver</artifactId>
    <version>6.3.0</version>
</dependency>
```
The latest stable version is **6.3.0** (as of September 2026).

#### Option B: Using Gradle

Add this line to your `build.gradle` file's `dependencies` block:

```groovy
implementation 'org.neo4j.driver:neo4j-java-driver:6.3.0'
```

### 🔌 Part 3: Verify Your Connection

Let's write a small Java program to confirm everything is working. Create a class like `Neo4jConnectionTest.java`:

```java
import org.neo4j.driver.*;

public class Neo4jConnectionTest {
    public static void main(String[] args) {
        // Load credentials from environment variables (best practice)
        String uri = System.getenv().getOrDefault("NEO4J_URI", "neo4j://localhost:7687");
        String user = System.getenv().getOrDefault("NEO4J_USERNAME", "neo4j");
        String password = System.getenv().getOrDefault("NEO4J_PASSWORD", "your_password");

        // Create the driver (one instance for the whole application)
        try (Driver driver = GraphDatabase.driver(uri, AuthTokens.basic(user, password))) {
            // Verify connectivity
            driver.verifyConnectivity();
            System.out.println("✅ Connection to Neo4j established successfully!");

            // Run a simple test query
            try (Session session = driver.session()) {
                var result = session.run("RETURN 'Hello, Neo4j!' AS message");
                String message = result.single().get("message").asString();
                System.out.println("Query result: " + message);
            }
        } catch (Exception e) {
            System.err.println("❌ Connection failed: " + e.getMessage());
            e.printStackTrace();
        }
    }
}
```

**How to run it:**
*   If you are using an IDE (IntelliJ, Eclipse, VS Code), simply run the `main` method.
*   If you are on the command line with Maven, use:
    ```bash
    mvn compile exec:java -Dexec.mainClass="Neo4jConnectionTest"
    ```

**What to expect:** If everything is configured correctly, you should see:
```
✅ Connection to Neo4j established successfully!
Query result: Hello, Neo4j!
```

### 💡 Key Best Practices from the Start

*   **Never hardcode credentials.** Use environment variables or a `.env` file. The example above uses `System.getenv()` with fallback defaults for local development.
*   **Reuse the `Driver`.** The `Driver` object is thread-safe and expensive to create. Create **one instance** for your entire application and reuse it. The `try-with-resources` block in the example ensures it is closed properly when the program ends.
*   **Use the correct URI scheme.** For Aura, the URI must start with `neo4j+s://` (the `+s` enforces TLS encryption). For local Docker, use `neo4j://localhost:7687`.

Once you see that success message, your environment is ready, and you can move on to **Step 3: Master the Core Neo4j Java Driver** to learn how to execute queries and manage transactions programmatically.
