Here is a step-by-step learning path to go from zero to building graph applications with Neo4j and Java.

### 🗺️ Your Learning Roadmap

We'll progress through five logical stages, moving from the foundational concepts to practical implementation.

1.  **Understand the Graph Model & Cypher**: Learn the core concepts and the query language.
2.  **Set Up Your Environment**: Get a Neo4j database and a Java project ready.
3.  **Master the Core: Neo4j Java Driver**: Learn to execute queries and manage transactions directly.
4.  **Level Up: Spring Data Neo4j**: Discover how to map Java objects to your graph for rapid development.
5.  **Apply Best Practices**: Learn the key patterns for building robust applications.

### Step 1: Understand the Graph Model & Cypher

Before writing Java code, you need to understand how Neo4j thinks. A graph database stores data as **nodes** (entities) and **relationships** (connections), both of which can have **properties** (key-value pairs). The language you use to talk to Neo4j is called **Cypher**.

It's highly recommended to spend some time with the official **Cypher tutorial**. You can create a free Neo4j Aura instance and use its built-in browser to run queries against a sample "Movie Graph" dataset.

**Key Cypher Concepts to Learn:**
*   **Nodes**: Represented with parentheses `()`, e.g., `(p:Person {name: 'Tom Hanks'})`.
*   **Relationships**: Represented with arrows `-->`, e.g., `[:ACTED_IN]`.
*   **Pattern Matching**: The `MATCH` clause is used to find patterns in the graph. For example, this query finds all movies Tom Hanks acted in:
    ```cypher
    MATCH (tom:Person {name: "Tom Hanks"})-[r]->(movie:Movie)
    RETURN tom, r, movie
    ```

### Step 2: Set Up Your Environment

You need two things: a running Neo4j database and a Java project.

1.  **Neo4j Database**: The easiest way to start is with a free **Neo4j Aura** cloud instance. Alternatively, you can run Neo4j locally using Docker or Neo4j Desktop.
2.  **Java Project**: Create a Maven project and add the official Neo4j Java Driver dependency. The latest stable version is **6.1.0**.
    ```xml
    <dependency>
        <groupId>org.neo4j.driver</groupId>
        <artifactId>neo4j-java-driver</artifactId>
        <version>6.1.0</version>
    </dependency>
    ```

### Step 3: Master the Core: Neo4j Java Driver

This is the foundational API. You'll use it to connect to Neo4j and execute Cypher queries directly.

#### 3.1: Managing the Driver Lifecycle
The `Driver` is the most critical object. It is **thread-safe** and **expensive to create**, so you should create **only one instance** for your entire application and reuse it. Use `verifyConnectivity()` to ensure the connection works.

```java
import org.neo4j.driver.*;

public class Neo4jConnection {
    public static void main(String[] args) {
        // It's best practice to load credentials from environment variables
        String uri = System.getenv().getOrDefault("NEO4J_URI", "neo4j://localhost:7687");
        String user = System.getenv().getOrDefault("NEO4J_USERNAME", "neo4j");
        String password = System.getenv().getOrDefault("NEO4J_PASSWORD", "");

        try (var driver = GraphDatabase.driver(uri, AuthTokens.basic(user, password))) {
            driver.verifyConnectivity();
            System.out.println("Connection established.");
        }
    }
}
```

#### 3.2: Executing Queries with Managed Transactions
For most operations, you should use **managed transactions** via `executeRead` and `executeWrite`. They provide automatic retry logic for transient errors, making your application more resilient.

**Example: Creating Data (Write Transaction)**
This code creates a `Person` node. Notice the use of **parameterized queries** (`$name`), which protects against Cypher injection.
```java
try (var session = driver.session()) {
    session.executeWrite(tx -> {
        return tx.run("CREATE (p:Person {name: $name, age: $age})",
                      Values.parameters("name", "Alice", "age", 30))
                 .consume();
    });
}
```

**Example: Reading Data (Read Transaction)**
This query finds all people older than a given age and returns their names.
```java
try (var session = driver.session()) {
    var people = session.executeRead(tx -> {
        var result = tx.run("MATCH (p:Person) WHERE p.age > $minAge RETURN p.name AS name",
                            Values.parameters("minAge", 25));
        return result.list(record -> record.get("name").asString());
    });
    people.forEach(System.out::println);
}
```

### Step 4: Level Up: Spring Data Neo4j (SDN)

If you are building a Spring Boot application, **Spring Data Neo4j (SDN)** will dramatically reduce boilerplate code. It maps your Java objects directly to graph nodes and relationships, similar to JPA/Hibernate for relational databases. The official **Spring Guide** is an excellent step-by-step tutorial for this.

**Core SDN Workflow:**
1.  **Add Starter**: Include the `spring-boot-starter-data-neo4j` dependency.
2.  **Define Entities**: Annotate your classes with `@Node` and `@Relationship`.
    ```java
    @Node
    public class Person {
        @Id @GeneratedValue
        private Long id;
        private String name;

        @Relationship(type = "ACTED_IN", direction = Relationship.Direction.OUTGOING)
        private List<Movie> actedIn = new ArrayList<>();
        // Getters and setters...
    }
    ```
3.  **Create Repositories**: Extend `Neo4jRepository` to get CRUD operations for free.
    ```java
    public interface PersonRepository extends Neo4jRepository<Person, Long> {
        List<Person> findByName(String name);
    }
    ```
SDN handles the Cypher generation and object mapping, allowing you to focus on your domain logic.

### Step 5: Apply Best Practices

These tips will help you build professional, production-ready applications.

*   **Use Environment Variables for Credentials**: Never hardcode usernames, passwords, or URIs in your source code. Load them from environment variables or a secure configuration service.
*   **Reuse the Driver**: Create one `Driver` instance for the application lifecycle. It manages an internal connection pool for you.
*   **Prefer Managed Transactions**: Use `executeRead`/`executeWrite` for automatic retries and better error handling.
*   **Always Use Parameters**: Avoid string concatenation in Cypher queries. Use `$parameter` placeholders to prevent injection attacks and improve query plan caching.
*   **Create Indexes**: For properties you frequently use in `MATCH` or `WHERE` clauses (like `Person.name`), create an index to speed up lookups. Use `CREATE INDEX ON :Person(name)`.
*   **Leverage Official Example Projects**: Exploring real-world code is one of the best ways to learn. The **`movies-java-bolt`** project is a complete example using the Java driver with a web backend.

By following these steps, you'll build a solid foundation in using Neo4j with Java, moving from core concepts to practical, production-ready patterns.
