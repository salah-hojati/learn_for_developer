# ConfigMap/Secret -> Volume Mount or Env Var -> Pod
+------------------------------------------------------------------+
|              CONFIGMAP/SECRET -> VOLUME MOUNT / ENV VAR          |
|                                                                  |
|  CONFIGMAP (non-sensitive)           SECRET (sensitive, base64)  |
|  +--------------------------+       +--------------------------+  |
|  | apiVersion: v1           |       | apiVersion: v1           |  |
|  | kind: ConfigMap          |       | kind: Secret             |  |
|  | metadata: {name: app-cm} |       | metadata: {name: app-sec}|  |
|  | data:                    |       | type: Opaque             |  |
|  |   APP_MODE: "production" |       | data:                    |  |
|  |   LOG_LEVEL: "info"      |       |   DB_PASSWORD: c2VjcmV0  |  |
|  |   config.yaml: |         |       |   API_KEY: YWJjZGVmZw==  |  |
|  |     key: value           |       +--------------------------+  |
|  +--------------------------+              |                     |
|         |                      |          |                     |
|         |    OPTION 1:         |          |    OPTION 1:        |
|         |    ENV VAR           |          |    ENV VAR          |
|         v                      v          v                     |
|  +--------------------------+       +--------------------------+  |
|  | POD SPEC                 |       | POD SPEC                 |  |
|  | envFrom:                 |       | envFrom:                 |  |
|  | - configMapRef:          |       | - secretRef:             |  |
|  |     name: app-cm         |       |     name: app-sec        |  |
|  | env:                     |       | env:                     |  |
|  | - name: CUSTOM_VAR       |       | - name: DB_PASS          |  |
|  |   valueFrom:             |       |   valueFrom:             |  |
|  |     configMapKeyRef:     |       |     secretKeyRef:        |  |
|  |       name: app-cm       |       |       name: app-sec      |  |
|  |       key: APP_MODE      |       |       key: DB_PASSWORD   |  |
|  +--------------------------+       +--------------------------+  |
|                                                                  |
|         |                      |          |                     |
|         |    OPTION 2:         |          |    OPTION 2:        |
|         |    VOLUME MOUNT      |          |    VOLUME MOUNT     |
|         v                      v          v                     |
|  +--------------------------+       +--------------------------+  |
|  | POD SPEC                 |       | POD SPEC                 |  |
|  | volumes:                 |       | volumes:                 |  |
|  | - name: config           |       | - name: secret           |  |
|  |   configMap:             |       |   secret:                |  |
|  |     name: app-cm         |       |     name: app-sec        |  |
|  |     items:               |       |     items:               |  |
|  |     - key: config.yaml   |       |     - key: cert.pem      |  |
|  |       path: config.yaml  |       |       path: tls.crt      |  |
|  | containers:              |       | containers:              |  |
|  | - volumeMounts:          |       | - volumeMounts:          |  |
|  |   - name: config         |       |   - name: secret         |  |
|  |     mountPath: /etc/app  |       |     mountPath: /etc/secret| |
|  |     readOnly: true       |       |     readOnly: true       |  |
|  +--------------------------+       +--------------------------+  |
|                                                                  |
|  SECRET MOUNT OPTIONS:                                           |
|  - defaultMode: 0400 (file permissions)                          |
|  - tmpfs volume (memory-backed, no disk)                         |
|  - secret.ssa.volumes.kubernetes.io (ServiceAccount token)       |

# Resource Requests/Limits -> QoS Classes -> Scheduler/Eviction
+------------------------------------------------------------------+
|            RESOURCE REQUESTS/LIMITS -> QOS -> SCHED/EVICT        |
|                                                                  |
|  CONTAINER RESOURCE SPEC:                                        |
|  +----------------------------------------------------------+    |
|  | resources:                                             |    |
|  |   requests:                                            |    |
|  |     cpu: "500m"        # 0.5 CPU cores                 |    |
|  |     memory: "256Mi"    # 256 MiB                       |    |
|  |     ephemeral-storage: "1Gi"                           |    |
|  |   limits:                                              |    |
|  |     cpu: "1000m"       # 1 CPU core                    |    |
|  |     memory: "512Mi"    # 512 MiB                       |    |
|  |     ephemeral-storage: "2Gi"                           |    |
|  +----------------------------------------------------------+    |
|                                                                  |
|  QOS CLASS DETERMINATION:                                        |
|  +--------------------------+  +--------------------------+      |
|  |  Guaranteed              |  |  Burstable               |      |
|  |  (Highest Priority)      |  |  (Medium Priority)       |      |
|  |                          |  |                          |      |
|  |  - ALL containers have   |  |  - At least one container|      |
|  |    requests == limits    |  |    has requests          |      |
|  |  - CPU & memory both     |  |  - Not all match limits  |      |
|  |                          |  |                          |      |
|  |  Eviction: Last          |  |  Eviction: Middle        |      |
|  |  OOM Score: -997         |  |  OOM Score: 2-998        |      |
|  +--------------------------+  +--------------------------+      |
|                                                                  |
|  +--------------------------+                                    |
|  |  BestEffort              |                                    |
|  |  (Lowest Priority)       |                                    |
|  |                          |                                    |
|  |  - NO requests/limits    |                                    |
|  |    for any container     |                                    |
|  |                          |                                    |
|  |  Eviction: First         |                                    |
|  |  OOM Score: 1000         |                                    |
|  +--------------------------+                                    |
|                                                                  |
|  SCHEDULER DECISIONS:                                            |
|  - Filters nodes: request <= allocatable                         |
|  - Scores nodes: least requested, balanced resource              |
|  - Requests = guaranteed minimum                                 |
|  - Limits = maximum (throttling/OOM)                             |
|                                                                  |
|  EVICTION SIGNALS (kubelet):                                     |
|  - memory.available < threshold (soft/hard)                      |
|  - nodefs.available < threshold                                  |
|  - imagefs.available < threshold                                 |
|  - pid.available < threshold                                     |
|                                                                  |
|  EVICTION ORDER:                                                 |
|  1. BestEffort pods                                              |
|  2. Burstable pods (exceeding requests)                          |
|  3. Guaranteed pods (last resort)                                |
|                                                                  |
|  QOS GUARANTEES:                                                 |
|  Guaranteed:  CPU limit enforced (cfs_quota), memory protected   |
|  Burstable:   CPU throttled at limit, memory min=request         |
|  BestEffort:  No guarantees, first to be killed                 |
+------------------------------------------------------------------+

# LimitRanges & ResourceQuotas
+------------------------------------------------------------------+
|                      LIMITRANGES & RESOURCEQUOTAS                |
|                                                                  |
|  LIMITRANGE (namespace defaults/constraints)                     |
|  +----------------------------------------------------------+    |
|  | apiVersion: v1                                           |    |
|  | kind: LimitRange                                         |    |
|  | metadata: {name: limits, namespace: default}             |    |
|  | spec:                                                    |    |
|  |   limits:                                                |    |
|  |   - type: Container                                      |    |
|  |     default:           {cpu: "500m", memory: "512Mi"}    |    |
|  |     defaultRequest:  {cpu: "250m", memory: "128Mi"}      |    |
|  |     max:               {cpu: "2", memory: "4Gi"}         |    |
|  |     min:               {cpu: "100m", memory: "64Mi"}     |    |
|  |     maxLimitRequestRatio: {cpu: "10", memory: "10"}      |    |
|  |   - type: Pod                                            |    |
|  |     max: {cpu: "4", memory: "8Gi"}                       |    |
|  |   - type: PersistentVolumeClaim                          |    |
|  |     min: {storage: "1Gi"}                                |    |
|  |     max: {storage: "100Gi"}                              |    |
|  +----------------------------------------------------------+    |
|                                                                  |
|  RESOURCEQUOTA (namespace hard limits)                           |
|  +----------------------------------------------------------+    |
|  | apiVersion: v1                                           |    |
|  | kind: ResourceQuota                                      |    |
|  | metadata: {name: quota, namespace: default}              |    |
|  | spec:                                                    |    |
|  |   hard:                                                  |    |
|  |     requests.cpu: "10"                                   |    |
|  |     requests.memory: "20Gi"                              |    |
|  |     limits.cpu: "20"                                     |    |
|  |     limits.memory: "40Gi"                                |    |
|  |     persistentvolumeclaims: "20"                         |    |
|  |     services.loadbalancers: "5"                          |    |
|  |     services.nodeports: "10"                             |    |
|  |     secrets: "100"                                       |    |
|  |     configmaps: "100"                                    |    |
|  +----------------------------------------------------------+    |
|                                                                  |
|  QUOTA SCOPES:                                                   |
|  - NotTerminating (running pods)                                |
|  - BestEffort / NotBestEffort                                   |
|  - PriorityClass                                                |
