# Worker Node Components
+------------------------------------------------------------------+
|                        WORKER NODE                               |
|                                                                  |
|  +----------------------------------------------------------+   |
|  |                    KUBELET                               |   |
|  |  - Pod lifecycle management                              |   |
|  |  - Container health checks (probes)                      |   |
|  |  - Resource monitoring (cAdvisor)                        |   |
|  |  - Node registration & status reporting                  |   |
|  |  - Volume mounting                                       |   |
|  |  - Secret/ConfigMap injection                            |   |
|  +---------------------------+------------------------------+   |
|                              |                                 |
|                              v                                 |
|  +----------------------------------------------------------+   |
|  |              CONTAINER RUNTIME INTERFACE (CRI)           |   |
|  |  containerd / cri-o / Docker (deprecated)                |   |
|  |  - Image pull                                            |   |
|  |  - Container create/start/stop                           |   |
|  |  - Sandbox (pause container) management                  |   |
|  +---------------------------+------------------------------+   |
|                              |                                 |
|              +---------------+---------------+                 |
|              v                               v                 |
|  +--------------------------+      +--------------------------+ |
|  |       RUNC / CRUN        |      |      CNI PLUGINS         | |
|  |  - Namespace setup       |      |  - Pod network setup     | |
|  |  - Cgroup configuration  |      |  - IP assignment         | |
|  |  - Rootfs pivot          |      |  - Route configuration   | |
|  |  - Process execution     |      |  - DNS configuration     | |
|  +--------------------------+      +--------------------------+ |
|                                                                  |
|  +----------------------------------------------------------+   |
|  |                    KUBE-PROXY                            |   |
|  |  - Service abstraction (ClusterIP, NodePort, LoadBalancer)|   |
|  |  - Backend: iptables / IPVS / nftables                   |   |
|  |  - Connection tracking & load balancing                  |   |
|  +----------------------------------------------------------+   |
|                                                                  |
|  +----------------------------------------------------------+   |
|  |                       POD                                |   |
|  |  +--------+  +--------+  +--------+  +--------+          |   |
|  |  |Container|  |Container|  |Container|  | Pause  |          |   |
|  |  |   A    |  |   B    |  |   C    |  |(sandbox)|          |   |
|  |  +--------+  +--------+  +--------+  +--------+          |   |
|  |  |  Shared Network Namespace  |  Shared Volume Mounts   |   |
|  +----------------------------------------------------------+   |
+------------------------------------------------------------------+
