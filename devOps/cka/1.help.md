The `kind` command isn't installed on your system by default. You just need to download the binary and place it in your PATH. Here is the step-by-step fix for your Ubuntu machine.

### 🐧 Install `kind` on Linux (Ubuntu)

The official method is to download the pre-built binary directly. Run these commands in your terminal:

**1. Download the binary**

First, check your system architecture. Most modern systems are `x86_64` (AMD64). If you are on an ARM-based system (like some cloud servers or Raspberry Pi), use the `arm64` link.

For standard **AMD64 (x86_64)** systems:
```bash
curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.33.0/kind-linux-amd64
```


For **ARM64** systems:
```bash
curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.33.0/kind-linux-arm64
```


**2. Make it executable**

```bash
chmod +x ./kind
```


**3. Move it to a directory in your PATH**

```bash
sudo mv ./kind /usr/local/bin/kind
```


`/usr/local/bin` is a standard location for user-installed binaries and is already in your system's `PATH`, so you can run `kind` from any directory.

### ✅ Verify the Installation

After moving the file, confirm everything worked by checking the version:

```bash
kind --version
```

You should see output confirming the version (e.g., `kind version 0.33.0`). Once that works, you can proceed with creating your practice cluster:

```bash
kind create cluster --name cka-practice
```

> **Note:** `kind` requires a container runtime (like Docker) to be installed and running on your machine. If `kind create cluster` fails with a Docker-related error, ensure Docker is installed and active (`sudo systemctl status docker`). The official docs note that `kind` does not require `kubectl`, but you'll need it for the CKA, so make sure that's installed as well.
