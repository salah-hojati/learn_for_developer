## آزمایشگاه پیشنهادی

بهترین کار این است که یک ماشین مجازی بسازی:

- **نرم‌افزار:** VirtualBox یا VMware
- **سیستم‌عامل:** Ubuntu Server 24.04 LTS
- **منابع:** 2 vCPU، 4GB RAM، 25GB Disk
- **نام کاربری:** مثلاً `devops`
- **نکته:** بعد از نصب یک Snapshot بگیر تا اگر خراب کردی، برگردی.

اگر ماشین مجازی نمی‌توانی بسازی، از **WSL2 + Ubuntu** روی ویندوز استفاده کن. ولی برای تجربه واقعی سرور، VM بهتر است.

# برنامه هفته‌به‌هفته فاز ۱

## هفته ۱: شل، فایل‌سیستم و مجوزها

### روز ۱ تا ۳: آشنایی با ترمینال و ناوبری

- تفاوت Shell و Terminal
- دستورات پایه:
    - `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `rmdir`
    - `ls -la`, `ls -lh`, `tree`, `file`, `stat`
- کمک گرفتن:
    - `man ls`
    - `ls --help`
    - `history`
    - `Ctrl + R` برای جستجوی دستورات قبلی
    - `Tab` برای تکمیل خودکار
- ساختار فایل‌سیستم لینوکس:
    - `/etc` → تنظیمات
    - `/var` → لاگ‌ها و داده‌های متغیر
    - `/home` → خانه کاربران
    - `/root` → خانه root
    - `/tmp` → فایل‌های موقت
    - `/usr` → برنامه‌ها و کتابخانه‌ها
    - `/opt` → نرم‌افزارهای جانبی
    - `/dev` → دستگاه‌ها
    - `/proc` → اطلاعات پروسه‌ها

**تمرین:**
1. یک ساختار پوشه بساز: `/home/devops/lab/week1/{docs,logs,tmp}`
2. چند فایل بساز، کپی کن، تغییر نام بده و پاک کن.
3. یک لینک نمادین (Symlink) بساز: `ln -s /etc/hosts ~/hosts-link`
4. با `find` فایل‌های `.log` را پیدا کن: `find /var/log -name "*.log"`

### روز ۴ تا ۷: مجوزها و مالکیت

- نمایش مجوزها: `ls -l`
- تغییر مجوز: `chmod`
    - عددی: `chmod 640 file`
    - نمادی: `chmod u+x script.sh`
- تغییر مالک: `chown`
- تغییر گروه: `chgrp`
- `umask`
- لینک سخت و نرم: `ln`, `ln -s`

**تمرین:**
1. فایلی بساز و مجوز آن را به `640` تغییر بده.
2. پوشه‌ای بساز و مجوز آن را به `750` تغییر بده.
3. مالک فایل را به کاربر دیگری تغییر بده.
4. تفاوت Hard Link و Soft Link را عملی تست کن.

## هفته ۲: کاربران، بسته‌ها، پروسه‌ها و سرویس‌ها

### روز ۱ تا ۳: مدیریت کاربران و گروه‌ها

- فایل‌های مهم:
    - `/etc/passwd`
    - `/etc/shadow`
    - `/etc/group`
- دستورات:
    - `useradd`, `usermod`, `userdel`
    - `groupadd`, `groupdel`
    - `passwd`
    - `id`, `whoami`, `who`, `w`
    - `su`, `sudo`
- مدیریت sudo:
    - `visudo`
    - فایل‌های `/etc/sudoers.d/`

**تمرین:**
1. کاربر `ali` و `sara` را بساز.
2. گروه `devs` را بساز و هر دو کاربر را به آن اضافه کن.
3. برای `ali` دسترسی sudo محدود تعریف کن.
4. با `id ali` بررسی کن.

### روز ۴ تا ۵: مدیریت بسته‌ها

- در Ubuntu/Debian:
    - `apt update`
    - `apt upgrade`
    - `apt install htop tree curl`
    - `apt remove`
    - `apt autoremove`
    - `apt search`
    - `apt show`
- `dpkg -l`, `dpkg -i`

**تمرین:**
1. `htop`, `tree`, `curl` را نصب کن.
2. لیست بسته‌های نصب‌شده را ببین.
3. یک بسته را حذف و دوباره نصب کن.

### روز ۶ تا ۷: پروسه‌ها و سرویس‌ها

- پروسه‌ها:
    - `ps aux`
    - `top`, `htop`
    - `kill`, `kill -9`, `pkill`, `killall`
    - `jobs`, `bg`, `fg`, `nohup`, `&`
- سرویس‌ها با systemd:
    - `systemctl status ssh`
    - `systemctl start/stop/restart/enable/disable`
    - `journalctl -u ssh -f`
    - `journalctl --since "1 hour ago"`
- دیسک:
    - `df -h`
    - `du -sh`
    - `lsblk`
    - `mount`, `umount`

**تمرین:**
1. `openssh-server` را نصب کن.
2. وضعیت سرویس SSH را ببین و آن را enable کن.
3. یک پروسه `sleep 1000` اجرا کن و با `kill` ببند.
4. فضای دیسک و پوشه‌های حجیم را بررسی کن.

## هفته ۳: پردازش متن، Vim، آرشیو، Cron و محیط

### روز ۱ تا ۲: Redirection و Pipes

- `>` و `>>`
- `2>` و `&>`
- `|`
- `tee`
- `grep`, `cut`, `sort`, `uniq`, `tr`, `wc`
- `sed` و `awk` در سطح مقدماتی
- `xargs`

**تمرین:**
1. خطاها را به فایل جداگانه بفرست.
2. از `/var/log/syslog` خطوط دارای `error` را استخراج کن.
3. با `awk` ستون‌های خاص را چاپ کن.
4. با `sort | uniq -c` تعداد تکرار آی‌پی‌ها را بشمار.

### روز ۳ تا ۴: Vim

- حالت‌ها: Normal, Insert, Visual, Command
- دستورات ضروری:
    - `i`, `Esc`, `:w`, `:q`, `:wq`, `:q!`
    - `dd`, `yy`, `p`
    - `/search`
    - `:%s/old/new/g`

**تمرین:**
1. یک فایل متنی با Vim بساز و ویرایش کن.
2. یک کلمه را در کل فایل جایگزین کن.
3. بدون موس کار کن.

### روز ۵: آرشیو و فشرده‌سازی

- `tar -czvf backup.tar.gz /etc`
- `tar -xzvf backup.tar.gz`
- `gzip`, `gunzip`
- `zip`, `unzip`

**تمرین:**
1. از `/etc` یک آرشیو بگیر.
2. آن را در مسیر دیگری باز کن.
3. حجم فایل را با `du -sh` ببین.

### روز ۶: Cron و محیط

- `crontab -e`, `crontab -l`
- فرمت کرون: `* * * * * command`
- `env`, `export`, `echo $PATH`
- `.bashrc`, `.profile`
- `alias`

**تمرین:**
1. یک کرون‌جاب بساز که هر دقیقه تاریخ را به یک فایل اضافه کند.
2. یک alias به نام `ll` برای `ls -alF` بساز.
3. `PATH` را بررسی کن.

### روز ۷: جمع‌بندی و پروژه فاز ۱

**پروژه: آماده‌سازی سرور تیم**

1. کاربران `ali`, `sara`, `reza` را بساز.
2. گروه `devs` را بساز و کاربران را به آن اضافه کن.
3. پوشه مشترک `/srv/devshare` بساز.
4. مالکیت را به `root:devs` تغییر بده.
5. مجوز را `2770` بگذار (SetGID).
6. مطمئن شو اعضای گروه می‌توانند فایل بسازند.
7. `htop`, `tree`, `curl` را نصب کن.
8. یک فایل گزارش سیستم بساز:
    - `hostnamectl`
    - `uname -a`
    - `df -h`
    - `free -h`
9. از `/etc` یک آرشیو `.tar.gz` بگیر.
10. یک alias و یک کرون‌جاب ساده اضافه کن.
