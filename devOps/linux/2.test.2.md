## Quiz – Set 2

**1. Which command shows the permissions of a file in both symbolic and octal form?**  
A) `ls -l`  
B) `stat`  
C) `chmod`  
D) `umask`

**2. In the permission string `-rwxr-xr--`, what permission does “others” have?**  
A) `rwx`  
B) `r-x`  
C) `r--`  
D) `--x`

**3. What does the `w` permission mean on a directory?**  
A) You can list the directory contents  
B) You can enter the directory  
C) You can create or delete files inside it  
D) You can execute files inside it

**4. Which numeric permission corresponds to `rw-rw-r--`?**  
A) `644`  
B) `664`  
C) `755`  
D) `775`

**5. What is the octal value of `rwxr-x---`?**  
A) `750`  
B) `755`  
C) `700`  
D) `740`

**6. Which command gives the owner execute permission on a file?**  
A) `chmod g+x file`  
B) `chmod u+x file`  
C) `chmod o+x file`  
D) `chmod a+x file`

**7. What does `chmod a+r file` do?**  
A) Gives read permission to the owner only  
B) Gives read permission to the group only  
C) Gives read permission to everyone  
D) Removes read permission from everyone

**8. Which command changes only the group owner of a file?**  
A) `chown`  
B) `chmod`  
C) `chgrp`  
D) `umask`

**9. What is the default `umask` value on most Ubuntu systems?**  
A) `0002`  
B) `0022`  
C) `0077`  
D) `0222`

**10. With `umask 022`, what permission does a new directory get?**  
A) `644`  
B) `755`  
C) `700`  
D) `777`

**11. What does `chmod 4755 file` set?**  
A) SetGID + `rwxr-xr-x`  
B) SetUID + `rwxr-xr-x`  
C) Sticky + `rwxr-xr-x`  
D) SetUID + `rwxrwxrwx`

**12. Which special permission allows a user to execute a file with the file owner’s privileges?**  
A) SetGID  
B) Sticky Bit  
C) SetUID  
D) umask

**13. Which special permission makes new files in a directory inherit the directory’s group?**  
A) SetUID  
B) SetGID  
C) Sticky Bit  
D) `chmod 777`

**14. What does `chmod +t folder` set?**  
A) SetUID  
B) SetGID  
C) Sticky Bit  
D) Read-only permission

**15. Which permission string represents a directory with SetGID and Sticky Bit (permissions `3775`)?**  
A) `drwxrwsr-t`  
B) `drwxrwsr-x`  
C) `drwxrwxrwt`  
D) `-rwsr-xr-x`

**16. What error do you get when trying to execute a script with `644` permissions?**  
A) `Command not found`  
B) `Permission denied`  
C) `No such file or directory`  
D) `Operation not permitted`

**17. If a directory has permissions `000`, what can you do?**  
A) You can `cd` into it but not list its contents  
B) You can list its contents but not `cd` into it  
C) You can neither `cd` into it nor list its contents  
D) You can both `cd` into it and list its contents

**18. Which command finds files with SetUID permission on the system?**  
A) `find / -perm -4000 -type f`  
B) `find / -perm -2000 -type f`  
C) `find / -perm -1000 -type f`  
D) `find / -perm -777 -type f`

**19. Why is `chmod 777` considered bad practice?**  
A) It makes files unreadable  
B) It gives full access to everyone and reduces security  
C) It removes the owner’s permissions  
D) It prevents the file from being executed

**20. In the project scenario, what does `chmod 3775 /srv/devshare` achieve?**  
A) SetUID + Sticky + `rwxrwxr-x`  
B) SetGID + Sticky + `rwxrwxr-x`  
C) SetGID + SetUID + `rwxrwxr-x`  
D) Sticky only + `rwxrwxr-x`
