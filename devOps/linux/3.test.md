## Test – Session 3: User and Group Management

**1. Which file stores basic user account information readable by everyone?**  
A) `/etc/shadow`  
B) `/etc/passwd`  
C) `/etc/group`  
D) `/etc/gshadow`

**2. In `/etc/passwd`, what does the `x` in the second field mean?**  
A) The password is stored in plain text  
B) The password hash is in `/etc/shadow`  
C) The account is locked  
D) The user has no password

**3. What is the UID range for regular human users on most Linux systems?**  
A) 0  
B) 1–999  
C) 1000 and above  
D) 65000 and above

**4. Which file contains the password hashes and is readable only by root?**  
A) `/etc/passwd`  
B) `/etc/group`  
C) `/etc/shadow`  
D) `/etc/gshadow`

**5. In `/etc/group`, which field lists the members of the group?**  
A) First field (group name)  
B) Second field (password)  
C) Third field (GID)  
D) Fourth field (member list)

**6. Which command shows the UID, GID, and all groups of a user?**  
A) `whoami`  
B) `groups`  
C) `id`  
D) `who`

**7. What is the main difference between `adduser` and `useradd`?**  
A) `adduser` works on all distributions; `useradd` only on Ubuntu  
B) `adduser` is interactive and Debian/Ubuntu-specific; `useradd` is a system binary available everywhere  
C) `useradd` creates home directories by default; `adduser` does not  
D) They are exactly the same command

**8. Which option for `useradd` creates the user’s home directory?**  
A) `-M`  
B) `-m`  
C) `-d`  
D) `-s`

**9. Which command creates a system user with no login shell and no home directory?**  
A) `sudo useradd -m -s /bin/bash appuser`  
B) `sudo useradd -r -s /usr/sbin/nologin -M appuser`  
C) `sudo adduser appuser`  
D) `sudo useradd -e 2026-12-31 appuser`

**10. What is the critical difference between `usermod -G group user` and `usermod -aG group user`?**  
A) `-G` adds the group; `-aG` removes it  
B) `-G` replaces all existing supplementary groups; `-aG` appends the new group  
C) There is no difference  
D) `-aG` only works for the primary group

**11. Which command locks a user account?**  
A) `sudo usermod -L devops`  
B) `sudo usermod -U devops`  
C) `sudo passwd -u devops`  
D) `sudo userdel devops`

**12. What does `sudo userdel -r ali` do?**  
A) Deletes the user but keeps the home directory  
B) Deletes the user and their home directory and mail spool  
C) Only removes the user from all groups  
D) Locks the user account

**13. Which command forces a user to change their password at the next login?**  
A) `sudo passwd -l ali`  
B) `sudo chage -M 90 ali`  
C) `sudo passwd -e ali`  
D) `sudo chage -l ali`

**14. Which command sets the maximum password age to 90 days for user `ali`?**  
A) `sudo chage -M 90 ali`  
B) `sudo chage -m 90 ali`  
C) `sudo chage -E 90 ali`  
D) `sudo passwd -x 90 ali`

**15. Which command adds user `ali` to group `devs` using the modern group management tool?**  
A) `sudo groupadd -a ali devs`  
B) `sudo gpasswd -a ali devs`  
C) `sudo usermod -G devs ali`  
D) `sudo groupmod -a ali devs`

**16. Why should you use `visudo` instead of editing `/etc/sudoers` directly?**  
A) `visudo` encrypts the file  
B) `visudo` checks syntax before saving, preventing lockout  
C) `visudo` automatically adds `NOPASSWD`  
D) `visudo` is the only way to edit the file

**17. Which sudoers line allows user `jenkins` to restart `myapp` without a password?**  
A) `jenkins ALL=(ALL) ALL`  
B) `jenkins ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart myapp`  
C) `%jenkins ALL=(ALL) /usr/bin/systemctl restart myapp`  
D) `jenkins ALL=(ALL) PASSWD: /usr/bin/systemctl restart myapp`

**18. What is the recommended location for custom sudoers rules?**  
A) Directly in `/etc/sudoers`  
B) In `/etc/sudoers.d/` using `visudo -f`  
C) In `/etc/passwd`  
D) In `/etc/group`

**19. Which command checks which sudo privileges user `charlie` has?**  
A) `sudo -l -U charlie`  
B) `sudo -u charlie -l`  
C) `id charlie`  
D) `getent group charlie`

**20. Which command lists all users with UID 0 (should only be root)?**  
A) `awk -F: '$3==0 {print $1}' /etc/passwd`  
B) `awk -F: '$3>=1000 {print $1}' /etc/passwd`  
C) `grep root /etc/passwd`  
D) `getent passwd | grep 0`
