# جلسه ۱: ترمینال و ناوبری در فایل‌سیستم

**هدف جلسه:** در پایان این جلسه بتوانی بدون موس، در کل فایل‌سیستم حرکت کنی، فایل و پوشه بسازی، کپی کنی و پاک کنی.

---

## بخش ۱: باز کردن ترمینال

روی Ubuntu یکی از این راه‌ها:

- کلید `Ctrl + Alt + T`
- یا جستجو کن: `Terminal`
- یا از منوی برنامه‌ها `GNOME Terminal` را باز کن

اولین چیزی که می‌بینی چیزی شبیه این است:

</div>

```
devops@ubuntu:~$
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

**تجزیه‌اش کنیم:**

- `devops` → نام کاربری
- `ubuntu` → نام دستگاه (hostname)
- `~` → یعنی الان در پوشه home خودت هستی
- `$` → یعنی کاربر معمولی هستی (اگر root بودی `#` می‌شد)

---

## بخش ۲: از کجا شروع کردم؟ (`pwd`)

**Print Working Directory** — مسیر فعلی را نشان می‌دهد.
</div>

```bash
pwd
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
خروجی احتمالاً:
</div>

```
/home/devops
```

**نکته:** در لینوکس `~` معادل `/home/نام‌کاربری` است. پس `~` و `/home/devops` یکی هستند.

---

## بخش ۳: چه چیزی اینجاست؟ (`ls`)

**List** — محتویات پوشه فعلی را نشان می‌دهد.
</div>

```bash
ls
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
خروجی مثلاً:
</div>

```
Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

### گزینه‌های پرکاربرد `ls`

| دستور | کارش |
|---|---|
| `ls -l` | نمایش لیستی با جزئیات (مجوز، مالک، اندازه، تاریخ) |
| `ls -a` | نمایش فایل‌های مخفی (آن‌هایی که با `.` شروع می‌شوند) |
| `ls -la` | ترکیب هر دو |
| `ls -lh` | اندازه‌ها به شکل خوانا (K, M, G) |
| `ls -R` | بازگشتی (همه زیرپوشه‌ها) |
| `ls /etc` | محتویات یک مسیر خاص |

**تمرین ۱:**
</div>

```bash
ls -la
```
چند فایل مخفی می‌بینی؟ (مثلاً `.bashrc`, `.profile`)
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

## بخش ۴: حرکت کردن (`cd`)

**Change Directory** — تغییر پوشه.
</div>

```bash
cd Documents
pwd
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

حالا داخل `/home/devops/Documents` هستی. برگرد به خانه:
</div>

```bash
cd ~
# یا فقط
cd
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

### مسیر مطلق vs نسبی

- **مطلق (Absolute):** از ریشه `/` شروع می‌شود. مثال: `/etc/ssh`
- **نسبی (Relative):** از جایی که هستی. مثال: اگر در `/home/devops` هستی، `Documents` یعنی `/home/devops/Documents`

### میان‌برهای مهم `cd`

| دستور | نتیجه |
|---|---|
| `cd ~` | برو به خانه |
| `cd` | همان بالا |
| `cd /` | برو به ریشه |
| `cd ..` | یک سطح برو بالا |
| `cd ../..` | دو سطح بالا |
| `cd -` | برگرد به پوشه قبلی |

**تمرین ۲:**
</div>

```bash
cd /etc
pwd
cd ..
pwd
cd -
pwd
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

## بخش ۵: ساختن پوشه (`mkdir`)

**Make Directory**
</div>

```bash
cd ~
mkdir lab
ls
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

### ساخت چند پوشه با هم
</div>

```bash
mkdir lab/week1 lab/week2
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

### ساخت پوشه‌های تودرتو با `-p`
</div>


```bash
mkdir -p lab/week1/docs lab/week1/logs lab/week1/tmp
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

با `-p` اگر پوشه‌های والد وجود نداشته باشند، خودش می‌سازد.

### دیدن ساختار درختی
</div>

```bash
tree lab
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

اگر `tree` نصب نیست:
</div>

```bash
sudo apt update
sudo apt install tree -y
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

**تمرین ۳:** این ساختار را بساز:
</div>

```
~/lab/
├── week1/
│   ├── docs/
│   ├── logs/
│   └── tmp/
└── week2/
    └── notes/
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

## بخش ۷: کپی کردن (`cp`)
</div>

```bash
cp note1.txt note1-backup.txt
ls
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
### کپی پوشه (نیاز به `-r`)
</div>
```bash
cp -r ~/lab/week1 ~/lab/week1-copy
ls ~/lab
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

### گزینه‌های پرکاربرد

| دستور | کارش |
|---|---|
| `cp -r dir1 dir2` | کپی بازگشتی پوشه |
| `cp -i` | قبل از بازنویسی سوال بپرسد |
| `cp -v` | نمایش عملیات (verbose) |

<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

</div>

<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

## بخش ۹: پاک کردن (`rm`, `rmdir`)

### پاک کردن فایل

</div>

```bash
rm note2-renamed.txt
```

### با تأیید

```bash
rm -i note1.txt
```

### پاک کردن پوشه خالی

```bash
rmdir ~/lab/week1/tmp
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

### پاک کردن پوشه با محتوا (بسیار خطرناک!)
</div>

```bash
rm -r ~/lab/week1-copy
```

### ⚠️ هشدار جدی

```bash
rm -rf /
```

<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

**هرگز این را نزن.** کل سیستم را نابود می‌کند. در لینوکس **Recycle Bin** وجود ندارد. هرچه با `rm` پاک کنی، رفته.

**قانون طلایی:** قبل از `rm -rf`، دوباره با `ls` ببین در چه مسیری هستی و چه چیزی داری پاک می‌کنی.

**تمرین ۴:** پوشه `~/lab/week1-copy` را کامل پاک کن.

## بخش ۱۰: پیدا کردن فایل (`find`)
</div>

```bash
find ~/lab -name "*.txt"
find /var/log -name "*.log" 2>/dev/null
find ~/lab -type d
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

| بخش | معنا |
|---|---|
| `~/lab` | از کجا شروع کن |
| `-name "*.txt"` | فایل‌هایی که با `.txt` تمام می‌شوند |
| `-type d` | فقط پوشه‌ها (`f` = فایل) |
| `2>/dev/null` | خطاها را نادیده بگیر |

چند دستور پرکاربرد:

</div>

## بخش ۱۲: لینک‌ها (Link)

### Soft Link (مثل Shortcut در ویندوز)
</div>

```bash
cd ~/lab
ln -s /etc/hosts hosts-link
ls -l
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">
خروجی چیزی شبیه:
</div>

```
lrwxrwxrwx 1 devops devops 10 ... hosts-link -> /etc/hosts
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

حرف `l` در ابتدا یعنی link.
</div>

```bash
cat hosts-link
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

همان محتوای `/etc/hosts` را نشان می‌دهد.

### Hard Link
</div>

```bash
touch original.txt
ln original.txt hardlink.txt
ls -li
```
<div dir="rtl" style="text-align: right; font-family: 'B Nazanin', Tahoma, sans-serif;">

ستون `-i` شماره inode را نشان می‌دهد؛ هر دو یک inode دارند.

**تفاوت خلاصه:**

- Soft Link → به مسیر اشاره می‌کند. اگر مقصد پاک شود، لینک می‌شکند.
- Hard Link → به inode اشاره می‌کند. تا وقتی یک لینک باقی باشد، فایل زنده است.

## پروژه کوچک جلسه ۱

این کارها را انجام بده:

1. یک ساختار بساز: `~/linux-course/session1/{files,backup,archive}`
2. در `files` سه فایل بساز: `a.txt`, `b.txt`, `c.txt`
3. یک فایل مخفی بساز: `touch files/.secret`
4. همه را با `ls -la` ببین
5. `a.txt` را به `backup/` کپی کن
6. `b.txt` را به `bb.txt` تغییر نام بده
7. `c.txt` را پاک کن
8. یک Soft Link به `/etc/os-release` داخل `archive/` بساز
9. با `find ~/linux-course -name "*.txt"` همه فایل‌های txt را پیدا کن
10. با `tree ~/linux-course` ساختار نهایی را ببین
