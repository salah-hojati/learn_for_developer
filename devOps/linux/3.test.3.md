## Advanced Scenario Questions – Session 3

**1. A user reports that their `sudo` command failed, but you need to see exactly what command they attempted and why it was denied. Which log source gives the most detailed sudo audit trail on a modern systemd‑based Ubuntu server?**  
A) `~/.bash_history`  
B) `journalctl -u sudo` or `/var/log/auth.log`  
C) `/etc/sudoers`  
D) `last`

**2. You want to verify that sudo is logging every successful and failed attempt. Which command shows recent sudo entries from the journal?**  
A) `sudo journalctl -u sudo -n 20`  
B) `sudo cat /etc/shadow`  
C) `sudo getent group sudo`  
D) `sudo chage -l root`

**3. You need to enforce a company policy: every user’s password must expire every 60 days, with a 7‑day warning before expiry, and accounts must be disabled 14 days after password expiry. Which `chage` options set these three values for user `ali`?**  
A) `sudo chage -M 60 -W 7 -I 14 ali`  
B) `sudo chage -M 60 -m 7 -E 14 ali`  
C) `sudo chage -M 60 -W 7 -E 14 ali`  
D) `sudo chage -m 60 -W 7 -I 14 ali`

**4. You want to set the default password aging policy for all **new** users on the system (not existing ones). Where should you configure this?**  
A) `/etc/passwd`  
B) `/etc/shadow`  
C) `/etc/login.defs`  
D) `/etc/sudoers`

**5. Which `chage` command sets an account expiration date of December 31, 2026 for user `sara`?**  
A) `sudo chage -E 2026-12-31 sara`  
B) `sudo chage -M 2026-12-31 sara`  
C) `sudo chage -I 2026-12-31 sara`  
D) `sudo chage -d 2026-12-31 sara`

**6. A user’s password was changed today, but you want to force them to change it again at their next login. Which command achieves this?**  
A) `sudo chage -d 0 ali`  
B) `sudo chage -M 0 ali`  
C) `sudo chage -E 0 ali`  
D) `sudo passwd -l ali`

**7. You run `sudo chage -l ali` and see “Password expires: never”. Which field in `/etc/shadow` controls this?**  
A) The second field (password hash)  
B) The fourth field (minimum days)  
C) The fifth field (maximum days)  
D) The seventh field (inactive days)

**8. Your company uses LDAP for central user management. You want to check whether user `jdoe` exists via NSS without directly querying `/etc/passwd`. Which command is best?**  
A) `cat /etc/passwd | grep jdoe`  
B) `getent passwd jdoe`  
C) `id jdoe` only  
D) `sudo useradd jdoe`

**9. Which file determines the order in which NSS sources (files, LDAP, sssd, etc.) are consulted for user and group lookups?**  
A) `/etc/passwd`  
B) `/etc/nsswitch.conf`  
C) `/etc/ldap.conf`  
D) `/etc/sudoers`

**10. On a system integrated with LDAP via SSSD, a local user `deploy` must still be able to log in even if the LDAP server is unreachable. What should you verify in `/etc/nsswitch.conf`?**  
A) That `passwd: files sss` lists `files` before `sss`  
B) That `passwd: sss files` lists `sss` before `files`  
C) That `sudoers: ldap` is set  
D) That `/etc/shadow` is world‑readable

**11. You want to grant sudo access to an LDAP group named `devops` without creating local Linux groups. Which approach is most appropriate?**  
A) Add each LDAP user to `/etc/sudoers` manually  
B) Use `sudoers: ldap` or SSSD’s `sudo` provider in `/etc/nsswitch.conf` and configure the sudoers LDAP schema  
C) Create a local group `devops` and add all LDAP users to it  
D) Set `chmod 777` on `/etc/sudoers`

**12. You suspect a user is repeatedly trying to run unauthorized sudo commands. Which command helps you audit their failed sudo attempts from the journal?**  
A) `sudo journalctl -u sudo | grep -i "incorrect password"`  
B) `sudo cat /etc/passwd`  
C) `sudo getent group sudo`  
D) `sudo chage -l $USER`

**13. You want to log every sudo command with the full command line and the user who ran it. Which sudoers option (or default) is relevant?**  
A) `Defaults logfile=/var/log/sudo.log` and `Defaults log_input, log_output`  
B) `Defaults !authenticate`  
C) `Defaults env_reset`  
D) `Defaults targetpw`

**14. A user `alice` is in LDAP, but `sudo -l -U alice` shows no sudo privileges even though the LDAP sudo rule exists. What is the most likely cause?**  
A) `/etc/nsswitch.conf` has `sudoers: files` only, so LDAP sudo rules are ignored  
B) `alice`’s password is expired  
C) `alice` is not in `/etc/passwd`  
D) `sudo` does not support LDAP

**15. You want to find all local users whose password will expire within the next 7 days. Which approach is most practical?**  
A) `sudo chage -l` for each user and manually compare dates  
B) `sudo awk -F: '{print $1}' /etc/shadow` and check each one  
C) Use `chage -l` in a loop over human users and parse the “Password expires” date, or use `chage -M`/`-W` reporting tools  
D) `getent passwd | grep 1000`
